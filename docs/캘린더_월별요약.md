# 캘린더 월별 노래 연습 요약
담당 범위: 캘린더 대시보드와 선택한 오늘 날짜 대비 수정.
미디어/R2/업로드/전사/압축/이전/곡 매칭/연습 기록 생성 로직은 수정하지 않습니다.
새 파일 app/calendar-summary.js, app/calendar-summary.css에서 기존 데이터를 읽기만 합니다.
공유 파일 변경은 index.html의 두 리소스 로딩과 views-lessons.js의 캘린더 렌더 연결입니다.

- 선택한 달의 총 노래 연습 시간과 횟수, 기본 TOP 3, 펼치면 TOP 5.
- 시간순/횟수순. 각 곡에 시간과 횟수를 함께 표시.
- 연습 기록 1건 또는 연결되지 않은 녹음 1개 = 1회.
- 연결 파일은 이중 집계하지 않음. 발성 훈련과 레슨 녹음 제외.
- 기록 날짜 및 기존 media.dateOf를 재사용. 원본이나 저장 날짜를 수정하지 않음.
- 길이 미상은 횟수만 포함. 곡 미지정도 합계에 포함.
- 선택된 오늘 날짜의 숫자를 흰색으로 표시하여 보라색 배경과 구분.

검증: node --test tests/calendar-summary.test.cjs
브라우저: npx playwright test tests/calendar-summary.spec.cjs
Chromium 모바일/PC, WebKit 모바일 뷰포트. 실제 iPhone 실기기 검증과는 다릅니다.
