## 우선순위와 상태

P0는 데이터·보안·운영비 노출을 먼저 막는 작업이며, 제품 고도화 중요도와 다르다. 예를 들어 일반 사용자 영상 제한은 P0 서버 보호, 소유자 3택 UX는 P2다. P3는 뒤로 미뤄도 되는 출시 옵션이 아니라 출시 전 필수 통합이다. iOS PoC는 P0에서 시작한다.

상태는 구현/정책 일치/검증을 분리한다. '이미 구현되고 검증'은 아래 S07의 명시 범위만 해당하며 전체 기능 완료가 아니다. 나머지 코드 존재는 '추가 테스트 필요'로 남긴다. 일부 문서가 없으므로 전체 기능 조사 완료를 선언하지 않는다.

## 확인 근거와 한계

- 기준 main: [6dd838934b4b27731c12d06f9ef3dd0530d4596e](https://github.com/eye215/Vocalzip/commit/6dd838934b4b27731c12d06f9ef3dd0530d4596e). 이번 작업은 문서 작성과 관련 코드의 제한적 읽기만 수행했다. 앱/운영 테스트를 새로 실행하지 않았다.
- 요청한 `docs/audit/2026-11-07-current-state.md`, `2026-11-07-phase-mapping.md`, `2026-11-07-next-actions.md`는 기준 main에서 404이며 전체 트리에도 없다. 조사 완료로 표시하지 않는다. Claude 미게시 작업을 대신 작성하거나 브랜치를 수정하지 않는다.
- [정책-코드 점검서](../audit/2026-11-07-policy-code-check.md)는 PR #112·#114의 코드/운영 증거를 포함한다. 초기 본문은 v1.1 기준이고 30일 휴지통 실패 판정은 v1.2에 적용하지 않는다. 후반 운영 감사 run `42329332614`는 RLS/비공개 Storage/미인증 Worker 거부의 제한된 검증 증거다. 실제 iPhone·R2 공개 도메인·수명주기·비용은 미검증이다.
- 현재 코드 재확인: `cloud-sync.js:503` 로그인→sync; `app/core.js:96~105` 미연결 파일 길이 포함; `worker/analysis-worker.mjs:235~274` 유료 전사와 자동 곡 지정; `r2-worker/src/index.js:30` video MIME 허용. 정책 변경 대상으로 분류한다.
- `app/views-main.js:91/175/220`은 이미 training·mediaIds·직접 분 저장을 제공한다. '트레이닝 녹음 새 엔진'을 재개발하지 않고 누락 진입/회귀를 검증한다.
- `app/scores.js:19~37`은 PDF 파일 선택·R2 업로드·메타데이터 저장이며, MusicXML은 향후 대비 주석이다. 옛 마스터 8A=보관, 8E=향후 OMR이다. XML 변환/편집/음표 평가를 완료라고 표시할 근거는 없다.
- `app/repertoire-model.js`의 상태·키/테이크 참조·공연 모델은 재사용 후보다. 모델 존재가 실제 운영·iPhone 검증을 의미하지 않는다.
- PR #111 `cf6379857c9eba55fa866cc97b4c1676f122cf3d` 검토서를 읽었다. 원문은 그대로 보존하고 v1.2 대조표만 새 문서에 둔다.
