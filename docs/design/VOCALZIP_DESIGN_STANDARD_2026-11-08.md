## 화면

- 인사말·레슨 설명을 복원하지 않는다. 헤더52px, 알림·프로필44px.
- 레슨은 연한 카드·최소108px·제목24px(좁은 화면22px)·일시13px. 제목과 D-day는 묶는다.
- 공연·오디션은 짧은 행, 터치44px 이상. 기존 일정 정렬·완료·삭제 정책을 유지한다.
- 주간 제목18px·숫자28px. 완료는 같은 보라 원+체크, 오늘은 링, 미래 완료 금지. 목표 미설정에는 설정 진입을 제공한다.
- 최근 곡은 부드러운 그라데이션, 하단 ‘계속 연습하기’로 기존 연습 화면을 곡 선택 상태로 연다. 녹음 유무와 무관하게 사용한다.
- 퀵메뉴는 가로 아이콘+문구,20px 선형 아이콘·간격8px·내부16px(좁은 화면12px).
- 목표는14px/400,20px 체크·6px 반경·49px 이상 행. 완료 문장은 #98A2B3·얇은 취소선. 출처는11px.
- 내비는 흰색78%·20px 블러·흰색65% 테두리·캡슐·가벼운 그림자. 선택 면 rgba(122,50,245,.055), 선택 라벨 #8A6DB8, 녹음52px 불투명 보라.
- 기능 아이콘은 전달본 Lucide SVG를 재사용한다. 선형24 viewBox·stroke1.8, 제목20px·내비24px. 라이선스는 [ISC/MIT 고지](../../design-system/icons/LUCIDE_LICENSE.txt).
- 실제 앱에 전달 미리보기의 외곽 프레임·가짜 OS 인디케이터를 넣지 않는다.
- 마지막 콘텐츠가 내비 위로 스크롤되도록 하단140px+Safe Area를 유지한다.
