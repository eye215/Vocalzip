# 최상단 일정 영역 · 상태별 시안

## 사용자 기준

- ‘2026 MAMA AWARDS 오사카 현지에서 즐겨요’가 표시된 신한은행 이벤트 영역처럼 배경에 직접 노출.
- 공연·오디션·레슨 모두 흰 카드/테두리/그림자 없이 표시. 여러 건은 세로로 나열.
- 인사말 바로 다음, 주간 연습보다 앞. 일정이 없으면 영역과 여백 모두 제거.
- 기존 서브페이지의 연보라 배경·흰 카드·보라 포인트 유지.

## 실제 사용한 색

`app/app.css`의 v6 공통 토큰을 재사용하고, 단독 시안은 같은 값을 fallback으로 사용한다.

| 역할 | 기존 토큰 | 값 |
| --- | --- | --- |
| 화면 바탕 | --bg | #f6f4fb |
| 나머지 카드 | --surface | #ffffff |
| 큰 제목 | 사용자 타입 기준 | #191f28 |
| 본문 | 사용자 타입 기준 | #4e5968 |
| 날짜/분류/보조 정보 | 사용자 타입 기준 | #6b7684 |
| D-day/진입 링크 | 사용자 라벤더 팔레트 | #6d59b5 |
| 메인 액션/선택 | 사용자 라벤더 팔레트 | #7865c8 |
| 옅은 선택 면 | 사용자 라벤더 팔레트 | #f0ecfa |

금융 앱의 파란색을 새 브랜드색으로 가져오지 않는다. 레퍼런스에서는 분류 → 제목 → 링크의 위계와 우측 이미지 배치만 적용한다.
무대 제목은 중성 계열의 기존 진한 글자색, 포인트는 D-day와 진입 링크에 집중한다.

## 글꼴과 글자 위계

기존은 `-apple-system` 우선이라 iOS에서는 시스템 글꼴, Linux 자동 캡처에서는 다른 fallback이 사용됐다.
CSS 목록의 Pretendard 이름만으로 해당 폰트가 실제 로드된 것은 아니었다.

이번 시안은 Pretendard v1.3.9 원본 WOFF2를 직접 포함하고 400/600/700을 명시해 기기별 재현성을 높인다.
원본 파일 3개는 upstream git blob SHA와 동일하다. 수정·서브셋 생성 없이 OFL 라이선스를 함께 보존했다.
홈에만 적용하며 기존 서브페이지의 전역 글꼴/스타일을 덮어쓰지 않는다. 폰트는 동일 출처에서 제공하고 font-display:swap을 사용한다.
총 원본 크기 약 2.34MB이며 첫 로드 이후 브라우저 캐시 대상이다.

| 요소 | 크기/행간 | 굵기 |
| --- | --- | --- |
| 화면 대표 제목/인사말 | 22 / 32 | 700 |
| 주요 카드 제목 | 18 / 26 | 700 |
| 카드 안 소제목/곡명 | 16 / 24 | 600 |
| 핵심 연습 수치 | 22 / 30 | 700 |
| 본문/목표 | 15 / 22 | 400 |
| 설명/날짜 | 13 / 20 | 400 |
| 메인 버튼 | 16 / 24 | 600 |
| 작은 버튼/링크 | 14 / 20 | 600 |
| 배지/상태 | 12 / 16 | 600 |
| 하단 메뉴 | 11 / 16 | 600 |

신한 캡처의 정확한 폰트명은 이미지로 확정하지 않는다. Pretendard를 해당 앱의 원본 폰트라고 주장하지 않는다.
숫자·단위는 baseline 정렬, 한글은 어절 줄바꿈을 우선하고 긴 단어는 내용이 보존되도록 확장한다.

## 상태별 예시

- `?upcoming=both`: 공연 + 레슨
- `?upcoming=stages`: 공연 + 오디션
- `?upcoming=all`: 공연 + 오디션 + 레슨
- `?upcoming=lesson`: 레슨만
- `?upcoming=none`: 일정만 없음. 목표·주간 기록은 유지

`design-system/upcoming-events-board.html`은 이 다섯 화면을 함께 렌더링한다.
모든 예시 데이터는 단독 프리뷰에만 있다. 실제 사용자 DB에 생성하지 않는다.
앱의 기존 단일 무대·다음 레슨 선택 및 상세 이동 계약은 유지한다.
공연과 오디션을 동시에 보여 주는 배열은 이 단계에서 시안용 입력이며, 실제 복수 일정 조회/분류 정책을 구현 완료로 표시하지 않는다.

## 검증 구분

기존 체크 저장·실패 복원·재생·이동·긴 제목·글자 확대 검증을 유지한다.
신규 검증은 실제 폰트 3개 로딩, v6 바탕/카드 색, 최상단 순서, 비카드 표면, 다섯 상태의 표시/미표시와 320/390/430px 가로 넘침을 확인한다.
실제 iPhone/PWA/VoiceOver 검증과 운영 배포는 포함하지 않는다. 실행 결과와 캡처는 PR #135에 기록한다.

## 최신 카드·버튼 규격

카드는 반경 20px, 기본 내부 여백 20px, 간격 12px, 흰색·무테·무그림자다. 주간 요약처럼 정보가 많은 표면은 상하 16px을 사용한다.
주간 요약은 제목과 핵심 수치를 한 줄에 두고 목표·연속일·7일 상태로 압축한다. 일별 분 값은 날짜별 접근성 설명과 기존 성장 상세에서 확인하며, 녹음 시간을 새로 합산하지 않는다.
목표는 행당 최소 48px이며 내용에 따라 늘어난다. 한 개의 긴 목표는 카드 자체가 늘어나 체크가 내부 스크롤에 숨지 않게 한다. 다수 목표는 기존 내부 스크롤을 유지한다.
녹음 재생/아이콘 조작은 최소 44px, 목표 저장은 52px·반경16·16px/600으로 적용한다. 설정 버튼은 32px 시각 면에 부모의 44px 터치 영역을 유지한다.
중앙 녹음은 기존 독의 부유 원형 컨트롤을 유지한다.

앞선 ‘기존 연보라 배경 유지’ 지시를 우선해 배경은 #f6f4fb를 사용한다. 제안의 #f5f5f8은 이 시안에서 교체하지 않는다.
레슨도 카드 없이 배경에 노출한다는 명시 지시를 유지한다. 레슨을 별도 흰 카드로 되돌리지 않는다.
굵기 세 가지 제한을 지켜 숫자 단위 13px은 500 대신 400으로 표현한다. 한글 자간은 -.02em을 기본으로 한다.
