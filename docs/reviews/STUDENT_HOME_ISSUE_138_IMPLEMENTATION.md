## 데이터 계약

기존 곡 ID를 연습 폼의 songId로 넘긴다. 폼을 열기만 해서는 곡·연습·목표·레슨을 생성하거나 시간을 합산하지 않는다.
기존 레슨과 공연은 읽기 전용으로 표시한다. 날짜·D-day는 기존 로컬 날짜 유틸리티를 재사용한다.
녹음 원본과 재생 기능은 기존 보관함·곡 상세에 남긴다. 홈의 주 행동만 요청된 연습 흐름으로 변경한다.

## 자동 검증 대상

-320/390/430px, 긴 제목·목표,200% 글자, 네비 위 마지막 항목.

- 곡·일정·목표 없음, 목표 설정 진입, 목표 저장·실패 복원·새로고침·900개 목록.
- 실제 색상·크기·굵기·폰트 로딩·SVG 초기 표시·레슨108px·미래 체크 금지.

- 현재 테스트는 합성 데이터·로컬 미디어를 사용하며 실제 계정·R2 쓰기를 수행하지 않는다.

실행 결과와 캡처는 PR #135의 최신 커밋과 CI 링크에 기록한다.
전달 미리보기는 날짜·기록 분포·곡을 고정한 예시이며 실제 앱에는 복사하지 않는다.
