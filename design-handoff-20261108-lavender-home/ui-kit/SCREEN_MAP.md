# 화면과 연결 구조

| 경로 | 화면 | 주요 흐름 | 실제 앱 연결 기준 |
| --- | --- | --- | --- |
| #/home | 홈 | 일정·주간·최근곡·목표·퀵메뉴 | 승인한 플로팅 홈 유지 |
| #/songs | 내 곡 | 검색·상태 필터·곡 추가 | 기존 songs 경로·곡ID |
| #/song/s1 | 곡 상세 | 메모·최근 연습·연결 녹음·연습 기록 | 기존 song 상세·practiceSheet |
| #/library | 보관함 | 파일 검색·음성/영상·가져오기 | 기존 media.list/import, 원본 보존 |
| #/media/m1 | 파일 상세 | 연결 곡·메모·재생 화면 | 기존 플레이어·파일ID, 본 시안은 파일 미포함 |
| #/calendar | 일정 | 달 이동·날짜 선택·일정 추가 | 기존 calendar·일정 데이터 |
| #/event/e1 | 일정 상세 | 장소·시간·연결곡·레슨 진입 | 기존 레슨/공연/오디션ID |
| #/lessons | 레슨노트 | 다음 레슨·지난 노트·숙제 | 기존 lessons |
| #/lesson/l2 | 레슨 상세 | 피드백 편집·곡·숙제 | 기존 lesson 상세 |
| #/homework | 숙제와 목표 | 진행/완료·체크·개인 목표 추가 | 숙제 원본과 일일목표 정책 구분 필요 |
| #/practice | 연습기록 | 목록·분 집계·추가 | 기존 practices, 수동 시간 |
| #/practice/p1 | 연습 상세 | 날짜·분·메모·곡 | 기존 practiceDetail |
| #/record | 녹음 | 시작·일시정지·계속·종료·기록 | 기존 recorder로 대체, 시안은 마이크 미사용 |
| #/growth | 성장 기록 | 기록 시간·곡별 집계 | 기존 growth |
| #/notifications | 알림 | 알림 확인·읽음 | 실제 알림 API와 별도 연결 |
| #/settings | 내 설정 | 목표·알림 옵션·디자인 시스템 | 기존 settings, 시안은 실제 저장 안 함 |
| #/design-system | 디자인 시스템 | 색·타입·버튼·필드·빈 상태 | 개발 전달용, 실제 앱 메뉴 노출 여부 별도 |

공통 하단 네비와 플로팅은 목록/상세에서도 같은 위치입니다. 녹음 화면에서는 둘 다 숨깁니다. 홈의 최근곡은 재생 대신 해당 곡이 선택된 연습 기록 입력으로 연결합니다. 보관함 파일 상세의 재생 버튼은 별도의 미디어 미포함 안내를 엽니다.

## 확인할 조합

320/390/430px, 긴 곡명·레슨명·목표, 빈 검색 결과, 태그와 숫자, 필수값 누락, 큰 글자, 플로팅/네비 가림, 페이지 이동 후 스크롤 초기화, dialog 닫기·Escape·폼 검증, 입력에 HTML을 넣었을 때 텍스트로 표시되는지 확인합니다.

## 범위 제외

실계정·클라우드·운영DB·미디어 원본·영구 삭제·정산·AI·배포를 변경하지 않습니다. 실제 녹음 권한과 저장, 서버 검색, 자동 동기화, 프로필 편집은 구현 시 기존 서비스 기능에 연결해야 합니다.
