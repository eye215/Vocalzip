# 학생 홈 재설계 — 2026-11-08

## 기준

사용자가 앞선 정돈안을 거절하고 “아예 니가 알아서 바꿔봐”라고 요청했다.
이전의 구성·색상·타일 비율 고정 조건을 해제하고 학생의 연습 시작을 중심으로 홈을 다시 구성한다.
이전 시안 및 검토 문서는 이력으로 보존한다.

## 화면

1. 간결한 워드마크, 인사말, 알림·프로필.
2. 짙은 잉크색 ‘오늘의 연습’ 카드. 목표 달성률과 녹음 시작 버튼, 전체 너비의 목표 체크 목록.
3. 주간 연습: 꽃 장식을 단순한 세로 막대로 교체. 실제 시간·목표 대비 상태·오늘 표시를 유지.
4. 예정 공연/오디션·레슨. 실제 정보가 있는 부분만 표시하고 사용자의 포스터만 사용.
5. 최근 곡을 가로형 항목으로 표시. 기존 녹음 재생과 곡 상세 연결 유지.
6. 레슨노트·연습기록 바로가기, 기존 5개 목적지의 하단 탐색.

## 구현 범위

- 학생 홈 컴포넌트·전용 CSS·스코프 토큰 및 캐시 버전.
- 새로운 녹음 시작 버튼을 기존 #/record 경로에 연결.
- 시간·목표·일정 계산 및 저장 계약, 기존 녹음·연습·레슨·정산·AI 로직은 유지.
- 목표의 체크 저장·실패 복구·대량 목록 스크롤 및 44px 터치 영역 유지.
- 주간 막대는 기존 실제 시간/목표 비율로 계산한다. 목표 미설정·미래·0분·100~120%·120% 초과를 구분한다.

## 검증

구성 변경에 맞춰 ‘작은 곡 타일과 세로 바로가기’의 고정 비율 검증을 가로형 항목·하단 바로가기 배치 검증으로 교체한다.
390px에서 모든 내용을 한 화면에 넣는 조건 대신 320/390/430px 모두 스크롤 끝에서 하단 메뉴와의 여유를 확인한다.
기존 저장·실패 복구·900개 목표·글자 확대·경로 이동·실제 WAV 재생 검증은 유지한다.
녹음 시작 버튼이 기존 녹음 화면으로 이동하고 연습 계획·기록을 변경하지 않는지 검증한다.

테스트 결과는 PR #135와 해당 커밋의 Actions에 기록한다.
Linux WebKit 검증과 실제 iPhone Safari/PWA/VoiceOver 검증은 구분한다. 운영 배포는 포함하지 않는다.
