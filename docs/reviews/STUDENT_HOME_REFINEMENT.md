# 학생 홈 디자인 정돈 — 2026-11-08

## 적용 기준

최신 요청: “구성은 그대로 디자인 고도화”. 이전 JPEG의 좌표·색상을 그대로 재현하는 목표보다 이번 요청을 우선한다.

- 헤더 → 예정 공연/오디션·레슨 → 오늘의 목표 → 주간 연습 → 최근 곡·바로가기 → 하단 5개 메뉴의 순서와 기능을 유지한다.
- 공연/오디션 및 레슨이 없으면 해당 영역을 숨기는 기존 정책을 유지한다.
- 목표 행의 44px 터치 영역, 목록 스크롤, 실제 저장 및 실패 복구 동작을 유지한다.
- 진한 배경 장식·엠보싱·강한 반사광을 줄이고, 흰 카드와 낮은 채도의 라벤더를 사용한다.
- 제목·보조 정보의 크기와 명도, 카드 여백과 테두리·곡률을 통일한다.
- 가상의 무대 그림과 사진 대신 단순한 음악 자리표시자를 사용한다. 사용자가 등록한 실제 포스터는 표시한다.
- 최근 곡과 바로가기 영역의 비율 및 높이, 8개 둥근 꽃잎 표시, 주간 연습의 데이터 계산은 유지한다.

## 변경 범위

학생 홈 전용 CSS·스코프 토큰, 아이콘/게이지 색상, 캐시 버전, 관련 시각 검증만 변경한다.
인증·동기화·녹음·정산·AI 데이터 구조 및 운영 환경은 변경하지 않는다.
기존 원본 이미지와 이전 검토서는 이력으로 보존한다.

## 검증 기준

320/390/430px에서 가로 넘침과 카드 간 겹침이 없어야 한다.
390px의 기본 프리뷰에서 최근 곡의 제목·가수가 카드 내부에 표시되고 하단 메뉴와 겹치지 않아야 한다.
목표 체크와 저장 실패 복구, 대량 목표 스크롤, 글자 확대, 메뉴 이동, 실제 오디오 재생 회귀 테스트를 유지한다.
이전 JPEG 좌표의 오차 검증만 해제한다. 실제 변경 후 캡처를 검토하고 CI 결과를 별도로 기록한다.

실제 iPhone Safari, 설치형 PWA, 하드웨어 Safe Area 및 VoiceOver 검증은 별도로 필요하다.
브라우저 자동 테스트 통과를 시각적 승인이나 운영 배포 완료로 취급하지 않는다.
