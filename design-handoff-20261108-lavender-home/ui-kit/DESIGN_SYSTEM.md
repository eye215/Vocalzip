# Vocalzip 디자인 시스템 · 플로팅 녹음 기준

## 원칙

기존 홈의 연보라 배경·흰 카드·선명한 보라 포인트를 이어갑니다. 읽는 정보는 남색과 회색, 행동과 선택은 보라색으로 구분합니다. 카드 안에 카드를 중첩하거나 모든 정보를 굵게 처리하지 않습니다. 최근곡은 커버가 없어도 곡명과 작품명만으로 완결됩니다.

## 레이아웃과 카드

390px 화면에서 좌우16px, 전체 카드358px, 두 열은173px씩 사용합니다. 최대폭390px이며 더 넓은 화면에서는 중앙 정렬합니다. 카드 모서리20px·내부20px·간격12px. 355px 이하에서는 내부16px까지 줄일 수 있습니다. 높이는 내용에 따라 늘어나며 최근곡 카드의 기본만 정사각형입니다. 기본 카드에는 진한 그림자와 테두리를 넣지 않습니다.

레슨은108px 이상 연보라 카드, 공연·오디션은 짧은 행. 입력 폼은 빈 칸마다 별도 카드를 만들지 않고 한 시트 안에서16px 간격으로 묶습니다.

## 버튼·입력·리스트

- 기본 버튼52px/R16/16px600. 보조는 연보라 면과 진보라 글자.
- 작은 조작44px/R12/14px600. 시각적으로32px여도 터치 영역44px을 확보합니다.
- 아이콘 버튼44×44px. 제목 아이콘20px, 네비24px, 선1.8px. 제목과 아이콘 색을 맞춥니다.
- 입력 높이48px/R12/패딩12px. 라벨13px600, 도움말12px. 오류는 문장과 색을 함께 사용합니다.
- 체크는20px 이상, 해당 행은44px 이상. 완료는 체크+문장 취소선으로 구분합니다.
- 목록 행72px 기본, 제목15px600+설명12px400. 동일 카드 안에서는 약한 구분선만 사용합니다.
- 빈 상태는 짧은 제목·설명·필요한 행동 하나로 구성합니다.

## 네비와 플로팅 녹음

하단은 홈·내 곡·보관함·일정4개. 흰색78%/블러20px/R999/높이70px, Safe Area를 고려한 하단12px 이상입니다. 메뉴 글자는 아이콘보다 연하게 둡니다.

녹음은 네비 밖의 오른쪽 캡슐입니다. 높이48px·최소너비132px·R24·좌우18px·마이크22px·글자15px600. 135도 #9557FF → #7A32F5 → #6D2BE5, 흰 마이크·글자. 네비 위12px에 고정합니다. 페이지 본문에180px 하단 여백을 두어 마지막 항목을 가리지 않게 합니다. 녹음 화면에서는 플로팅과 하단 네비를 숨겨 중복 행동을 줄입니다.

체크 원에는 그라데이션을 넣지 않습니다. 최근곡은 #F3ECFF → #FCFAFF의 은은한 면으로 표현합니다.

## 상호작용과 접근성

페이지 이동은 해시 경로를 사용하며 뒤로 가기를 지원합니다. 링크는 링크, 실행은 버튼, 완료는 체크박스, 입력은 기본 폼 요소를 사용합니다. 폼 필수값과 연습 시간1~1440분을 검증합니다. 저장 성공은 짧은 안내, 잘못된 입력은 폼을 유지합니다. 포커스 링을 숨기지 않으며 모달은 기본 dialog와 Escape 닫기를 사용합니다. 모션 감소 설정을 존중하고 블러 미지원 시 불투명 면으로 대체합니다.

현재 시안의 변경은 메모리에만 유지합니다. 실제 저장 실패·권한·업로드 진행·오프라인·로딩·삭제 확인은 서비스 연결 시 추가 검수합니다. 영구 삭제·정산·파일 원본 변경은 이 시안에 구현하지 않습니다.
