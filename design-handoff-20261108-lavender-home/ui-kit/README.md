# Vocalzip — 플로팅 녹음 디자인 시스템과 서브페이지

선택한 플로팅 녹음 홈을 기준으로 만든 단일 HTML 프로토타입입니다. **Vocalzip_UI_Kit.html**을 브라우저에서 열면 홈에서 모든 서브페이지로 이동할 수 있습니다. 네트워크 없이도 아이콘과 페이지는 표시되며 Pretendard 웹폰트만 외부 CDN에서 불러옵니다. 폰트가 로드되지 않으면 시스템 서체로 대체합니다.

## 시작

- `Vocalzip_UI_Kit.html`: 모든 화면·CSS·아이콘·JavaScript를 포함한 실행 파일.
- `DESIGN_SYSTEM.md`: 색상·글자·치수·상태·접근성·동작 규칙.
- `SCREEN_MAP.md`: 화면별 목적·진입점·동작·서비스 연결 지점.
- `design-tokens.css`, `subpages.css`, `app.js`: 개발 전달용 원본.
- `approved-home.html`: 확정한 플로팅 홈 원본 보존본.
- `build.py`: 위 소스를 단일 HTML로 만드는 빌드 스크립트. Python 표준 라이브러리와 동봉한 icons.json만 사용합니다.

## 확인 방법

1. 홈에서 내 곡·보관함·일정 탭, 레슨노트·연습기록 카드를 눌러 이동합니다.
2. 오른쪽 위 사람 아이콘 → 내 설정 → 디자인 시스템에서 컴포넌트와 규격을 확인합니다.
3. 곡/파일 검색, 필터, 상세 진입, 일정 달력, 추가 폼, 레슨노트 편집, 목표 체크를 확인합니다.
4. 플로팅 녹음을 누르면 녹음 흐름 시뮬레이션으로 이동합니다. 타이머 시작·일시정지·계속·종료를 확인할 수 있습니다.

## 범위와 데이터

모든 곡·레슨·일정·파일·프로필은 예시 데이터입니다. 변경은 현재 브라우저 문서 메모리에만 보관하며 새로고침하면 초기화됩니다. 실제 로그인·서버·운영 데이터·클라우드·결제·AI는 연결하지 않았습니다. 파일 가져오기는 선택한 이름만 목록에 보여주며 파일 내용의 업로드나 저장은 하지 않습니다. 녹음 시뮬레이션은 마이크를 사용하지 않으며 실제 음성 파일을 만들지 않습니다.

홈의 주간 카드는 사용자가 유지 요청한 180분·목표3시간·100%·6일 연속을 고정한 디자인 예시입니다. 요일별 수치와 이 고정 요약은 서로 합산한 실제 데이터가 아닙니다. 서브페이지 예시 날짜는 2026-11-08 기준이며 홈의 토요일 강조는 사용자 지정 비교 시나리오를 유지합니다.

## 기존 앱과의 관계

기존 `app/views-main.js`, `app/views-lessons.js`, `app/views-more.js`의 곡·레슨·숙제·연습·보관함·일정·성장·설정 구조를 참고했습니다. 이 폴더는 실제 앱 소스를 덮어쓰거나 배포하지 않는 디자인 전달용입니다. 실제 구현 때는 기존 경로·ID·저장·녹음·정산 분리 정책을 재사용해야 합니다.
