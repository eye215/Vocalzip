# 레슨 데이터 연동 계약 (프로젝트 A UI ↔ 프로젝트 B 레슨비 정산)

작성: 2026-11-04 · 대상: `claude/uiux-v6` 브랜치(v6 UI) 기준

## 역할
- 프로젝트 A(UI 개편): 홈·하단 메뉴·녹음·곡·연습·캘린더·레슨 일정, 공통 CSS/JS. `billing/` 폴더는 수정하지 않는다.
- 프로젝트 B(레슨비 정산, Codex): `billing/`, 진입 경로 `/billing/`, 별도 저장소. 레슨 데이터는 **읽기만** 한다.
- A는 `billing/`로 가는 링크만 둔다: 설정 → 메뉴 → "레슨비 정산", 레슨 목록 화면 상단 영수증 아이콘. 상대 경로 `billing/`(커스텀 도메인에서는 `/billing/`, GitHub Pages 하위 경로에서도 동작).

## 저장 위치 (변경 없음)
- localStorage 키 `vocal-zip_mvp_v1` → `lessons` 배열.
- 클라우드: Supabase `vocal_data.payload.lessons`(같은 객체 전체를 upsert).

## 정산 연동 필드
| 정산 이름 | 저장 필드 | 형식 | 비고 |
|---|---|---|---|
| `lesson_id` | `lessons[].id` | 문자열(UUID 또는 v5의 기존 값) | 생성 후 바뀌지 않음 |
| `lesson_date` | `lessons[].date` | `YYYY-MM-DD`(기기 로컬 날짜) | 사용자가 일정 수정으로 바꿀 수 있음 |
| `lesson_status` | `lessons[].status` | `scheduled` \| `done` \| `cancelled` \| **필드 없음** | 아래 규칙 참고 |

v5와 비교해 **필드 이름이나 의미를 바꾼 것은 없다**. `status`는 v6에서 새로 쓰기 시작한 필드다.

## `status` 규칙
- v5에서 만든 레슨에는 `status`가 없다. v6 화면은 이를 "완료"로 **표시만** 하고 저장값은 바꾸지 않는다. 정산은 합의대로 "상태 없음 → 사용자 확인 후 차감"을 적용하면 된다.
- v6가 `status`를 쓰는 경우는 아래뿐이다.
  - 새 레슨 일정 추가: `scheduled`.
  - 레슨 상세에서 사용자가 누를 때: "레슨 완료" → `done`(+`completedAt` ms), "레슨 취소" → `cancelled`, "예정으로 되돌리기"/"취소 철회" → `scheduled`.
  - 일정 수정 시트에서 사용자가 상태를 직접 바꿀 때. 상태 없는 레슨을 수정해도 상태를 바꾸지 않았다면 `status`를 추가하지 않는다(테스트로 고정).
  - 피드백 작성 시 "레슨 완료로 표시" 체크(오늘 이전의 `scheduled` 레슨에서만 노출).
- 날짜가 지나도 자동으로 `done`이 되지 않는다.
- 한 날짜에 여러 레슨이 있을 수 있다.
- `done` → `scheduled`처럼 되돌리는 것도 가능하므로, 정산은 상태 변화(차감 후 취소 등)를 고려해야 한다.

## 정산 쪽에서 알아둘 동작
- **레슨 삭제는 하드 삭제다**(v5와 동일). 레슨 객체가 배열에서 사라지고 숙제·녹음 연결만 정리한다. 정산이 이미 차감한 `lesson_id`가 사라질 수 있다.
- v6는 레슨 객체에 선택 필드를 추가한다: `startTime`, `endTime`(`HH:MM`), `place`, `teacher`, `songIds[]`, `prepMemo`, `songFeedback{}`, `completedAt`, `created`. 정산은 무시해도 된다.
- PR #31 이후 클라우드 동기화는 ID별 병합이다. 같은 레슨의 충돌은 updatedAt이 더 큰 쪽을 사용하고 시각이 같거나 없으면 기기 값을 우선한다. 삭제 표식도 반영한다. 서버 동시 쓰기 버전 검사는 없으므로 여러 기기에서 같은 레슨을 동시에 편집했을 때의 최종 상태는 별도 확인해야 한다.

## 바꾸기 전에 공유할 것
프로젝트 A가 아래를 바꿀 때는 먼저 이 문서를 갱신하고 공유한다.
- `id`·`date`·`status`의 이름, 형식, 값 목록.
- 레슨 삭제 방식(하드 → 소프트 삭제 등).
- `vocal-zip_mvp_v1` 키 또는 `lessons` 배열 위치.
