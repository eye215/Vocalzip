# 승인 학생 홈 구현 — 검토 상태

기준: main 27ca50caafa82b4ce866e048b68de0a3893a55c6, 시안 PR #127, 개발 이슈 #126.

- DS #120의 tokens/components를 가져와 승인 스코프를 확장. #122의 단일 레슨 파일럿은 통합 일정 카드로 이어가되 다른 작업 브랜치는 수정하지 않는다.
- 실제 홈은 독립 ES module adapter로 기존 라우터/레슨 상세/연습 기록 sheet/미디어 player를 연결한다. 별도 프리뷰와 같은 컴포넌트 사용.
- 최근곡/공연/예정 레슨은 기존 ID 참조, 날짜는 로컬 달력. 시안 인물·곡명·날짜·분수는 서비스에 저장하지 않는다.
- 목표만 dailyGoals[] / practicePlans[] 추가 배열로 저장. 기존 core의 변경 이력과 data-merge ID/tombstone 병합에 추가했다. goal check는 숙제 원본/실제 수행시간/정산을 바꾸지 않는다.
- 홈의 실제 연습시간은 manualMinutes 우선, 없으면 legacy minutes. 녹음 길이를 더하지 않는다. 기존 성장 화면 전체 집계 정책 변경은 별도 작업이다.
- 일반 v6 fixture는 기존 UI 계약으로 검증하고, 신규 홈 전용 QA는 새 UI를 활성화하여 실제 체크 저장/실패 복원/이동/900개·긴 텍스트/모바일을 검증한다. 신규 계정 세션 테스트도 실제 새 홈 로드에 대한 회귀를 포함한다.
- 목표/일별·주별 시간은 사용자가 명시 저장한 값만 사용. 미설정과 0분을 구분하며 100~120% 포함 중간색, 120초과 진한색, 오늘은 별도 표시한다.

검증 결과는 구현 PR/Actions에서 기록한다. iPhone Safari·설치형 PWA·실제 safe area·VoiceOver는 미검증이다. 전후 이미지에는 synthetic fixture만 쓴다. 원본 UI와 같은 가짜 데이터/시계로 비교한다.

이 변경으로 서버 revision/필드 초안/lease를 구현하거나 운영 DB를 변경하지 않았다. 신규 목표 데이터도 현재 JSON 동기화의 동일 레코드 LWW 한계를 가지며, 오래된 앱과 혼용한 동시 편집은 출시 전 추가 검증이 필요하다.

인계 지시서의 별도 요청 원칙에 따라 이번에는 구현 PR/검토용 스크린샷까지 준비하며 병합·서비스 배포는 수행하지 않는다. 시각적 동일성과 실기기 완료를 자동 테스트만으로 주장하지 않는다.
