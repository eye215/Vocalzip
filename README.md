# VOCAL.zip

레슨 피드백·숙제와 개인 연습, 음성·영상 파일을 연결해 기록하는 모바일 우선 웹앱입니다.

- 서비스: https://vocalzip.yullul.com/
- 인수인계: [개발 인수인계](docs/VOCALzip_Codex_인수인계_2026-11-03.md)
- 변경·검증 범위: [UI/UX 개편 검증](docs/UIUX_개편_검증.md)

## 화면과 사용 흐름

홈에서 연습 또는 레슨 작성을 시작합니다. 레슨과 연습 탭은 기록 목록과 작성 폼으로 나뉘며, 탭을 이동해도 작성 중 입력을 유지합니다. 새로고침까지 임시 작성 내용을 보존하는 기능은 아직 보장하지 않습니다.

연습 폼에서 음성 녹음·영상 녹화 또는 파일 가져오기를 하면 원본을 기기에 저장하고 이번 연습에 연결합니다. 보관함에 있는 기기·클라우드 파일도 선택할 수 있습니다. 같은 파일은 한 번만 연결하고 시간을 합산합니다. 파일 길이를 읽을 수 없으면 연습 시간을 직접 입력합니다.

녹음 저장에 실패하면 원본을 메모리에 유지하며 다시 저장하거나 다운로드할 수 있습니다. 페이지를 닫으면 이 임시 원본은 사라질 수 있습니다. 연습 기록을 삭제해도 보관함 원본은 남습니다. 보관함에서 파일을 영구 삭제하면 연결된 기록에서도 재생할 수 없습니다.

보관함에서는 출처·음성/영상 필터, 재생, 정보 수정, 파일 비교를 제공합니다. 성장 화면에서는 주간 기록과 비교 리포트를 확인합니다. 현재 AI는 기록·메모를 이용한 분석이며 음정·호흡·비브라토의 실제 오디오 분석 완료를 의미하지 않습니다.

## 저장과 클라우드

- 기록: localStorage의 `vocal-zip_mvp_v1`.
- 미디어: IndexedDB의 `vocalzip_media_v1` / `recordings`.
- 연습의 `mediaIds`가 파일 ID를 참조합니다. 기존 Blob과 ArrayBuffer 형식 모두 읽습니다.
- 로그인 후 설정 → 계정·클라우드에서 기록 업로드 또는 가져오기로 최초 연결을 선택합니다. 이후 연결 계정의 기록 변경·새 미디어 저장에 자동 업로드를 시도합니다.
- 기존 기기 파일 전체는 ‘녹음·영상 클라우드 백업’으로 별도 백업합니다. 클라우드에만 있는 파일은 스트리밍으로 재생하며 연습에 연결할 수 있습니다.
- 보관함의 로그인 상태 파일 가져오기는 재개 가능한 클라우드 직접 업로드를 사용하며 현재 파일당 100MB로 제한합니다.
- JSON 내보내기는 기록 백업입니다. 음성·영상 원본이 포함되지 않습니다. 브라우저 데이터 삭제 전에 미디어 클라우드 백업 성공 여부를 별도로 확인하세요.

## 개발과 검사

빌드 과정이 없는 정적 HTML/CSS/JavaScript 앱입니다. HTTPS 또는 localhost에서 실행해야 녹음 권한을 사용할 수 있습니다.

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

별도 터미널에서 검사를 실행합니다.

```sh
npm install --ignore-scripts
npx playwright install --with-deps chromium webkit
npm run test:syntax
npm run test:ui
```

GitHub Actions의 UI checks도 같은 검사를 실행하고 HTML 보고서·화면 캡처를 보관합니다. Playwright는 인증·클라우드 SDK를 대역으로 바꾸고 실제 Supabase 요청을 차단합니다. Chromium 녹음·녹화는 가상 장치를 사용합니다. Linux WebKit에서는 MediaRecorder 미지원 검사를 제외합니다. 이 결과는 실제 iPhone Safari나 실제 계정 동기화 검증을 대신하지 않습니다.

실기기에서는 로그인 → 연습 음성/영상 녹음 → 저장 → 기록 상세/보관함 재생 → 재접속을 반복하고, 실제 .m4a/.mov 가져오기, 권한 거부, 저장 공간 부족, 업로드 실패 재시도, 다른 기기 동기화를 별도 확인해야 합니다.

## 배포

GitHub Pages에서 `main` 브랜치 루트를 배포하는 저장소입니다. PR의 변경은 main 병합 전까지 서비스에 반영되지 않습니다. 병합 후 Pages 배포 결과와 실제 사이트의 버전·스크립트 로드를 확인하세요. 공개 프런트엔드에는 Supabase service-role 키나 외부 AI 비밀키를 넣지 않습니다. AI 서버 설정은 Edge Function에서 관리합니다.
