# 정산에서 시작하는 레슨 선택 삭제

## 범위

DELETE-21-01-B, Phase 10/21. 레슨 쪽 선택 삭제(#196)의 반대 진입을 기존 정산 화면에 연결한다. 공통 디자인·녹음/업로드 엔진·결제/환불 데이터 구조와 운영 DB는 변경하지 않는다.

- 수강 내역의 삭제: 연결 레슨 동시 삭제는 기본 미선택이다. 날짜 대신 레슨 ID와 차감 ID로 대상을 확인한다.
- 연결 레슨을 선택하면 실제 레슨 상세에서 녹음 선택과 최종 영구 삭제를 재확인한다. 이 확인 전에는 차감을 취소하지 않는다. 정산에서 명시한 차감만 미리 선택되며 녹음은 모두 미선택이다.
- 선택한 차감 ID/버전이 달라졌거나 여러 레슨에 연결돼 있으면 자동으로 대상을 고르지 않는다.
- 차감만 삭제하면 원본 레슨·녹음·같은 날의 다른 차감·결제·환불을 유지한다. 잔여 횟수를 반환하고 최소 거래 감사 이력과 복구 방지 식별자를 보존한다.
- 영구 취소한 차감의 복구/과거 백업 복원을 차단하고, 레슨을 남긴 경우 자동 차감이 다시 생성되지 않도록 한다. 기존 임시 차감 복구 정책과 신규 영구 삭제를 구분한다.
- 로그인 계정은 서버 보호 계약과 소유한 레슨 목록을 조회한다. 클라우드 저장 확인 전에는 서버 완료를 표시하지 않는다. 실패한 취소는 기기에 남기고 기존 동기화로 재시도한다.
- 레슨 삭제 중 중단되면 기존 단계별 재시도와 계정/내용 검증을 사용한다. 완료 후 정산으로 돌아온다. 삭제 요청 쿼리는 첫 진입 때 소비하며 새로고침으로 자동 재실행하지 않는다.

## 남은 범위

결제·환불·레슨권·수동 조정의 일반 삭제/복구 정책 전환과 기존 데이터 소급 정리는 이번 범위 밖이다. 실제 거래 감사 보존 범위부터 별도 확정한다. iPhone Safari/PWA 실기기 검증은 수행하지 않았다. 기존 고객 기록/미디어를 삭제하는 검증은 하지 않는다.
