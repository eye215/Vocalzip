# 레슨에서 시작하는 선택 삭제 — Phase 10/21

DELETE-21-01-A · PR #196

## 적용 동작

- 레슨 삭제에서 연결 녹음별 영구 삭제 및 연결 차감 취소를 각각 선택한다. 기본값은 모두 해제다.
- 삭제 대상·다른 기록에서 사용하는 파일·보존 대상을 안내한 뒤 복구 불가 최종 확인을 받는다. 숙제·연습 기록·곡과 미선택 파일/차감은 보존한다.
- 실행 전 계정별 작업 ID, 대상 ID, 단계 완료 상태와 SHA-256 검증값을 기기에 저장한다. 피드백·메모·녹음 원본을 작업 기록에 복제하지 않는다. 작업 완료 후 작업 기록을 제거한다.
- 차감 취소 확인 → 선택 파일 삭제 → 클라우드 레슨 CAS 삭제 → 기기 레슨 삭제 순서로 처리한다. 로그인 계정이면 차감 취소의 클라우드 ack 확인 전 다음 단계로 넘어가지 않는다.
- 시간 초과/중간 실패는 미완료 삭제로 남고 사용자 재시도 때 확인했던 대상의 남은 단계만 처리한다. 페이지 시작/로그인만으로 삭제를 자동 실행하지 않는다.
- 계정 전환·레슨 내용 변경·원장 버전/참조 충돌은 중단한다. 사용자별 Web Locks와 기존 IndexedDB 거래 및 서버 CAS를 재사용한다.
- 실제 결제·환불과 같은 날짜의 별도 차감은 유지한다. 차감은 작업 ID로 한 번만 반환하며 재요청은 같은 결과다. 차감 취소는 금전 환불이 아니다.
- 새로운 삭제에 따른 취소는 복구 버튼을 제공하지 않는다. 업그레이드된 클라이언트의 기기별 최소 방지 기록은 기기 정산 초기화 후에도 남아 과거 백업/버전으로 해당 차감을 다시 활성화하지 못하게 한다. 이 기록은 ID/작업 ID만 저장한다.
- 레슨 삭제 표식을 5,000개에서 자르지 않으며, 오래된 숙제의 레슨 링크도 병합 시 해제한다. 정산에서 수동 가져온 레슨은 차감을 보존해도 자동으로 새 ID로 재생성하지 않는다.

## 검증

단위: 선택/미선택, 타 계정·경합, 저장 공간 실패, 응답 유실·단계 재시도, 검증값/작업 기록의 개인정보 비포함, 5,000개 이상 삭제 표식, 서버 CAS·참조 정리, 결제/환불 불변 및 복구 방지.

브라우저: 모바일 Chromium/WebKit·데스크톱에서 실제 선택·최종 확인, 미선택 원장/파일 보존, 차감 응답 유실 후 한 번만 반환, 파일 부분 실패 후 새로고침 재시도, 확인 중 레슨 변경, 정산 클라우드 ack 실패 및 과거 백업 방지. 실제 실행 수치와 배포 파일 대조는 PR #196/Actions에 기록한다. 실기기 iPhone 성공으로 표시하지 않는다.

## 경계와 후속 작업

- 운영 DB 마이그레이션·기존 사용자 기록 정리·실제 미디어 이동은 하지 않는다. 기존 R2 및 Supabase 삭제 API·권한·CAS를 재사용한다. 실제 삭제는 사용자가 앱에서 대상을 선택하고 최종 확인한 경우에만 실행된다.
- 여러 저장소를 단일 트랜잭션으로 묶은 구조가 아니다. 이미 삭제한 파일을 되돌리지는 않는다. 한 기기의 미완료 작업은 그 기기에서 재시도하며 다른 기기로 작업 인계까지 제공하지 않는다.
- 서버 CAS는 이미 서버에 반영된 레슨 내용과 비교한다. 같은 필드의 미수신 오프라인 변경 및 구형 클라이언트/서버 관리도구가 삭제 표식을 버리고 덮어쓰는 경우까지 보장하지 않는다. 서버 독립 삭제 원장과 구형 클라이언트 차단 계약은 별도 출시 관문이다.
- **정산 화면에서 시작하는 역방향 레슨 선택 삭제**, 기존 정산의 일반 삭제 내역/복구 정책 정리 및 iPhone 실기기 검증은 후속 작업이다. Phase 10/21 전체 완료로 표시하지 않는다.
