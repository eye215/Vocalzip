# 원본 시안 재검수 기준
기준은 PR #132 맨 위의 final-approved.jpeg이며 기존 구현 캡처는 승인된 디자인이 아니다.

- 709×1536 원본을 390px 폭으로 환산한 수동 측정값(±1~3px)을 우선한다.
- 카드 x≈13, 폭≈365, 간격≈6. 무대 y108/h153, 목표 y267/h150, 주간 y423/h152.
- 최근곡 x13/y581/w179/h156: 실제 원본 외곽은 약1.15:1이다. 과거 문서의1:1과 충돌하며 이번 원본 충실도 요청에 따라1.15를 사용한다.
- 목표 목록은 사용자가 명시 선택한44px 행 터치를 유지한다. 원본의 약29px 행간과 다른 부분이며 내부 스크롤로 처리한다. 보이는 체크는 약19px.
- 주간 꽃은 둥근8엽, 약32px의 실제 glyph, 체크14×10/약3px stroke. 오늘 이중 윤곽 약40px. 달성률과 오늘 상태의 의미는 바꾸지 않는다.
- 중앙 녹음만 구체, 약56px. 나머지 아이콘은 평면 채움형, 약20/24/25px의 용도별 크기와 옅은 보라색 변화. 돌출 그림자 금지.
- approved-reference.jpeg는 원본 Git blob80cf84ea928a72bea96199a5bdc79ee7d0e361bf를 그대로 재사용한다. 이미지를 새로 생성하거나 편집하지 않는다.
- CSS sprite로 무대 오른쪽의 텍스트 없는 x505/y250/w150/h150 영역과 커버 x110/y1128/w160/h126 영역만 보여준다. 전체 UI 이미지를 배경으로 쓰지 않는다.
- 전체 무대 장식에는 D-12 글자가 겹쳐 있어 전체 사각 crop을 사용하지 않는다. 오른쪽 장식만 재사용하는 한계가 있다.
- 커버의 원본 흰 재생 도형은 실제 재생 가능한 파일이 있을 때만 표시한다. 원본 중복 도형을 만들지 않으며 실제 ID의 플레이어를 그대로 사용한다.
- 기존 일정 없음 숨김·저장·체크·실패 복원·실제 연습 시간·계정/데이터 계약 유지.
- 원본 픽셀 색 분석과390px 실제 캡처의 geometry를 CI에 기록. 프리뷰 최근곡과 독이 최소6px 떨어져야 한다.
- 검토용 Draft. 실제 iPhone/PWA/VoiceOver 검증 및 사용자 시각 검수 전 추가 배포하지 않는다.
