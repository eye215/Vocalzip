# 업로드 준비 대기·R2 전송 개선 (2026-11-09)

## 변경

- 자동 가져오기 검사 창 250개 → 4개. 첫 전송을 나머지 전체 파일 검사 뒤로 미루지 않는다.
- 같은 File 객체에서 파서가 확인한 음원 메타데이터와 길이를 메모리에서 재사용한다. 다른 File·영상·읽기 실패·검증이 필요한 WAV→FLAC은 기존 준비 경로를 사용한다.
- 원본 음원은 같은 File을 그대로 전송한다. 영상의 음성 패킷 검증과 Chromium WAV→FLAC 샘플 검증을 생략하지 않는다.
- 자동 업로드 준비 중에도 배경 백업을 대기시켜 경쟁을 줄인다.
- R2 v1 동시 전송은 최대 4×8MiB, 데이터 절약/느린 회선/2GB 이하 기기는 2개 유지. 취소·인증 만료 시 모든 전송을 멈춘 뒤 정리한다.
- 보관함 행 확인과 완료 영수증 복구, 기존 ID/날짜/곡 연결 계약은 유지한다. UI/CSS·운영 DB·Worker·미디어 자체를 수정하지 않는다.
- v2 이어올리기 플래그는 계속 비활성이다.
