# 플로팅 녹음 홈 — 최신 선택안

기준 파일: [Vocalzip_Floating_Record_Home.html](Vocalzip_Floating_Record_Home.html). 사용자가 생성 이미지 세 가지 중 3번을 선택했고 HTML로 확인한 뒤 이 파일의 GitHub 업로드를 요청했습니다.

## 배치

- 하단 네비: 홈 / 내 곡 / 보관함 / 일정 4개. 녹음 탭 제거.
- 녹음: 마이크 + '녹음 시작' 캡슐. 높이48px, 최소너비132px, 모서리24px.
- 배경: 135도 #9557FF → #7A32F5 → #6D2BE5. 흰색 글자·아이콘.
- 스크롤 시 고정: 네비 위12px, 홈 콘텐츠 오른쪽 끝에 정렬.
- 네비 높이70px. 화면 하단 최소12px 또는 safe-area inset 반영.
- 마지막 콘텐츠를 끝까지 올릴 수 있게 본문 하단180px 여백 확보.
- 녹음 버튼은 정적 HTML 요소이며 표시를 위해 JavaScript 실행을 요구하지 않음. SVG 아이콘도 내장.

## 유지한 내용

180분·목표3시간·달성률100%·6일 연속, 기존 일정·최근곡·퀵메뉴·목표 카드 유지. 주간 원은 달성률에 따라 연보라/기본보라/진보라, 현재 요일은 요일명 유지+보라 글자+바깥 링. 요일 아래 작은 분 표시. 최근곡 카드에 은은한 그라데이션.

시안의 주간 요약과 요일 수치는 디자인 비교용 예시이며 서로 합산한 실계정 데이터가 아닙니다. 실제 구현에서는 사용자 기록과 목표에서 계산해야 합니다.
