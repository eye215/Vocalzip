# 홈 시선 위계 및 아이콘 정돈

## 최신 사용자 요구

연보라 #f6f4fb, 흰 카드, Pretendard 400/600/700과 기존 카드 규격을 유지한다.
인사말을 제거하고 짧은 앱 헤더를 구분선·여백으로 일정 영역과 분리한다.

## 최상단 일정

- 일정은 카드 없이 배경에 노출한다.
- 남은 일수가 가장 적은 일정 한 개만 22px 제목·14px 일시·상세 링크로 강조한다.
- 같은 날이면 둘 다 유효한 24시간제 시각이 있을 때 시각으로 비교하고, 그 외는 입력 순서를 유지한다.
- 날짜가 미정이면 유효한 일정 뒤로 둔다. 완료/취소 등 조회 정책과 DB를 변경하지 않는다.
- 나머지 일정은 15px 제목과 13px 일시의 짧은 행으로 표시하고 장식 그림·반복 링크를 제거한다.
- 일정 간 간격20px. 목록을 정렬할 때 원본 입력을 변경하지 않는다.
- 분류+D-day → 제목 → 날짜를 묶는다. 주인공의 그림은 이 정보 묶음과 수직 중앙 정렬한다.

공연·레슨 / 공연·오디션 / 모두 / 레슨만 / 없음과 함께 ‘오디션이 가장 가까운 경우’를 추가했다.
복수 일정은 기존 시안 입력 계약을 유지하며 실제 복수 조회·분류 개발 완료로 표시하지 않는다.

## 시선의 강약

- 이번 주 실제 분 수치는 32px/700으로 키운다. 목표·달성률·연속일은12px 회색 보조 정보로 낮춘다.
- 최근곡은 곡명·작품명을 먼저 배치하고 하단에 ‘이어 듣기’와45px 연보라 재생을 한 버튼으로 묶는다. 키보드와 터치 모두 기존 재생 동작을 사용한다. 음원이 없으면 곡 상세로 이동한다.
- 오늘의 목표는 문장을 #344054로 읽히게 하고 출처는12px #818DA2로 낮춘다. 완료 개수도 회색으로 둔다.
- ‘설정’ 글자 버튼을18px 선형 설정 아이콘과44px 터치 영역으로 교체한다.

## 색과 아이콘

채도를 올린 보라색 #6326FF를 녹음·선택·완료에 사용한다. 눌림 #4E1BCC, 연한 면 #F1EAFF. 연한 면 위 글자·아이콘은 #4E1BCC, 메인 버튼 위는 #FFFFFF로 지정한다. 링크·D-day·완료 체크·선택 아이콘도 #6326FF로 통일한다.
일반 본문·조작 아이콘은 회색을 유지한다. 재생은 연한 면+진한 아이콘, 녹음은 진한 면+흰 마이크로 구분한다.

상단 가면·마이크·노트는 동일96 viewBox·동일 연보라 면·유사한 채움 면적과 디테일의 부드러운 일러스트로 다시 구성한다.
그림의 광학 영역을 보정하고, 조작용 SVG와 분리한다. 실제 포스터 참조는 유지한다.

조작용 아이콘은24 viewBox, stroke1.8, 같은 둥근 끝/접합으로 통일한다.
제목20px, 퀵메뉴22px, 내비24px, 화살표14px, 설정18px. 선 굵기는 non-scaling-stroke로 유지한다.
내비게이션은 기본 선형, 선택 시 채움형. 메뉴명 #667085는 아이콘 #475467보다 연하게 둔다.
중앙 녹음은 흰24px 마이크와 진한 보라 원형으로 유지한다.
공유 내비의 아이콘 규칙은 홈에서 다른 페이지로 이동한 뒤에도 유지하며, 해당 페이지의 레이아웃은 재작성하지 않는다.

## 검증

검증 대상은 일정별 강조/요약 개수와 가장 가까운 종류, 시각 동률 정렬, 원본 입력 보존, 기본/선택 아이콘 표현, 재생과 녹음 색 구분, 실제 글자 스타일과 기존 저장·재생·이동이다.
긴 제목·200% 글자·320/390/430px·일정 없음의 기존 검증을 유지한다.
실행 결과·실제 렌더링은 PR #135에 기록한다. 실기기/PWA/VoiceOver 검증과 운영 배포는 포함하지 않는다.

## 장식과 정보 색상 정리

꽃 모양·그라데이션·달성률별 다색 스탬프를 제거하고20px 원+체크로 대체한다. 목표 이상은 모두 #6326FF, 진행 중은 #F1EAFF, 미래는 연한 테두리다. 오늘은 바깥 링으로 별도 표시한다. 목표 미설정은 완료로 오인하지 않게 체크하지 않는다. 기존 실제 시간과 달성률 접근성 설명은 유지한다.

카드 제목 #101828/600, 곡명·주요 숫자·강조 본문 #344054, 일반 본문·보조 버튼 #475467, 날짜·설명 #667085, 가장 약한 정보 #818DA2. 제목 옆 선형 아이콘도 제목 색으로 연결한다. 인사말은 복원하지 않는다.

퀵메뉴는 아이콘+문구를8px 간격의 한 그룹으로 만들고 작은 연한 화살표를 분리한다. 최근곡 하단의 텍스트와 원형 재생은 하나의 버튼으로 동작하여 중첩 버튼을 만들지 않는다. 큰 글자에서는 문구 줄바꿈을 허용한다.

하단 여백은140px+Safe Area로 확보한다. 200% 글자·320/390/430px에서 내부 목표 목록과 문서 끝까지 스크롤 후 마지막 행이 하단 내비 위로12px 이상 올라오는지 검증한다. 초기 스크롤 위치의 고정 내비가 화면 아래 콘텐츠와 만나는 현상을 숨기지 않고, 끝까지 스크롤한 증거도 별도로 남긴다.
