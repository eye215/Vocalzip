# 영상만 압축 · 음성 패킷 원본 유지
- 명시적 선택 옵션: 720p(최대 1280×720 또는 720×1280), 최대 24fps, 영상 H.264 목표 1.2Mbps.
- 오디오 디코더/인코더를 사용하지 않는다. EncodedAudioPacketSource로 모든 오디오 트랙의 패킷을 복사한다.
- 변환 후 원본/출력의 모든 음성 패킷 바이트, 패킷 수, 코덱, 샘플레이트, 채널 수 및 타이밍을 비교한다. 다르면 업로드하지 않는다.
- 전용 Worker, OPFS 임시 파일, 4MiB 입력 캐시, 1MiB 쓰기 버퍼, 1초 단위 영상/음성 공급으로 전체 원본/출력을 메모리 배열로 만들지 않는다.
- Mediabunny 1.65.1 고정 버전(MPL-2.0, https://github.com/Vanilagy/mediabunny)을 CDN에서 선택 시 로드한다.
- 원본 파일은 수정/삭제하지 않는다. 출력이 더 크거나 원본 음성 복사가 불가능하면 실패를 표시하고 명시적으로 원본 업로드를 선택할 수 있다.
- 실패한 전송 재시도는 검증된 압축 파일을 재사용한다. 성공·새 선택·페이지 종료 시 임시 파일을 정리한다.
- WebCodecs와 Worker의 OPFS SyncAccessHandle이 필요하다. 지원하지 않는 브라우저/코덱은 원본 경로만 제공한다.
- 압축 처리 시간·발열·배터리 소모가 추가된다. 네트워크 전송 시간 단축과 전체 소요 시간 단축은 다르다.
- 실제 iPhone 200MB MOV/HEVC, 메모리/발열/백그라운드는 미검증. 자동 검사는 AAC MP4와 201MiB MP4(표준 free atom 패딩) fixture를 사용한다.
