# VOCAL.zip 🎤

보컬 레슨, 숙제, 개인 연습, 녹음·영상 기록과 성장 분석을 위한 웹앱.

## 기능 계획
- 레슨 피드백과 2Depth 연습 항목 관리
- 숙제 목록과 날짜별 수행 이력
- 개인 연습일지·곡별 기록·만족도
- 직접 녹음/녹화, 이전 기록 비교
- 사용자가 선택한 항목만 AI 분석 (향후)

## 배포 방법
앱 HTML 파일을 `index.html`로 이름 변경해 저장소 루트에 업로드한 뒤 GitHub Settings → Pages에서 `main` / `/ (root)`를 선택합니다.

> 공개 저장소에는 개인 녹음·영상, 레슨 개인정보, API 키를 올리지 마세요.
