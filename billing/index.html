기존 레슨권 정산 보기 (참고)

차감은 0.01회 단위, 금액은 원 단위입니다. 사용 금액은 레슨권별 합산 후 반올림합니다. 환불은 순결제금액에 반영하며, 레슨권 금액·횟수 변경은 별도 수동 조정으로 기록합니다.

레슨권

결제·분할 결제·환불

분할 결제는 같은 레슨권으로 각각 등록하세요. 환불은 원래 결제를 지우지 않고 별도 거래로 남깁니다.

수강과 차감

기존 Lesson ID는 읽기만 합니다. 날짜만 있는 과거 수강도 별도 이력으로 남길 수 있습니다. 잘못 추가한 수강은 목록의 삭제 버튼으로 지울 수 있어요. 삭제하면 차감 횟수도 정산에서 제외됩니다.

잔액·횟수 수동 조정

조정은 별도 거래입니다. 조정 후 레슨권 금액 ÷ 충전 횟수로 단가와 과거 사용 금액을 다시 계산합니다. 사유를 남기고 미리보기를 확인하세요.

CSV · XLSX · 노션 CSV 가져오기

파일

선택한 파일 없음 · 파일당 10MB · 합쳐서 최대 2,000행

레슨권 이름은 날짜 표기가 달라도 같은 날짜면 연결합니다. 수강 CSV의 ‘레슨권 결제일’(결제일·결제날짜·충전일) 열을 매핑하면 해당 결제일의 레슨권이 하나일 때 연결합니다. 후보가 여러 개이면 행별로 선택하세요. 레슨 날짜만으로는 연결하지 않으며 레슨권 열이 없으면 ‘기본 연결 레슨권’을 먼저 고르세요. 같은 날짜의 여러 수강은 허용합니다. 날짜만으로 자동 중복 처리하지 않습니다. 분할 결제는 새 레슨권을 여러 개 만들지 말고 기존 레슨권에 연결하세요. 파일의 수강생 열은 출처 정보로 보존되며 다른 계정으로 전송되지 않습니다.

등록할 행 확인

업로드 이력

업로드한 내역 삭제는 해당 작업에서 만든 기록을 목록과 정산에서 제외합니다. 업로드 후 수정한 항목은 결제·수강 목록에서 개별 삭제하세요. 삭제 내역 보기에서 이력을 확인하고 개별 기록을 복구할 수 있어요.

변경 이력

결제 수정, 차감 변경·취소·복구, 수동 조정의 변경 전후 값을 보존합니다.

백업·동기화

정산 기록은 어디에 저장되나요?

정산 기록은 먼저 이 기기에 저장돼요. 백업·동기화에서 JSON 복원과 계정별 클라우드 저장을 사용할 수 있어요. 클라우드 전송은 직접 실행하며, 기존 레슨·녹음·연습 기록은 바꾸지 않아요.

정산 전체 삭제
