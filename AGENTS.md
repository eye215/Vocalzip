# Vocalzip UI changes

Before changing UI, read `docs/design/VOCALZIP_DESIGN_SYSTEM_2026-11-09.md` and reuse its approved component rules.

When the user asks to match, unify, or reuse another screen/component, record the approved reference, scope, dimensions, colors, and state behavior in that guide in the same PR as the implementation. Update superseded rules and the change log. These decisions are shared defaults for future screens, not isolated screen overrides.

Preserve existing user data and functional behavior during visual changes. Report verification and deployment status accurately in the PR.
