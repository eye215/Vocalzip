# 소리 길 흔적 보류 복구 · 긴 녹음 구간 분석 (2026-11-17)

기준 main: `f4197173ccacb90069230e7930b162e014393473`. 브랜치: `codex/voice-path-recovery`. 이 문서는 해당 PR의 구현·합성 데이터 검사이며 운영 반영 또는 실제 iPhone 인수를 뜻하지 않는다.

## 재현과 변경

- 기존 화면은 목소리 검출 일관성 부족·잦은 도약 등 모든 실패를 “반주가 목소리만큼 크게”라는 하나의 문구로 설명했다. 검출 사유별 문구와 실제 일관성/기준을 표시한다. 통과 문턱·분석 알고리즘·캐시 버전은 유지한다. 백분율은 소수 첫 자리 아래를 버려 기준 바로 아래 값이 통과 기준처럼 보이지 않게 한다.
- 서버 AI 분리 후 저장된 신뢰도 높은 분석이 있어도 원본 혼합 음원 재측정은 별도로 보류될 수 있다. 두 경우를 구분해 `저장된 보컬 분석` 표에 실제 저장값과 측정 방법만 표시한다. 한쪽의 신뢰도가 낮으면 그쪽은 보류, 누락 수치는 `—`이다. 기존 원본의 소리 길·끊김·울림·숨소리 비교는 보류를 유지하고 실력 판정을 만들지 않는다.
- 서버 분리 worker는 분리 음원 파일이 아닌 측정 요약을 저장한다. 요약만으로 원본 PCM을 깨끗한 음원처럼 취급하지 않는다. 분리 음원의 지속 보관/재사용은 이 PR의 구현 범위가 아니다.
- 실패 녹음에서 `구간을 골라 정밀 분석`으로 해당 녹음과 최초 최대60초 범위를 지정해 이동한다. 기존 리포트가 있어도 입력 폼이 열린다. 연결한 녹음이 없으면 다시 선택하도록 안내하며 다른 녹음을 몰래 고르지 않는다. 목소리 전용 확인은 자동 선택하지 않는다.
- 4–5분 원본을 정밀 분석에서 무조건 거절하던180초 제한을 metadata/실제600초(10분)로 확장한다. 원본25MiB 이하, decoded 모노/스테레오·80MiB 이하, 명시 구간60초 이하, 전체90초 중단 한도를 적용한다. 실제4분8초 합성 WAV의120–122초만 worker/실제 엔진에 전달하는 것을 확인했다.
- 완료된 읽기/decode의 취소 감시를 해제해 원본 버퍼를 worker 종료까지 붙잡지 않는다. 공통 파일 읽기 모듈을 재사용해 로컬 우선, 만료된 연결 갱신, 유휴 연결 중단, 크기 제한, 취소를 유지한다. 기존 녹음·analysis·history를 쓰지 않으며 새 정밀 결과만 기존 append-only 기기 보관함에 추가한다. 자동 일괄 재분석·유료 API는 실행하지 않는다.

## 검사

메모리 수명 검사에서도 완료된 취소 감시가2개 남는 실패(3개 대1개)를 확인한 뒤 정리했다. 문제별 테스트를 먼저 추가했고180초 제한에서 긴 녹음/사전 구간 검증/실제 소스 경계 검사3개가 실패함을 main에서 확인했다. 수정 전 화면도 같은 합성 AI 측정 이력으로 잘못된 경고와 수치 누락을 재현했다.

- Node74개 통과: 기존 음정/소리 길, 새 거절 사유, 긴 입력 브리지, 정밀 음향/전환/공명/리포트/결합 모델.
- Chromium 모바일: 소리 길·MR 재분석·정밀 리포트39개 통과, 별도 조건 전용5개 제외(태블릿·선택 실행 캡처/성능·독립 모듈 부재).
- JavaScript 구문 검사·공백 검사 통과.
- 최초 전체 브라우저 실행에서 화면 진입2개/중단1개가 시간 초과 및 기존 비동기 모듈 오류로 실패했다. 같은 소스의 해당3개를 개별 재검사해 통과했고, 최종 전체 실행도 통과했다. 실패를 삭제하거나 테스트를 완화하지 않았다.
- 운영 녹음·인증·DB·AI provider 호출은 검사하지 않았다. 캡처와 오디오는 모두 가짜 데이터다.

## 남은 한계

전체 압축 파일을 브라우저에서 decode한 뒤 선택 구간만 분석한다. streaming 또는 서버의 긴 파일 분석을 구현한 것이 아니며, 오래된 iPhone의 메모리·발열·Safari/PWA 실기기는 검증하지 않았다. 원본 다운로드 속도와 실제 MR 일치 여부를 보장하지 않는다. 혼합 음원의 과학적 신뢰도 기준을 완화하거나 합성 테스트를 실제 사람 음성의 정확도 증명으로 해석하지 않는다. 정밀 AI 서버 배포·비용 활성화와 자동 기존 녹음 분석은 수행하지 않는다.
