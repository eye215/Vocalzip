# 악보 필기 선택·편집 — 2026-11-10

태블릿+Apple Pencil을 주 입력, iPhone을 보조 열람 기기로 한다. 기존 개인 필기 모델과 계정별 복구 저장소를 재사용하며 서버·DB·R2 원본은 변경하지 않는다.

- 선택: 탭으로 가장 위 한 획, 사각형과 실제 선분의 교차로 여러 획 선택. PDF의 원래 인쇄 내용은 선택 대상이 아니다.
- 이동: 선택 범위 안 드래그. 크기: 오른쪽 아래 손잡이 또는 44px 확대/축소 버튼. 가로세로 비율·굵기를 함께 변경한다.
- 입력: 펜만 설정에서는 Pencil 선택/조절, 손가락 이동/확대. 조절 중 손바닥 입력 무시. pointercancel은 미리보기만 취소한다.
- 저장: 원래 획을 수정하지 않고 새 UUID의 획 추가와 원래 ID의 삭제 마커를 한 작업으로 기록한다. 압력·색·투명도·원본 연결을 보존한다. 여러 획이 한 번에 되돌아간다.
- 보호: 선택한 원본이 달라지면 재선택. 쓰기 실패는 복구 저장소와 미완료 작업을 남기며 다시 저장을 제공한다. 기존 사용자·PDF 해시·페이지 격리를 유지한다.
- 내보내기: 저장한 변환 결과를 필기 PDF 사본에 포함한다. 원본 PDF와 녹음·레슨·연습은 변경하지 않는다.
- 제한: 자유 올가미·회전·텍스트·도형·다중 페이지 선택·대형 노트북용 별도 저장 구조는 이번 범위 밖이다. 기존 계정별 2MiB 복구 저장 한도를 늘렸다고 표시하지 않는다.

검증 결과와 배포 증거는 PR에 기록한다. 합성 Pencil/터치 브라우저 검사는 iPad+Apple Pencil 실제 기기 인수를 대신하지 않는다.
