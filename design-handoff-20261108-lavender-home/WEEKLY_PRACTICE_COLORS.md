# 이번 주 연습 — 달성률 색상

오늘이 토요일인 예시입니다. 실제 서비스 날짜를 변경하는 설정이 아닙니다.

| 달성률 | 표시 | 색상 |
| --- | --- | --- |
| 지난 날 0% | 회색 원 | #E4E7EC |
| 0% 초과~100% 미만 | 연보라 원 | #D9C5FA |
| 100% 이상~120% 이하 | 기본 보라 원 + 흰 체크 | #7A32F5 |
| 120% 초과 | 진보라 원 + 흰 체크 | #4C188E |
| 미래 날짜 | 비어 있는 점선 원 | #E4E7EC |

요일은 월·화·수·목·금·토·일로 고정합니다. 현재 요일은 '오늘'로 치환하지 않고 요일 글자를 #6528CA/700으로 강조하고 해당 원 바깥에 #7A32F5 2px 링(간격 3px)을 추가합니다. 현재 날짜 강조와 달성률 원의 색상은 독립적입니다. 토요일 실적이 생기면 동일한 달성률 색상 규칙을 적용합니다.

예시: 월0% · 화30% · 수100% · 목130% · 금100% · 토(진행률 미지정) · 일(미래). 토요일의 미지정 값을 0%로 단정하지 않습니다. 일요일은 실패가 아닙니다.

[홈 예시](home-preview-saturday.html) · [홈 이미지](home-preview-saturday-390.png) · [주간 카드 확대](weekly-practice-saturday.png)

이미지는 예시 데이터의 디자인 참고 자료입니다. 주간 누적 분/주간 달성률은 일별 목표 시간이 없어 산정하지 않았습니다. 예시에는 월~금 연습한 날 4일, 목표 달성 3일을 표시합니다. 실서비스의 연습시간 집계 정책 변경을 뜻하지 않습니다.

## 분 단위 표시

요일 아래는 퍼센트 대신 실제 연습 분을 표시합니다. 원의 보라색 진하기는 일별 목표 대비 달성률을 따릅니다.

이번 시안의 일 목표는 예시로 30분, 주 목표는 매일 동일한 목표 기준 210분을 사용합니다. 월 0분·화9분·수30분·목39분·금30분, 합계108분입니다. 토요일 실적은 미지정으로 —, 일요일은 미래로 —를 표시합니다. 이 목표는 시안 예시이며 실제 사용자 목표 설정을 변경하지 않습니다.
