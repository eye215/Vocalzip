# VOCAL.zip 학생 1.0 — 오늘의 목표·추천 연습·휴식·홈 UX

작성: 2026-11-07 · 상태: **기획 및 개발 페이즈 초안, 미구현**  
기준: [통합 로드맵](../VOCALZIP_PRODUCT_ROADMAP_2026-11-07.md) · [기존 결정 D09](PRODUCT_DECISIONS_V1_2_2026-11-07.md)

> 기존 30개 상위 Phase는 유지한다. 이번 변경은 개발 범위/검증 항목 정리이며 운영 서비스, DB, 미디어나 기존 레슨 데이터의 변경 및 출시가 아니다.

## 1. 이번 대화의 최종 방향

- **매일 첫 진입:** 사용자 기준 새 날짜에 목표가 없다면 “오늘의 목표를 설정하세요” 추천 바텀시트를 **그날 한 번** 제안. 홈 진입 차단 금지.
- **추천 목록:** 선생님 숙제, 개인 목표, 공연/오디션 준비, 미완료 계획, 반복 연습 루틴을 **하나의 리스트에 섞어** 우선순위 순서대로 표시. 유형별 섹션/구분선 없음. 학생은 선택·해제·추가·순서 변경·연습량 조정 가능.
- **진입 선택지:** [오늘의 목표 설정하기] / [오늘은 쉴래요] / [나중에 정할게요]. **휴식과 미설정은 다르다.** 휴식을 선택해도 선생님 숙제/반복 목표/레슨·공연 원본 삭제 금지.
- **홈 ‘오늘의 목표’:** 연습과 숙제를 나누지 않고 **1개의 통합 글래스 카드**. 왼쪽 원형 차트는 '오늘 완료한 목표 개수 / 선택한 목표 개수', 오른쪽은 **한 개의 혼합 체크리스트**. 오른쪽 목록만 내부 세로 스크롤(2.5~3행 노출), 왼쪽 지표 고정. **[연습 시작하기] 버튼 없음**. 연습 시간 실적/목표는 별도 작은 보조 텍스트.
- **체크의 의미:** 완료형은 학생이 체크·취소, 시간/횟수형은 실행 실적 또는 수동 기록으로 확인, 결과형은 검증 기능 후 도입. **체크 = 실제 녹음/연습 시간 자동 생성 아님**. 선생님 숙제 '학생 수행'과 '선생님 확인'은 별도 상태.
- **홈 ‘이번 주 연습’:** 막대그래프/불꽃 아이콘 **없음**. 월~일 달성 체크 타일 + 실제 분 + 연속 연습 일수; 주간 목표시간/달성률은 하단 작은 글씨. 일자별 연보라=목표 미달, 진보라=달성, 미래/무기록/휴식/미설정은 별도 중립 상태. 휴식일을 연습 수행으로 산입하지 않음.
- **홈 나머지:** 공연·오디션 일정 있으면 상단 주 카드, 다음 레슨은 서브; 최근 연습곡은 자체 카드. 최근 연습곡 1×1 + 오른쪽 퀵버튼 2개는 선호 시안으로 유지하며 배치/버튼 종류는 UI 검증 후 확정. 하단 독 중앙은 녹음 마이크. 아이폰 위젯 비율·스퀴클·글래스·독 스타일을 통일.

## 2. 일일 사용 흐름

```text
새 달력 날짜의 첫 진입
  ├─ 오늘 계획 있음 → 바로 홈(진행률 및 목록)
  ├─ 오늘 휴식임 → 휴식 홈; 나중에 연습으로 전환 가능
  └─ 미설정 → 추천 시트(그날 자동 1회, 강제 아님)
       ├─ 추천 후보 선택/수정/추가/재정렬 → 저장 → 홈
       ├─ 오늘은 쉴래요 → 오늘 상태=rest → 홈
       └─ 나중에 정할게요 → 오늘 상태=deferred → 홈
홈 → 오늘의 목표 카드(선택한 항목만) → 완료 체크/실적 입력/목표 수정
```

- 추천 시트에는 **숙제 1순위, 개인 목표 2순위 등 출처가 달라도 단일 순서**로 표시. 우선순위 초안은 마감 긴급도, 공연 일정, 어제 미완료, 반복 루틴, 사용자 수동 순서를 반영하며 학생의 직접 재정렬이 우선.
- 선택하지 않은 추천 후보는 원본 숙제/개인 목표에서 삭제되지 않음. 오늘 계획에 넣은 목표만 홈 카드에 표시.
- 항목별 시간/횟수 추천 값은 **선택 입력**이며, 일일 총 연습 시간 목표도 선택 입력. 권장값과 사용자 확정값을 별도 저장.
- 추천 후보 없음/추천 실패 시 직접 추가와 휴식을 항상 허용. AI 기능 사용 없이 **규칙 기반 추천 먼저**, AI는 Phase 17에서 별도 검증 후.

## 3. 데이터 및 계산 계약 초안

- 제안 모델: `daily_plan`(user_id, local_date, timezone, state=planned/rest/deferred/unplanned, target_minutes nullable, suggestion_presented_at), `daily_plan_item`(plan_id, original_source_type/id, title_snapshot, order_index, measure=check/duration/count/result, target_value nullable, actual_value, completion_state, completed_at), `practice_session`(기존 기록 재사용), 숙제 원본 연결.
- 실제 DB 스키마/ID/컬럼명은 **Phase 03에서 기존 `practices`, `assignments`, 로컬/클라우드 저장 계약 감사 후 결정**. 부주의한 새 테이블 전체 생성 금지.
- 한 날짜·사용자에 plan은 하나가 원칙(멱등 저장). 휴식→계획 전환, 계획 수정, 목표 추가/체크 취소 시 이전 기록과 원본 숙제 보존.
- 기준 날짜는 사용자 설정 IANA time zone으로 계산. 기기/브라우저/오프라인 재접속에 팝업이 반복되지 않도록 서버 상태를 기준으로 중복 제거. 미동기화 로컬 선택은 보존하고 충돌 복구한다.
- **전체 목표 달성률:** 완료된 일일 항목 수 ÷ 일일 계획 항목 수 × 100. 항목 수 0이면 0%가 아니라 '미설정/—'. '우선순위'는 달성률 가중치가 아님.
- **목표 시간 미설정:** 시간 진행률 '—'로, 실제 연습 시간은 있다면 그대로 표시. 30분 목표 등록/기록 0분이면 '0/30분'. 체크만 했어도 세션/분을 생성하지 않음.
- **시간형/횟수형:** 실제 수행량 또는 수동 실적을 입력. 자동 완료 여부는 기획 검증 후 확정. 녹음 길이를 연습 세션 시간으로 무조건 더하지 않는다. 하나의 연습 세션이 여러 목표/곡/트레이닝에 연결되더라도 **세션 ID 기준 합산 중복 방지**.
- **주간 달성 타일:** '그날 총 실제 연습 분 / 그날 설정한 목표 분'을 기본 기준으로 하는 제안. 목표 분 미설정은 목표달성 미판정. **연속 연습은 실제 연습 기록이 있는 날** 기준; 휴식일의 streak 단절/보호 정책은 추가 결정 필요.

## 5. 수용 테스트 필수 시나리오

1. 첫 진입: 후보 0/1/10/30개, 숙제와 개인 목표 혼합, 사용자 재정렬 및 동일 날짜 다른 기기 진입.
2. [오늘은 쉴래요]와 [나중에 정할게요] 각각 선택 후 재방문. 목표 없을 때 0% 표기 금지. 휴식 취소 후 연습 시작.
3. 다음 날 추천 시 이전 날짜 계획/완료/휴식 이력 보존. 타임존 변경·자정 직전/직후·오프라인 동기화.
4. 목표 기간·시간 없이 체크 가능, 시간/횟수 실적 수동 입력, 완료 취소, 반복 숙제 원본/레슨 피드백 불변.
5. 카드 오른쪽 목록만 스크롤: 1개/20개, iPhone 세로/가로, VoiceOver, 터치 타겟 44pt 이상, 홈 스크롤과 제스처 충돌.
6. 같은 녹음·연습 세션 여러 목표 연결 시 **연습 분 중복 집계 금지**. 단순 체크로 연습 분 증가 금지.
7. 주간 타일 목표 달성/미달/휴식/미설정/미래, 요일·분·주간 목표 퍼센트, 화염·막대그래프 부재.
8. 학생 1.0 직접 숙제와 추후 선생님 2.0 검토 상태 격리. 다른 사용자 레슨·숙제·녹음 접근 차단.

## 6. 열린 결정(코딩 전 별도 확정)

- 홈 목록 체크 시 **즉시 체크(완료형만)** vs 모든 목표 상세 바텀시트.
- 시간형/횟수형의 자동 완료와 실제 연습의 증거 수준.
- 휴식일이 연속 연습 streak을 끊는지 여부(휴식일을 연습으로 인정하지는 않음).
- 주간 목표 시간을 명시적으로 설정하지 않은 사용자에게 달성 퍼센트를 보여줄지 여부.
- 최근 연습곡 1×1 + 퀵버튼 2개 구성 및 위치를 시각 QA로 확정.
