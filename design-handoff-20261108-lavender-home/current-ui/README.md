# 현재 개발된 Vocalzip 페이지 기준 시안

이전 `ui-kit`은 실제 기능을 축약한 별도 예시였으며 이 수정본의 구현 기준으로 사용하지 않습니다. 이번 시안은 main `111dd126eaebd58cb584e9bc149c2b88d2f2df6b`의 **실제 화면 렌더·마운트·입력 폼 코드**를 재사용합니다. 디자인 시스템은 개발 문서로만 제공하며 사용자 메뉴에서 제거했습니다.

`Vocalzip_Current_UI.html`을 브라우저에서 열어 확인합니다. 승인한 홈을 유지하고, 서브페이지에는 실제 구현의 버튼·필드·필터·탭을 그대로 포함합니다. 실제 앱 파일 자체를 덮어쓰거나 배포하지 않습니다.

## 바로잡은 구조

- 홈·내 곡·보관함·일정: 네비 메인. 뒤로가기 없음.
- 곡·레슨·공연 상세 등: 뒤로가기 유지.
- 녹음: 플로팅으로 진입, 상단 닫기, 하단 네비와 플로팅 숨김. 진행 중 닫으면 계속 녹음/중단하기 확인.
- 디자인 시스템: 앱 메뉴에 없음. 별도의 개발 문서.
- 실제 구현의 연습 기록·목표·곡 편집 등은 기존처럼 입력 시트로 엽니다. 별도의 가짜 메인 페이지를 만들지 않습니다.

## 실제 기능을 유지한 부분

- 내 곡: 작품·배역 검색, 최근 연습/이름/최근 등록/숙련도 정렬, 레퍼토리 상태, 나의 공연.
- 곡 상세: 전체·가사·악보·레슨·연습·공연 탭, 작품·배역/키/숙련도/대표 테이크, 비교, 연습 기록.
- 보관함: 공연·레슨·연습 구분, 음성·영상/곡 필터, 월별 파일·길이, 선택 처리, 상세 확장, 정보 수정·비교·분석·가져오기 진입.
- 일정: 기존 월간 요약, 날짜별 레슨·연습·공연 및 연결 녹음. 별도의 단순 일정 목록으로 교체하지 않음.
- 레슨: 예정/완료/취소, 여러 곡 선택, 시작·종료 시각, 선생님·장소·준비 메모, 곡별 피드백·숙제·녹음.
- 연습: 곡/트레이닝, 분·자기평가·숙제 반복·메모·녹음 연결 등 실제 입력 시트.
- 녹음: 기존 곡 선택·시작·일시정지·종료·미리듣기·제목/메모·저장/다시 흐름.
- 성장·공연·AI 곡 추천·기존 자료 가져오기·저장 공간·설정 등 기존 등록 경로도 보존.

## 시안의 한계

모든 데이터는 합성 예시이며 문서 메모리에만 유지합니다. 실제 계정·클라우드·운영DB·R2·AI 서버·서비스워커를 로드하지 않습니다. 외부 API 요청은 차단합니다. 마이크는 사용하지 않고 무음 샘플로 녹음 흐름을 확인합니다. 파일 가져오기 화면은 실제 항목을 보여주되 실제 파일 저장·업로드는 차단합니다. 소스에 있는 정산 링크도 외부로 이동하지 않습니다.

실제 페이지 코드를 재사용했다고 해서 모든 백엔드 기능이 동작하거나 기존 결함을 수정했다는 뜻은 아닙니다. 시안 데이터와 실제 서비스 데이터는 연결되지 않습니다. 홈은 별도로 확정한 고정 시안이며 요일·수치는 실제 날짜·집계와 독립적입니다.

`source/`는 해당 커밋의 UI 소스 스냅샷, `preview-environment.js`와 `source-adapter.js`는 격리된 예시 환경, `current-theme.css`는 스타일 변경, `preview-boot.js`는 승인 홈과 네비 정책 연결입니다. `build.py`는 Python 표준 라이브러리만으로 단일 HTML을 만듭니다.
