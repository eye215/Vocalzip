# 악보 작업 공간: 태블릿/Pencil 중심 고도화

2026-11-10. PR [#238](https://github.com/eye215/Vocalzip/pull/238). 목표는 **악보를 보고 필기하고 레슨/연습을 남길 때 Goodnotes를 따로 열지 않아도 되는 흐름**이다. 주 사용은 태블릿+Apple Pencil, 아이폰은 빠른 열람/확인이다. 전체 Goodnotes 기능/실기기 검증이 완료됐다는 뜻으로 쓰지 않는다.

## 이번 구현

- 펜: 검정·진한 빨강·파랑·남색·초록·보라·갈색·자주 8색. 형광펜: 노랑·분홍·하늘·초록·보라·주황·민트·라일락의 파스텔 8색.
- 도구별 최근 8색, 사용자 색 최대 24개. 네이티브 색상 선택과 #RRGGBB 코드로 추가하고 선택한 사용자 색을 삭제한다. 설정은 계정별 로컬 저장이며 필기 데이터와 분리한다.
- 펜/형광펜별 굵기·투명도. 투명도 0~95%는 저장 opacity 1~0.05에 대응한다. 기존 opacity 없는 획은 펜 1/형광펜 0.28로 읽어 기존 화면을 유지한다. 새 형광펜 기본은 파스텔색·opacity 0.55다.
- 같은 편집기를 전체화면으로 전환한다. 상단 한 줄 도구, 설정·종료 고정, 좁은 화면의 도구 좌우 스크롤. 상태/기존 필기 유지. 네이티브 API 미지원 시 화면 채움으로 동작하며 Safari 주소 표시줄 숨김을 보장하지 않는다.
- 태블릿 추정 기기의 최초 입력 설정은 펜만 모드. 사용자가 바꾼 설정을 우선한다. 이동 모드/펜만 모드의 손가락 드래그·두 손가락 확대와 Pencil 입력 중 터치 무시. 확대 중에는 표시 크기를 바꾸고 종료 후 한 페이지를 재렌더링한다. 획의 정규화 좌표는 바꾸지 않는다.
- 곡 상세 악보 항목 전체·키보드 Enter로 뷰어 진입. 눈/별도 필기 아이콘 제거, 정보 수정/삭제는 각각 독립 처리. 원본 PDF 열기는 뷰어 설정에서 유지.
- 기존 획 단위 지우개, undo/redo, 자동 기기 저장/실패 재시도·계정 보호 유지.
- 필기 포함 PDF 사본 준비/저장. PDF.js의 원본과 같은 해시인지 확인한 뒤 브라우저의 pdf-lib 1.17.1로 복사한다. 페이지별 투명 필기 PNG만 덧대어 원본 PDF 콘텐츠는 유지하고, 회전·CropBox는 viewport의 PDF 좌표로 역변환한다. 새 파일만 내려받으며 R2에 덮어쓰거나 업로드하지 않는다. 필기 이미지는 한 번에 한 페이지/최대 400만 픽셀로 처리한다.

## 데이터 보호

원본 PDF, 곡/녹음/레슨·연습은 변경하지 않는다. 신규 필기에 선택적 opacity만 추가하며 기존 version 1 획과 복구 원장 형식은 읽을 수 있게 유지한다. 설정 키는 계정 범위의 `vzip_score_ink_settings_v1:<owner>`이고 PDF/서명 URL/토큰은 포함하지 않는다. 설정 변경은 과거 필기를 수정하지 않는다.

운영 DB/원본 파일 이동·삭제·새 동기화 활성화는 없다. native fullscreen 지원 여부·Pencil 실제 압력/손바닥 처리와 자동 WebKit/합성 포인터 검사를 구분한다.

## Goodnotes 대체 인수 흐름

태블릿에서 악보 열기 → Pencil 필기/손가락 이동·확대 → 선택/텍스트/도형 → 자동 저장 → 앱 종료/오프라인 후 재개 → 아이폰에서 확인 → 필기 PDF 출력까지 원본과 필기가 유지되어야 한다. 현재 표에서 후속인 항목을 완료로 표시하지 않는다. 실제 iPad Pencil/iPhone Safari·PWA, 긴 세션·메모리 부족·기기 간 동기화는 별도 인수 대상이다.

실행 SHA·검사 결과·배포 여부는 PR #238에 기록한다. 기존 필기 검증 61개와 이번 신규 검사를 합산해 모두 새 기능 검증으로 표시하지 않는다.
