# 유료 AI 임시 소유자 전용 정책 — 2026-11-09

최신 사용자 지시: 현재는 본인 계정만 허용하고 나머지 계정의 유료 AI를 비활성화한다.
Plus/Pro 예산 기능 개발은 보류한다. 금액·횟수 제한을 임의로 확정하지 않는다.

## 서버 계약

- 관리자가 설정한 단 하나의 Auth UUID만 유료 STT를 요청할 수 있다. 이메일·브라우저 표시·user_metadata·자칭 owner 역할로 권한을 얻지 않는다.
- 기존 2개 등록 세션 정책은 유지한다. 소유자도 회수·만료된 세션에서는 유료 요청을 할 수 없다.
- vzip_ai_owner_policy는 브라우저가 조회·수정할 수 없다. 초기값/행 없음/소유자 없음은 비활성이다.
- Edge는 GET 사전 확인과 POST 본문 처리 전에 vzip_ai_owner_allowed를 호출한다. RPC 부재·오류도 유료 호출 없이 실패한다.
- 기존 Edge/클라이언트도 vzip_song_stt_reserve의 서버 소유자 검사에서 차단된다. 기존 사용량 카운터와 세션 구현은 보존한다.
- 무료 규칙 추천·캐시 곡 비교·기존 서버 측정과 유료 API 실행은 구분한다. 자동 워커의 유료 STT 금지는 유지한다.

## 운영 적용 순서

1. 본인의 로그인 이메일로 Auth 계정을 정확히 대조한다. 다른 계정·가장 오래된 계정·첫 사용자로 임의 지정하지 않는다.
2. 소유자 식별과 기존 RPC/구현·세션 계약을 읽기 전용으로 확인한다.
3. 검증한 SQL과 소유자 설정을 한 트랜잭션에 적용한다. 사용자 데이터·원본·기존 카운터는 초기화하지 않는다.
4. Edge 수정본을 배포하고 기존 STT_ENABLED/API key/allowlist를 보존한다. 새 유료 호출을 자동 시작하지 않는다.
5. 타 계정 사전 확인/예약 거부, 소유자 유효 세션 허용, 회수 세션 거부를 실제 환경에서 별도 확인한다.
