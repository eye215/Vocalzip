# 음원 중심 가져오기와 날짜 자동 분류

- 레슨/연습의 영상 녹화를 제거하고 마이크만 요청한다. 이전 공유 녹음기와 영상 압축 모듈은 로드/사용하지 않는다.
- 영상 파일 가져오기는 지원하되, 영상 트랙을 저장하지 않고 원본의 모든 음성 트랙을 재인코딩 없이 복사한다.
- Worker + OPFS 임시 파일과 제한된 Blob 읽기를 사용한다. 추출 결과의 코덱/샘플레이트/채널/음성 패킷 바이트 및 타이밍을 원본과 비교한다. 불일치/무음 영상/미지원 형식은 저장하지 않는다.
- 보관함/연습 가져오기, 공유 수신, 기존 기기 영상의 수동 백업 모두 음원 추출을 통한다. 기존 저장 영상은 삭제하거나 자동 마이그레이션하지 않는다.
- 날짜 우선순위: 명시적 촬영·녹음 태그(QuickTime creationdate, ID3 TDRC, WAV ICRD 등) → 파일 내부 생성 시각 → 온전한 메타데이터 날짜 → 파일 수정일 → 가져온 시각.
- 명시적 시간대 오프셋이 있는 촬영 날짜는 해당 날짜를 보존한다. 연도만 있는 태그나 잘못된 날짜, 1904년 등 무효 생성 시각은 녹음 날짜로 사용하지 않는다.
- 기록 캘린더는 가져온 음원도 원본 날짜에 표시한다. 날짜 카드에서 보관함 재생으로 이동할 수 있다.
- 보관함의 ‘곡·감상 기록’에서 날짜를 언제든 수정한다. 수동 수정은 recordedDate/dateSource=manual로 기기/클라우드에 저장하며 캘린더도 이동한다.
- 연습 폼의 날짜를 직접 선택하지 않았고 첫 단일 파일을 가져온 경우 원본 날짜를 자동 적용한다. 사용자가 고른 날짜는 덮어쓰지 않는다.
- MPL-2.0 Mediabunny 1.65.1을 고정 CDN에서 로드한다. 영상/음성 디코더나 인코더가 필요 없는 패킷 복사 방식이다.
- 실제 iPhone의 200MB MOV/HEVC·발열·백그라운드 및 운영 계정 파일 전송 검증은 별도다. 자동 테스트는 AAC가 있는 실제 MP4, 201MiB MP4(free atom 패딩), 무음 영상, 날짜 태그·수정/재접속·카메라 미요청을 확인한다.

- OPFS를 제공하지 않는 브라우저는 음원 출력만 최대 24MiB의 제한된 임시 버퍼로 처리한다. 원본 영상은 이 버퍼에 읽지 않으며, 임의 위치 쓰기/헤더 덮어쓰기를 지원한다. 상한을 넘으면 저장하지 않고 음원 파일로 가져오도록 안내한다.
