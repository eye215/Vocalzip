# Vocalzip 홈 개발 전달서 — 2026-11-08

이 폴더의 home-preview.html과 아래 규격을 기준으로 학생 홈을 구현한다. 최종 합의된 라이트 테마이며, 토스의 정보 위계와 밀도에 연보라 브랜드 컬러를 적용한다. 이전 시안에 있던 파란 보라, 인사말, 레슨 설명 문구, 세로 퀵메뉴를 다시 적용하지 않는다.

## 파일과 기준

- home-preview.html: 최종 시안. 다운로드 후 브라우저에서 열기. 아이콘 28개를 SVG로 내장했다. 폰트는 Pretendard CDN을 사용하므로 최초 로드에는 네트워크가 필요하다.
- design-tokens.css: 구현에 사용할 색상·간격·글자·버튼 토큰.
- 본 문서: 화면 구성, 동작, 예외, 검수 기준.
- 미리보기의 날짜·곡·180분·100%·6일·목표는 예시 데이터다. 실제 구현 시 사용자 데이터와 로컬 날짜로 계산한다.
- 미리보기는 화면 확인용이다. 목표 체크와 완료 개수만 로컬로 반응하며, 이동·녹음·저장·인증·API 연동은 구현되어 있지 않다.
- 기존 앱은 README 기준 홈/내 곡/녹음/캘린더/성장이다. 이번 시안의 네비는 **홈/내 곡/녹음/보관함/일정**이다. 기존 화면과 데이터 접근 기능이 사라지지 않도록 성장 등 기존 진입점은 기존 메뉴에서 보존한다. 실제 라우트명은 코드에서 확인하여 연결하고 임의 URL을 만들지 않는다.
- 미리보기의 외곽 390px 프레임·둥근 화면 모서리·홈 인디케이터는 확인용이다. 실제 앱 안에 가짜 OS 인디케이터를 만들지 않는다.

## 1. 공통 규격

| 항목 | 값 |
| --- | --- |
| 기준 너비 | 390px, 320~430px 대응 |
| 화면 좌우 여백 | 16px, 좁은 화면은 12px까지 |
| 기본 카드 | radius 20px / padding 20px |
| 카드 간격 | 가로·세로 12px |
| 일반 카드 면 | #FFFFFF, 테두리·그림자 없음 |
| 메인 버튼 | 높이 52px / radius 16px |
| 보조 버튼 | 높이 44px / radius 12px |
| 작은 버튼 | 보이는 높이 32px / 실제 터치 최소 44×44px |
| 폰트 | Pretendard, 400·600·700 |
| 기본 자간 | -0.02em |
| 숫자 | 시간·금액 등 변화하는 수치는 tabular-nums 권장 |

고정 높이로 긴 텍스트를 잘라내지 않는다. 기본 여백은 20px이며 퀵메뉴 16px, 목표 카드 상하 여백 등은 미리보기의 컴팩트한 예외를 따른다. 작은 화면에서도 최소 터치 영역이 겹치지 않아야 한다.

| 대상 | 크기/행간 | 굵기 | 색상 |

| 작은 출처·요일·네비 라벨 | 11/약16px | 400, 선택 600 | 해당 역할색 |

- 대제목 옆 아이콘과 제목은 같은 #101828. 아이콘 20px, 선 굵기 1.8px, 간격 8px.
- 퀵메뉴는 **아이콘 왼쪽 + 텍스트 오른쪽**, 중앙 정렬, 간격 8px. 둘 다 #344054. 세로 배치 금지.
- 기능 아이콘은 동일 Lucide 선형 세트 사용. 미리보기의 SVG를 재사용하거나 기존 앱의 같은 라이브러리로 치환한다.
- 주요 매핑: 주간 연습 chart-no-axes-column-increasing / 목표 sparkles / 레슨노트 notebook-pen / 연습기록 history / 홈 house / 내 곡 music-2 / 녹음 mic / 보관함 archive / 일정 calendar-days.
- 상단 노트 일러스트는 장식용이다. 조작 아이콘과 별도로 유지한다.
- 장식은 aria-hidden, 아이콘 단독 버튼은 접근 가능한 이름 제공. SVG가 초기 렌더부터 보여야 하며 CDN 아이콘 변환 실패로 빈칸이 생기지 않도록 한다.
- Lucide 아이콘은 해당 라이브러리의 ISC 라이선스를 기존 의존성 고지와 함께 준수한다.

## 4. 홈 구성과 동작

### 헤더

왼쪽 Vocalzip 로고, 오른쪽 알림·프로필. 별도 카드로 감싸지 않는다. 높이 52px, 아이콘 버튼 터치 44×44px.

**삭제 상태 유지:** “좋은 오후예요, 유리님”, “오늘도 나만의 목소리를 쌓아가요.”를 노출하지 않는다.

### 상단 레슨 카드 + 공연/오디션

- 레슨 카드: #F3ECFF, radius 20px, padding 20px, **최소 높이 약 108px**.
- 왼쪽 제목+D-day, 아래 일시. 오른쪽 축소한 노트 일러스트. 텍스트가 길면 높이는 늘릴 수 있다.
- “다가오는 레슨”, “이번 레슨 · 고음 연결과 호흡” 문구는 삭제 상태 유지.
- 제목과 D-day는 하나의 묶음. 날짜는 사용자 로컬 시간으로 표시, 당일은 D-day, 미래는 D-n. 시안의 숫자를 하드코딩하지 않는다.
- 공연·오디션은 카드 아래 페이지 배경 위의 짧은 행. 종류 / 일정명 / D-day / 화살표 구성.
- 미리보기의 행은 시각 높이가 38px지만 **실제 구현에서는 터치 영역 44px 이상**을 보장한다.
- 레슨·공연·오디션은 실제 데이터가 있는 경우만 표시. 일정이 없으면 가짜 일정을 넣지 않고 기존 일정 등록 기능으로 연결한다.
- 실제 일정 정렬과 삭제·완료 정책은 기존 앱 정책을 보존한다. 데이터 스키마 변경이나 자동 완료는 이 디자인 작업에 포함하지 않는다.

### 이번 주 연습

- 흰 카드, 제목·아이콘 왼쪽 / 누적 분 숫자 오른쪽.
- 하단 보조 줄: 목표 시간 / 달성률 / 불 아이콘+연속일.
- 그 아래 월~일 7칸. 완료=보라 원+흰 체크, 오늘=바깥 링, 미완료=연한 면. 미래에는 완료 체크 금지.
- 시안의 꽃 도장·스탬프를 되살리지 않는다. 별도 달성률 막대는 추가하지 않는다.
- 연습시간 산정은 기존 기록 기준을 재사용하며 녹음 연결로 시간을 중복 합산하지 않는다. 목표 미설정 시 0으로 나누지 않고 목표 설정 진입을 제공한다.

### 최근 연습곡 + 퀵메뉴

- 2열, 간격 12px. 왼쪽 최근 곡은 약 173×173px(390px 기준), 오른쪽은 같은 전체 높이를 둘로 나눈 레슨노트·연습기록.
- 최근 곡 배경: #F3ECFF → #FAF8FF의 은은한 그라데이션. 커버·포스터 없이도 완성되는 타이포그래피 중심 구성.
- 곡명 / 작품·분류 / 하단 “**계속 연습하기**” 액션.
- “이어 듣기” 문구로 바꾸지 않는다. 버튼은 단순 음원 재생이 아니라 **해당 곡이 선택된 연습 흐름**으로 연결한다. 기존 곡/연습 기능을 재사용한다.
- 녹음이 없더라도 연습을 시작할 수 있어야 한다. 곡 자체가 없으면 곡 추가/선택 진입을 제공한다.
- 오른쪽 퀵메뉴는 반드시 **가로 아이콘+텍스트**, 우측 연한 화살표. 아이콘을 텍스트 위나 아래로 배치하지 않는다.

### 오늘의 목표

- 제목+같은 색 아이콘, 우측 완료 개수+설정.
- 체크 20×20px, radius 6px, 문장 간격 10px, 행 높이 약 49px.
- 숙제/개인은 작은 출처 라벨. 문장이 먼저 읽혀야 한다.
- 완료 시 포인트 배경+흰 체크, 문장은 #98A2B3와 얇은 취소선.
- 완료 개수는 실제 항목 수에 따라 계산. 미리보기의 분모 3을 제품에 하드코딩하지 않는다.
- 실제 저장·숙제 연계는 기존 데이터 기능에 연결. 목표 없음/긴 문장/저장 실패도 처리한다.
- 시안에 없는 원형 완료율 그래프나 연습 시작 큰 버튼은 이번 전달본에 추가하지 않는다.

### 하단 네비

- 홈 / 내 곡 / **중앙 녹음** / 보관함 / 일정.
- 흰색 78% + backdrop blur 20px, 캡슐형, 흰색 65% 1px 테두리.
- 그림자: 0 5px 20px rgba(55,33,85,.045).
- 선택 면: rgba(122,50,245,.055), 선택 아이콘=포인트. 선택 라벨은 미리보기의 연한 보라 #8A6DB8.
- 기본 아이콘 #475467, 기본 라벨 #667085: 글자가 아이콘보다 연하게.
- 녹음은 52px 불투명 보라 원형, 흰 아이콘·라벨. 눌림 #6528CA.
- 제품에서는 실제 앱 하단에 안전영역 포함 고정. 미리보기는 확인 편의를 위해 일반 흐름에 놓았다.
- 스크롤 콘텐츠는 네비 뒤에서 흐리게 보일 수 있으나 마지막 목표까지 네비 위로 올릴 수 있도록 네비 높이+하단 safe-area+여유 공간 확보.
- 블러 미지원 시 충분히 불투명한 흰색으로 대체한다.

## 검증 범위

전달 파일의 SVG 내장, 최종 색상·문구·가로 정렬 CSS 및 파일 구성을 정적으로 확인했다. 이 환경에서는 브라우저 실행이 제한되어 최신 시안의 렌더 캡처와 실기기 검증을 완료하지 못했다. 위 체크리스트는 개발 완료 시 수행할 검증이며 통과했다고 간주하지 않는다. 이 PR은 개발 전달용 문서·미리보기만 추가하며 실제 서비스 앱은 수정하지 않는다.
