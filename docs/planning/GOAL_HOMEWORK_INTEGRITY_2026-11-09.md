# 목표 저장·숙제 수행 집계 보강

Phase 09/11/13 · LEARN-09-02 · PR #183

## 반영 범위

- 오늘의 목표 설정창을 열 때 해당 날짜 목표와 같은 주의 시간 설정을 메모리에 스냅샷으로 보관한다. 저장 전에 이미 수신된 변경과 대조하며, 다르면 최신 데이터를 유지하고 작성 중 입력·오류 안내를 남긴다.
- 목표 체크는 숙제 전체 완료 및 실제 연습시간과 별개다. 이번 변경으로 연습 기록이나 숙제 완료를 자동 생성하지 않는다.
- 숙제 수행 집계와 숙제 상세의 수행 목록은 같은 연습 ID의 최신 버전을 한 번만 센다. 날짜가 같아도 서로 다른 연습 ID는 각각 유지한다.
- 수행 횟수가 없는 과거 완료 연결은 기존 의미인 1회를 유지한다. 명시된 0 또는 잘못된 횟수는 1회로 만들지 않는다. 잘못된 값은 집계 시 0으로 취급하며 원본을 수정하지 않는다.
- 숙제 반복 횟수를 실제 연습시간에 곱하거나 녹음 길이를 시간으로 더하지 않는다.
- 기존 레슨·숙제·연습·녹음 ID, 계정 권한 및 UI 배치를 유지한다. DB 변경·운영 데이터 일괄 수정 없음.
- #151의 가입 시 목표 설정 변경은 별도 브랜치로 유지한다.

## 검증 범위와 한계

순수 모델 시험은 체크 변경·목표 추가/삭제·일/주 목표시간 변경 충돌, 무관한 날짜/주/연습 변경 허용, 입력 불변, 중복 세션 및 횟수 정규화를 검증한다. 브라우저 시험은 모바일 Chromium/WebKit·데스크톱에서 실제 목표 설정창의 충돌/입력 보존/새로고침과 숙제 상세·기존 숙제 저장 흐름을 검증한다. 실행 결과는 PR #183 및 전용 Actions에 기록한다. 실기기 iPhone 검증은 하지 않았다.

이 스냅샷은 클라이언트가 이미 받은 변경만 비교한다. 서버 전체 동시 쓰기 보호나 필드별 충돌 병합을 보장하지 않는다. #125/#142/#143의 비활성 서버 계약을 활성화한 것으로 보지 않는다.

반복 일정 정책, 목표-연습 수행 연결 고도화 및 기기간 충돌 처리는 후속 과제다. 이 수정으로 Phase 09/11 전체를 완료 처리하지 않는다. 기존 과거 기록을 추정해 일괄 수정하지 않는다.

## 다음 순서

1. 데이터 보존·중복 집계 검증 후 이 변경만 배포한다.
2. 레슨/정산/녹음의 선택적 영구 삭제와 차감 복구 계약을 점검한다. 기존 비UI 작업 흐름을 유지한다.
3. 개별 파일 공유의 접근·회수 검증과 비활성 서버 동기화 계약의 운영 준비를 진행한다.
