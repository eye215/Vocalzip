# VOCAL.zip 디자인 기준

확정 방향: **토스의 정돈된 디테일 + 연보라 브랜드 컬러**.
모바일을 우선하고 Pretendard의 기존 크기를 유지하며 굵기·색상·간격으로 위계를 만든다.

## 공통 규격

| 항목 | 기준 |
| --- | --- |
| 폰트 | Pretendard 400 / 600 / 700 |
| 카드 | 반경20px / 기본 내부20px / 카드 간12px |
| 페이지 배경 | #F8F6FD |
| 카드 | #FFFFFF |
| 포인트 | #6326FF |
| 눌림 | #4E1BCC |
| 연한 선택 면 | #F1EAFF |
| 메인 버튼 | 높이52px, 흰 글자·아이콘 |
| 터치 영역 | 최소44×44px |

좁은 화면(359px 이하)의 정보가 많은 작은 카드는 내부16px까지 줄여 문구를 읽기 쉽게 유지한다.
같은 줄의 카드는 높이를 맞추고 긴 내용·확대 글자는 필요한 만큼 높이가 늘어난다.

## 텍스트 위계

| 용도 | 굵기 | 색상 |
| --- | --- | --- |
| 인사말·일정명·주요 카드 제목 | 700 | #101828 |
| 주요 숫자 | 700 | #344054 |
| 곡명·레슨노트·연습기록 | 600 | #344054 |
| 목표 항목·일반 본문 | 400 | #475467 |
| 날짜·시간·부가 설명 | 400 | #667085 |
| 가장 약한 보조 정보 | 400 | #818DA2 |
| 버튼·링크·선택 | 600 | #6326FF |

작은 설명·출처까지600~700으로 올리지 않는다.
주요 채움 버튼 위는 #FFFFFF, 연한 버튼 면 위 글자·아이콘은 #4E1BCC.
현재 홈에서 삭제한 인사말을 이 표 때문에 복원하지 않는다.

기존 홈의 크기: 주 일정22px, 주요 카드 제목18px, 곡명16px, 목표15px, 퀵메뉴14px, 설명13px, 배지12px, 내비11px.
주요 숫자32px는 기존 강조 크기를 유지한다.

## 영역별 마감

### 최상단 일정

배경형을 유지한다. 가장 가까운 일정은 제목·D-day 한 줄과 날짜·시간 한 줄, 나머지는 종류·제목·D-day 한 줄이다.
제목과 D-day 간격은8px이며 제목을 빈 공간 전체로 늘려 둘을 떨어뜨리지 않는다.
부가 배역·준비곡·반복 상세 링크는 홈에 나열하지 않고 기존 상세에서 확인한다.
긴 제목은 말줄임하되 전체 제목은 접근성 설명·툴팁·상세에 남긴다.
일정이 없으면 영역과 여백을 표시하지 않는다.

### 카드·아이콘

관련 정보를 묶고 카드 안의 글자·아이콘 시작선을 정렬한다.
퀵메뉴는 아이콘·문구를8px 간격으로 묶고 작은 연한 화살표를 둔다.
최근 곡은 곡명·설명을 먼저, 연결된 녹음이 있으면 하단 ‘이어 듣기’+재생을 하나의 버튼으로 표시한다.

조작용은24 viewBox, stroke1.8, 둥근 선 끝·접합의 동일 선형 세트를 사용한다.
주요 제목 옆20px, 네비24px, 퀵메뉴22px를 기준으로 한다.
작은 분류명·화살표는 기존 작은 크기를 유지한다.
상단 일정의 부드러운 일러스트와 조작용 아이콘은 역할별로 구분하되 각 그룹 안의 스타일을 맞춘다.

### 주간 연습

완료는 #6326FF 원+흰 체크, 오늘은 바깥 링, 미래는 연한 테두리다.
달성률별 다색 도장·꽃 장식은 사용하지 않는다. 목표 미설정은 완료로 오인하지 않게 체크하지 않는다.
실제 시간·목표·달성률의 계산 정책과 접근성 설명은 유지한다.

### 하단 내비

표면은 흰색78%, backdrop blur20px, 완전 둥근 캡슐이다.
아이콘·글자 전체의 opacity를 낮추지 않는다.
그림자는0 4px 20px rgba(35,20,60,.04)로 가볍게 처리한다.
선택 면은 메뉴 전체 대신 아이콘 뒤44×32px의 #F1EAFF 타원으로 제한한다. 원래 메뉴의 터치 영역은 유지한다.
중앙 녹음은 불투명 #6326FF와 흰 마이크로 강조한다.
메뉴명은 기본400·회색, 선택600·보라. 투명도 감소·고대비 환경의 불투명 대체 표면을 유지한다.

### 스크롤

하단140px+Safe Area 여백을 유지한다.
320/390/430px 및200% 글자에서 마지막 목표가 고정 네비 위로 올라오는지 확인한다.
스크롤 중 콘텐츠는 네비 뒤로 흐릿하게 지나갈 수 있다.

## 적용 순서와 범위

네비 무게 → 텍스트 위계 → 일정·작은 카드 여백 순으로 점검한다.
이번 PR은 홈과 이미 연결된 내비 아이콘의 마감에 적용한다. 서브페이지 전면 개편이나 데이터·권한·동기화 변경을 포함하지 않는다.
다른 화면은 후속 작업에서 이 문서를 기준으로 적용·검증한다. 문서화만으로 전 화면 적용 완료를 표시하지 않는다.
