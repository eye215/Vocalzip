레슨비 정산

정산 데이터는 이 브라우저의 별도 저장소에 보관됩니다. 기존 레슨·녹음·연습은 변경하지 않습니다. 기기를 바꾸거나 브라우저 데이터를 지우기 전 JSON 백업을 보관해 주세요.

정산 현황

차감은 0.01회 단위, 금액은 원 단위입니다. 사용 금액은 레슨권별 합산 후 반올림합니다. 환불은 순결제금액에 반영하며, 레슨권 금액·횟수 변경은 별도 수동 조정으로 기록합니다.

레슨권 등록·수정

결제·분할 결제·환불

분할 결제는 같은 레슨권으로 각각 등록하세요. 환불은 원래 결제를 지우지 않고 별도 거래로 남깁니다.

수강과 차감

기존 Lesson ID는 읽기만 합니다. 날짜만 있는 과거 수강도 별도 이력으로 남길 수 있습니다. 완료 취소는 상태를 취소로 변경하거나 차감 기록을 취소하세요.

잔액·횟수 수동 조정

조정은 별도 거래입니다. 조정 후 레슨권 금액 ÷ 충전 횟수로 단가와 과거 사용 금액을 다시 계산합니다. 사유를 남기고 미리보기를 확인하세요.

CSV · XLSX · 노션 CSV 가져오기

같은 날짜의 여러 수강은 허용합니다. 날짜만으로 자동 중복 처리하지 않습니다. 분할 결제는 새 레슨권을 여러 개 만들지 말고 기존 레슨권에 연결하세요. 파일의 수강생 열은 출처 정보로 보존되며 다른 계정으로 전송되지 않습니다.

등록할 행 확인

업로드 이력

되돌리기는 해당 작업에서 만든 데이터만 취소합니다. 이후 수정되거나 다른 이력이 연결된 경우에는 안전을 위해 차단합니다.

변경 이력

결제 수정, 차감 변경·취소·복구, 수동 조정의 변경 전후 값을 보존합니다.
