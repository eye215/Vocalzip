# 파일명 월·일의 연도 해석 — Phase 06/08

최신 main 기준: c156213d480d05c5b93ab0a02480bdbe7da0b498 (`Interpret month day recording filenames in current year`).

- `11-3 scale.m4a`, `12-25 carol.m4a`처럼 연도가 없는 이름은 현재 달력 연도를 사용한다. 2026년 11월에 읽은 `12-25`는 2026-12-25이며 이전 12월로 추정하지 않는다.
- 기준 연도는 함수에 주어진 기준 시각의 기기 현지 달력 연도다. 파일 이름에 연도가 명시되면 그 연도를 유지한다.
- 시간이 없는 이름의 `timeless` 의미와 파일의 시간 유지, 명시 날짜/녹음 메타데이터/직접 수정 날짜의 기존 우선순위는 변경하지 않는다.
- 2월 29일은 해당 현재 연도가 윤년일 때만 유효하다. 이전 윤년으로 자동 이동하지 않는다.
- 과거 녹음의 날짜를 이 변경으로 일괄 재계산하거나 수정하지 않는다.

기존 단위 시험은 이전 규칙(미래 월·일을 이전 연도로 이동)을 기대해 main의 의도적 변경과 충돌했다. 구현을 되돌리지 않고 검증 기준을 맞췄으며, 연말·연초·윤년 경계를 UTC/서울/미국 서부 시간대에서 확인한다. 이 작업은 서비스 코드나 날짜 UI 변경이 아니다.
