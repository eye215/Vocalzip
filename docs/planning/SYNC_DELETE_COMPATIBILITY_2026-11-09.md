# 기기 간 동기화와 영구 삭제 호환성 검증

## 목적과 범위

Phase 03/05의 revision·generation, 필드 초안/lease/오프라인 outbox를 실제 서비스에 연결하기 전에 #196/#204의 영구 삭제와 함께 작동하는지 확인한다. 이 변경은 테스트/문서만 포함한다. 운영 DB에 제안 SQL을 설치하거나 클라이언트 기능을 활성화하지 않는다.

## 확인한 소스

- `supabase/proposals/20261113_snapshot_revision.sql`
- `supabase/proposals/20261114_field_drafts.sql`
- `supabase/migrations/20261114_permanent_lesson_delete.sql`
- `sync/field-draft-outbox.js`

제안 SQL은 현재 `proposals/`에 있다. 소스/자동 시험 존재와 운영 설치, 앱 엔트리포인트 연결, 계정별 활성화는 별개다. 기존 앱의 시각 디자인·녹음·AI 큐·파일 저장 엔진은 수정하지 않는다.

## 새 통합 시나리오

1. 두 등록 세션으로 초안과 충돌 사본을 만들고 영구 삭제 RPC를 실행한다. 대상 레슨의 초안·충돌·요청 영수증·임시 커밋 표식을 제거한다. 다른 계정의 초안·본문과 기존 곡·연습 시간·녹음 원본은 유지한다.
2. 삭제 뒤 revision/generation이 맞는 새 요청으로 과거 본문을 보내도 삭제한 레슨과 숙제 연결을 되살리지 않는다. 삭제 전 오프라인 outbox의 늦은 저장도 서버 초안을 재생성하지 않으며, 미전송 로컬 텍스트는 유실시키지 않는다.

자동 outbox 시험은 SQL 트랜잭션을 호출하는 합성 HTTP 어댑터를 사용한다. 실제 PostgREST/JWT 서명 검증이나 두 대의 실기기 E2E로 표시하지 않는다.

## 운영 연결 전 남은 단계

| 순서 | 작업 | 통과 조건 |
|---|---|---|
| 1 | 운영 설치 여부 읽기 전용 확인 | 버전 열·RPC·요청 영수증·초안/rollout 테이블 존재를 확인. 사용자 본문/식별자 출력 금지 |
| 2 | 앱 브리지 구현 | 클라우드 읽기에 revision/generation 연결, 서버 조건부 저장·중복 요청 복구. 일반 계정 활성화 기본 꺼짐 |
| 3 | 구형 클라이언트 공존 검사 | 직접 쓰기와 신규 RPC가 충돌할 때 덮어쓰지 않고 양쪽 내용을 보존. 영구 삭제 guard 계속 적용 |
| 4 | 초안/outbox 엔트리포인트 연결 | 계정·세션·editor ID 고정, 다른 기기 인계/lease 만료, 늦은 응답·저장 중 추가 입력·용량 부족 검증 |
| 5 | 제한된 운영 검증 | 운영 스키마 설치와 계정별 활성화를 분리. 테스트 계정으로 CAS/응답 유실/로그아웃 차단을 확인 |
| 6 | Safari/PWA 실기기 인수 | 두 세션, 절전·오프라인·강제 종료·재로그인, 미전송 녹음/초안 보존과 편집 인계 확인 |

중단 시 새 쓰기/신규 초안 활성화를 멈추고 미전송 대기열을 유지한다. 테이블 삭제·사용자 데이터 초기화·기존 미디어 이동으로 되돌리지 않는다. 현재 자동 검사만으로 학생 1.0 저장 전체를 완료 처리하지 않는다.

## 운영 읽기 전용 확인

[Actions 42613143438](https://github.com/eye215/Vocalzip/actions/runs/42613143438), 별도 운영 점검 브랜치의 `mode=preflight`로 실행했다. TLS 인증서 및 프로젝트 식별 확인 후 읽기 전용 트랜잭션에서 스키마 메타데이터만 조회했다. 고객 데이터·미디어·권한·활성화 플래그를 변경하지 않았다.

관측 결과는 아래 Actions 출력과 대조하며, 운영 설치 여부가 거짓이면 제안 소스/자동 시험 통과를 운영 제공으로 표시하지 않는다.

실측: 영구 삭제 보호는 설치됨. snapshot revision/generation 열, 저장 RPC, 요청 영수증, 필드 초안, rollout 테이블은 모두 미설치다. 따라서 현재 운영 서비스에서 새 revision/초안/인계 계약이 활성화됐다고 볼 수 없다. 다음 작업은 앱 브리지와 제한된 설치/활성화 절차를 갖추는 것이다.
