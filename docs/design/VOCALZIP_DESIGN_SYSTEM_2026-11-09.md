# Vocalzip 디자인 시스템 가이드

버전 3.46 · 2026-11-10 · 공통 셸 / 홈 / 내 곡 / 보관함 / 일정 / 녹음 / 곡 확인 / 곡 상세 / 보컬 연구소 / 나의 공연 / 레슨노트 / 따라 하기


이 문서는 11월 9일까지 확정한 시안과 상호작용을 개발에 전달하는 기준이다. 새로 만든 이미지의 세부 픽셀보다 아래 명시한 토큰과 규격을 우선한다. 내 곡의 마지막 변경은 **곡마다 개별 카드, 카드 사이 12px 간격**이다.

## 1. 기준과 적용 상태

| 대상 | 디자인 기준 | 구현 기준 |
|---|---|---|
| 홈 | 원본 플로팅 녹음 홈의 카드 비율·레이아웃·여백 | `design-system/Vocalzip_Floating_Record_Home.html`과 어댑터 |
| 내 곡 | 최근 연습곡 + 전체 곡 + 개별 곡 카드 | `app/views-main.js`, `app/collection-ui.css` |
| 보관함 | 종류 탭 + 검색 버튼 + 월별 묶음 목록 | `app/views-more.js`, `app/collection-ui.css` |
| 곡 확인 | 선 없는 분석 현황 카드 + 선택 행 + 녹음 카드 + 고정 하단 버튼 | `app/song-suggestions.js`, `app/song-check-ui.css` |
| 녹음 | 승인된 다크 스튜디오 `Vocalzip_Record_Preview.html`의 준비·녹음·일시정지·검토 화면 | `app/views-main.js`, `app/record-experience.css` |

내 곡·보관함 운영 적용 변경은 [PR #147](https://github.com/eye215/Vocalzip/pull/147)에 있다. 최종 병합·배포 상태는 해당 PR에서 확인한다. 홈의 원본 직접 연결 방식은 [기존 기준](VOCALZIP_DESIGN_STANDARD_2026-11-08.md)을 유지한다.

보관함·곡 상세 등 공통 녹음 더보기의 파일 저장 동작은 **음원 다운로드**로 표기한다. 영상에서 가져온 녹음도 음원 확장자와 실제 형식에 맞춰 내려받으며, 예전 기기에만 남아 있는 영상은 내려받을 때 음성을 추출한다. 기존 녹음 정보·화면 배치는 유지한다.

### 공통 기준 유지

사용자가 “A에 맞춰줘”, “동일하게”, “전부 통일”로 확정한 내용은 해당 화면의 일회성 수정으로 끝내지 않는다. 기준 컴포넌트, 적용 대상, 색·크기·상태별 규칙을 이 문서에 기록하고 같은 PR에서 구현을 맞춘다. 이후 같은 역할의 UI는 이 기준을 재사용한다. 새로운 공통 규칙이 이전 규칙을 대체하면 기존 본문과 변경 이력을 함께 갱신한다. 배포·검증 상태는 PR에 기록하며, 승인된 규칙과 배포 상태를 구분한다.

## 2. 시각 방향

연한 라벤더 배경 위에 흰 카드를 둔다. 면·여백·텍스트 위계로 정보를 구분한다. 보라색은 선택 상태, 주요 동작, 필요한 수치에 사용한다. 검색·설정 같은 일반 도구는 회색 선 아이콘으로 표시한다.

일반 화면 전체에 번짐·광택·큰 그림자를 추가하지 않는다. 유리 효과는 하단 네비와 녹음 화면의 선택 곡에, 진한 그라데이션은 녹음 플로팅·녹음 조작 버튼·내 곡의 최근 연습곡 카드 및 선택 녹음의 보컬 분석 버튼에 한정한다. 커버가 없는 곡에 임의의 포스터·앨범 이미지를 만들지 않는다.

## 4. 글자

Pretendard를 우선 사용한다. 운영 앱은 기존 번들 폰트를 재사용하고, 독립 HTML은 설치 폰트가 없으면 시스템 산세리프로 대체된다. 이미지 시안은 정확한 폰트 검증 자료로 취급하지 않는다. 기본 자간은 `-0.02em`이다.

| 요소 | 크기 / 행간 | 굵기 |
|---|---|---|
| 메인 페이지 제목 | 26 / 34px | 700 |
| 하위 페이지 헤더 제목 | 26 / 34px | 700 |
| 섹션 제목 | 18 / 26px | 700 |
| 일반 카드 제목 | 16 / 22px | 600 |
| 내 곡 목록 곡명 | 15 / 21px | 600 |
| 보관함 목록 제목 | 14–15 / 19–21px | 600 |
| 본문 | 14 / 20px | 400 |
| 필터·정렬 | 13 / 18px | 600 |
| 날짜·시간·메타정보 | 12 / 18px | 400 |
| 네비 라벨 | 11 / 16px | 400–600 |

고정 높이 안에 긴 제목을 억지로 두 줄 넣지 않는다. 목록 제목은 한 줄 말줄임, 상세 화면에서 전체 제목을 제공한다. 사용자 글자 확대에서는 행 높이를 자연스럽게 늘린다.

메인 강조색은 모든 화면에서 `#7A32F5`를 공유한다. 선택·주요 버튼·파형·기기 관리 주요 동작도 이 토큰을 재사용한다. 눌림 `#6528CA`, 선택 면 `#EDE1FF`, 연한 면 `#F3ECFF`는 상태별 파생색이며 화면별 메인색을 새로 정의하지 않는다.

### 공통 작업 화면과 메뉴 (2026-11-09 확정)

버튼에 붙은 짧은 작업·선택 메뉴는 아이폰 시스템 메뉴처럼 어두운 팝오버로 표시한다. 입력·수정, 검색이 필요한 긴 곡 목록·다중 선택, 필터, 긴 설명과 결과는 독립 페이지 형태로 화면 전체를 사용한다. 기존 아래쪽에서 올라오는 시트는 새 작업에 재사용하지 않는다. 이전 절의 “바텀시트” 표현은 이 규칙으로 대체한다. 삭제처럼 되돌리기 어려운 확인은 짧은 확인창을 허용한다.

| 구분 | 공통 규격과 상태 |
|---|---|
| 팝오버 | 기준: 보관함 `+`의 어두운 반투명 메뉴. 누른 버튼에 붙여 열고 화면 가장자리에서 위·안쪽으로 방향을 바꾼다. 최대 폭 304px, R27, 어두운 유리 면 `rgba(54,51,59,.92)`, 56px 이상 행. 동작이 분명해지는 경우에만 21px 흰 선 아이콘을 쓰고, 적절한 아이콘이 없으면 텍스트만 둔다. 제목·손잡이·닫기 버튼·행 구분선은 없다. 삭제는 맨 아래 연분홍 글씨로 둔다. 바깥 터치·Escape로 닫는다. |

곡 상세·보관함 등 흰 목록을 쓰는 화면에서도 팝오버 내부 목록은 흰 카드 배경·패딩을 상속하지 않는다. 팝오버의 어두운 면과 흰 메뉴 글씨를 함께 유지하며 좁은 웹 창에서도 모든 항목이 보여야 한다.
| 전체 페이지 | 최대 폭 560px, 배경 `#F8F6FD`, 위쪽 둥근 시트 모서리 없이 화면 전체를 차지한다. 상단은 뒤로가기·가운데 제목(18px/700), 본문만 스크롤한다. 입력 면은 연한 `#F2EFF7` R15로 구분하고 필드 사이 선을 쓰지 않는다. 날짜 값은 최대 175px. 하단 네비·녹음 플로팅은 가린다. |
| 저장 | 등록·수정 페이지의 저장 버튼은 최하단 52px/R16 고정한다. 키보드 입력 중에는 숨기고 키보드를 닫으면 화면 맨 아래에 표시한다. 키보드를 따라 이동하지 않는다. 필수값이 없으면 비활성. 성공 시 직전 페이지로 돌아와 토스트를 표시한다. |
| 선택·취소 | 곡 등 긴 목록은 검색 가능한 전체 페이지에서 고르고 직전 입력 페이지로 돌아간다. 선택 결과는 그 입력 페이지의 저장 전까지 확정되지 않는다. 뒤로가기·취소는 현재 입력을 버리고 직전 페이지로 돌아와 취소 토스트를 표시한다. |

보관함·곡 상세의 녹음 더보기/일괄 작업, 곡 메뉴, 일정 `+`, 보컬 연구소의 짧은 이동 메뉴와 짧은 단일 선택을 공통 팝오버로 한다. 검색이 필요한 긴 곡 목록·녹음 다중 선택, 내 곡/보관함 필터, 레슨·연습·공연·숙제·악보·녹음 정보 입력은 공통 페이지를 사용한다. 기존 계정 데이터·녹음 재생·분석 제한 조건을 유지한다. 모든 필드가 필수일 때 마지막 필드 완료 후 키보드 위에 저장을 띄우는 방식은 백로그로 둔다.

공통 등록·수정 폼은 본문/상단/하단 좌우 여백 12px, 필드 높이 최소 52px, 하단 저장 52px로 통일한다. 필수 입력이 비어 있거나 유효하지 않으면 저장 버튼을 비활성화한다. 기존 공연·레슨·연습·곡·악보 폼에도 동일하게 적용한다.

보컬 연구소는 여러 날짜를 골랐을 때 변화 그래프 아래에 접힌 **두 녹음 자세히 비교**를 제공한다. 펼치면 A/B 녹음 지정, 같은 위치 재생 전환, 측정값 비교표, 비교 메모 저장과 작성 메모 AI 정리가 보인다. 기존 저장 비교 메모는 리포트 보관함에서 연구소로 열고, 별도 녹음 비교 화면은 노출하지 않는다. 곡 상세는 성장 비교 카드와 보컬 연구소 진입 카드를 표시하지 않는다. 녹음 탭의 하단 보컬 분석하기 버튼 아래에 연구소 이동 문구를 둔다. 한 녹음의 구간 분석, 여러 녹음의 추이, 만족도, 추천 연습은 기존 연구소 흐름을 유지한다.

나의 공연 목록은 12px 카드 간격, R20 흰 카드·얇은 연보라 테두리, 왼쪽 66×76 포스터, 날짜→작품명→배역·회차·공연곡의 정보 순서, 회색 꺾쇠를 쓴다. 포스터가 없으면 연보라 음영과 선 아이콘을 쓴다. 연도 필터와 공연 등록은 목록 위 같은 줄에, 작품·출연·공연곡 요약은 한 줄에 둔다.

## 6. 아이콘

선 아이콘을 기본으로 하고 같은 화면에서 크기·선 두께를 통일한다. 일반 도구 20–22px, 작은 꺾쇠 14–17px, 기본 스트로크 약 1.8px를 기준으로 한다. 운영 앱은 기존 Phosphor를 사용한다. 홈의 원본 HTML은 보관한다. 운영 홈의 알림·프로필·주간 연습·연속 기록·최근 연습곡·레슨노트·목표 아이콘은 연습 기록 `ph-timer`와 같은 Phosphor Regular(선형)로 맞춘다. 로고·재생·녹음 표시, 꺾쇠·플러스 같은 조작 기호는 각자의 규칙을 따른다.

검색 아이콘은 회색이고 배경 박스·보라색 면이 없다. 눈에 보이는 아이콘이 작아도 버튼의 터치 영역은 44px이다. 설정은 정상적인 대칭 톱니 모양으로 제공하고 헤더 맨 오른쪽에 배치한다. 하위 항목 진입은 오른쪽 꺾쇠, 선택 바텀시트는 아래 꺾쇠를 사용한다.

### 공통 아이콘 매핑

| 의미 | 기준 | 공통 적용 |
|---|---|---|
| 연습 기록 | 캘린더의 Phosphor Regular `ph-timer` | 홈 바로가기, 연습 기록 목록·빈 상태, 곡 상세 연습 기록, 캘린더 기록 행·추가 버튼 |
| 레슨 기록·레슨노트 | Phosphor Regular `ph-note-pencil`, 20–22px | 홈 바로가기, 레슨 목록, 일정 속 레슨 기록. 연습 기록 `ph-timer`와 시각적 선 굵기를 맞춘다. |
| 오늘의 목표 정하기 | 원형 `+`, 22px, 스트로크 1.8px | 꺾쇠·플러스는 조작 기호로 별도 관리. 아이콘과 문구는 보조 회색 유지 |
| 헤더 일반 도구 | 홈 알림·프로필과 같은 `#667085` | 우측 검색·추가·설정·더 보기 등 일반 헤더 아이콘 |

홈 원본 HTML은 유지하고 어댑터에서 의미 아이콘에 Phosphor Regular를 적용한다. 꺾쇠·플러스는 별도 관리하며 하단 네비는 다른 화면과 같은 Phosphor Regular를 유지한다. 연습 기록 아이콘을 화면마다 시계·되돌리기·음표로 바꿔 쓰지 않는다.

## 7. 내 곡

1. 헤더: 내 곡 + 실제 곡 수, 우측 곡 추가·설정.
2. 나의 공연: 전체 폭의 별도 진입 행.
3. 최근 연습곡: 실제 마지막 활동이 있는 곡 1개. 제목·작품/배역·상태·숙련도·최근 연습일을 표시한다. 값이 없는 정보는 생략한다.
4. 전체 곡: 우측에 배경 없는 회색 필터·검색 버튼을 나란히 둔다.
5. 필터 버튼은 상태·정렬 선택 페이지를 열고, 적용된 필터는 아이콘 자체를 보라색으로 표시한다. 검색어가 있을 때는 회색 검색 아이콘 옆에 작은 보라 점을 표시한다. 선택 즉시 해당 값으로 갱신한다. 상태·정렬의 기존 선택지는 유지한다.
7. 곡 목록은 **한 곡당 흰 개별 카드**로 표시한다. 카드 사이 12px, 카드 사이 내부 구분선 없음. 아이콘·곡명·작품/아티스트·배역·상태·오른쪽 꺾쇠를 둔다.

최근 연습곡을 누르면 `#/record?song=<곡ID>`로 이동한다. 녹음 화면 진입 시 곡이 선택되어 있어야 한다. 녹음 자체는 녹음 시작 조작 후 시작한다. 일반 목록의 곡을 누르면 곡 상세로 이동한다.

검색은 곡명·작품·배역을 대상으로 한다. 적용한 검색·상태·정렬은 목록 재렌더링에도 유지하고, 현재 필터명과 실제 필터가 일치해야 한다. 곡이 없을 때 첫 곡 추가, 결과가 없을 때 빈 결과를 표시한다.

나의 공연 목적지 화면은 내 곡 카드 규칙을 재사용한다. 상단의 중복 레퍼토리 링크·본문 등록 버튼·긴 집계 설명을 제거하고 헤더의 `+`를 유일한 등록 동작으로 둔다. `공연 기록 N`과 44px 연도 선택을 한 줄에, 출연 작품·실제 출연·배역·공연곡 집계를 채도 낮은 라벤더 `#F2EEF8` R20의 2×2 요약에 둔다. 공연은 간격 12px의 개별 흰 R20 카드로 표시하며 작품명·기간·배역/상태를 읽는 순서로 배치한다. 실제 포스터가 있는 경우에만 포스터 면을 사용하고, 카드 꺾쇠는 `#98A2B3`로 둔다. 연도 필터와 기존 집계·공연 상세 연결은 유지한다.

내 곡·보관함의 필터와 우측 일반 도구 아이콘은 기본 `#667085`로 통일한다. 적용된 필터는 아이콘 자체를 공통 보라 `#7A32F5`로 표시한다. 검색어가 있을 때 검색 아이콘은 기본 회색을 유지하고 오른쪽 위에 작은 보라 점을 표시한다. 일정 달력의 월 이동은 홈 주간 달력과 같은 44px 터치 영역, 가운데 지름 32px `#F2F4F7` 원, `--ink-2` 회색 18px 꺾쇠를 사용한다.

## 8. 보관함

헤더는 ‘보관함’과 실제 파일 수, `+` 버튼 하나로 구성한다. `+`를 누르면 웹에서 만든 메뉴 없이 iOS의 파일 소스 선택 메뉴가 바로 열린다(사진 라이브러리 / 동영상 촬영 / 파일 선택 / 기기에서 제공하는 클라우드 드라이브). 파일을 고른 후에만 업로드 확인 화면이 열린다. iOS 메뉴와 같은 선택지를 앱에서 다시 그려 중복 노출하지 않는다. 선택한 파일은 업로드 전에 날짜·곡을 확인한다. 파일명의 `yyyy-MM-dd_HH-mm-ss`는 날짜와 시각을, `yyyy-MM-dd`는 표기된 날짜를 인식한다. `MM-dd`만 있으면 올해 연도로 지정한다. 파일명에 등록된 곡 제목이나 별칭이 명확하게 포함되면 곡을 미리 선택하며, 후보가 여러 개면 자동 지정하지 않는다. 사용자는 업로드 전에 날짜와 곡을 수정할 수 있다. 중복된 기존 자료 가져오기 헤더 버튼은 두지 않는다. 메인 탭이므로 뒤로가기 버튼이 없고 하단 보관함 항목이 선택되어야 한다.

`전체 / 공연 / 레슨 / 연습` 탭 오른쪽 끝에 검색 버튼을 둔다. 항상 열린 검색창과 별도 필터 아이콘은 두지 않는다. 파일 형식·곡 필터·선택 모드는 목록 위 도구에서 접근한다. 대량 가져오기는 파일 선택 또는 설정의 기존 자료 가져오기 경로로 접근한다.

보관함 `+`에서 파일을 고르면 개수와 관계없이 동일한 전체 페이지 확인 화면으로 이동한다. 파일 분석 중에는 진행 문구만 표시하고, 확인 화면에서는 날짜·곡·종류·중복 여부를 검토한 뒤 가져오기를 누른다. 업로드를 실제로 시작한 뒤에만 화면 맨 위에 진행 대시보드를 표시한다. 완료 후에는 진행 대시보드를 접고 간결한 결과 카드와 보관함 이동 버튼을 보여 준다. 기존 파일 가져오기 시트는 이 진입 경로에서 사용하지 않는다.

보관함 목록과 설정에서 `처리 내역 · 분석 상태` 페이지로 들어간다. 흰색 R20 카드로 현재 서버·기기 분석, 사용량, 파일별 원본→저장 이름·곡 지정 근거·가사 비교 후보·음성 추출·저장 위치·오류를 구분한다. 완료 후에도 기록을 확인할 수 있다. 가사 매칭은 파일명 추천/사용자 지정과 서버의 기준 가사 비교를 섞어 설명하지 않는다. 비용은 작업 테이블에 기록된 합계와 실제 서비스 청구액을 구분하고, 확인할 수 없는 비용은 0원으로 표시하지 않는다. 다운로드 파일은 저장된 음성 형식에 맞는 확장자를 붙인다.

비용 카드의 R2 월 보관료는 현재 계정의 서버 저장량이 한 달간 유지된다는 가정으로 계산한다. 유료 가사 인식은 서버의 누적 호출 횟수와 30초 클립 단가로 별도 계산한다. 서버 분석 작업의 기록 금액도 따로 둔다. 누적 AI 비용과 미래 한 달의 보관료를 하나의 총액으로 더하지 않고, 실제 청구액이나 사업자 전체 계정 사용량으로 표기하지 않는다.

처리 내역의 `새로고침`은 상태를 다시 읽고 실패한 업로드·클라우드 백업·서버 분석을 재시도한다. 서버 분석은 로그인 계정의 실패 작업만 재등록한다. 브라우저를 닫아 원본 파일이 사라진 업로드 오류는 다시 선택 버튼을 보여 주고 날짜·곡 확인 화면으로 이동한다. 버튼은 일반 중립색으로 표시하고 재시도 중에는 중복 실행을 막으며 결과를 같은 카드에서 알린다.

저장 시간과 백업 상태는 실제 값으로 표시한다. 백업 중·오류·기기 전용 상태를 단순 ‘백업 완료’로 치환하지 않는다. 곡 확인은 한 진입점으로 통합하고 실제 확인 대기 작업 수를 표시한다.

보관함은 내 곡과 다르게 **월별 흰 카드 안에 간결한 녹음 행들을 묶는다**. 월 안의 행 구분선은 표시하지 않는다. 제목 아래 날짜·공연/레슨/연습·길이를 표시하고 오른쪽 꺾쇠로 같은 카드 안의 플레이어를 펼친다. 1,000개 이상 파일에서 기존 지연 렌더링을 유지한다.

파일 형식 전체·곡 전체 필터를 목록 위 선택 버튼의 왼쪽에 한 줄로 배치한다. 선택 버튼은 우측 끝이다. 선택 모드의 전체 선택은 바텀시트를 열고 현재 필터 결과 전체, 보관함의 모든 녹음, 이번 달 녹음 중 범위를 고른다. 범위 선택은 기존 선택에 추가하며 취소는 선택 모드를 끝내고 선택을 비운다.

보관함 녹음 행은 가운데 제목·날짜·종류·길이를 보여주고 선택 모드에서 왼쪽 체크박스를 추가한다. 제목 영역을 누르면 그 행 아래에 플레이어가 아코디언으로 열리고, 다시 누르면 닫는다. 다른 녹음을 열면 이전 플레이어와 재생을 닫는다. 체크 선택만으로 카드 배경색은 바꾸지 않는다.

최종 합친 시안은 `design-system/library-merged-preview.html`이다. 기본 목록에는 체크박스를 숨기고 연보라 R16 선택 바에 `선택`만 둔다. 선택을 누르면 각 녹음 왼쪽에 체크박스가 나타나고 바 왼쪽에 `전체 선택`과 가까이 붙은 `취소`, 오른쪽에 `N개 선택`과 일괄 더보기를 둔다. 취소는 선택을 모두 해제하고 기본 상태로 돌아간다. 체크된 녹음도 흰 카드이며 제목을 눌러 플레이어를 펼칠 수 있다. 월별 흰 카드 안 녹음 사이의 구분선과 플레이어 위 구분선은 표시하지 않는다. 개별 더보기는 펼친 플레이어 오른쪽의 최소 44px 터치 영역에 둔다. 플레이어는 44px 터치 영역 안에 36px 원형 재생 면을 쓰고, 재생 버튼 터치 영역과 진행 바 사이의 간격은 17px로 두고, 진행 바에 남은 가로 폭을 우선 배분하되 시간은 줄바꿈 없이 한 줄로 유지한다. 350px 이하에서 시간 글씨만 10px로 줄인다.

목록 상단에는 항상 `#F3ECFF` R16 선택 행을 둔다. 선택 모드의 전체 선택은 현재 필터 결과에 적용한다. 개별 더보기 바텀시트는 정보 수정·저장·보컬 분석을 우선 보여주고 기타 작업으로 비교·삭제를 제공한다. 일괄 더보기 바텀시트는 곡 지정·종류 변경만 제공한다. 보컬 분석은 녹음별 더보기에서만 진입한다. 아코디언 플레이어의 속도와 A/B 지점 조작은 표시하지 않는다. 버튼 터치 영역은 44px 이상, 카드 안쪽은 디자인 시스템의 20px 곡률과 여백을 따른다.

개별 녹음의 보컬 분석은 연결 곡의 보컬 연구소로 이동한다. 보관함에서는 선택한 녹음이 1개 이상이며 전부 같은 곡으로 지정되어 있을 때만 일괄 더보기의 `보컬 분석`을 표시한다. 곡 미지정·서로 다른 곡 선택 시 버튼 대신 `같은 곡으로 지정된 녹음만 분석할 수 있어요.`를 짧게 안내한다. 한 곡의 여러 녹음 비교는 곡 상세에서 같은 곡의 녹음을 선택한 경우에만 제공한다. 분석 자료를 생성하거나 임의 수치를 채우지 않는다.

보관함의 `곡 확인 필요 N건`은 내 곡의 `나의 공연`과 같은 강조 행을 쓴다. 연보라 `#F3ECFF` 면, 연보라 테두리 `#DCC1FF` 1px, R20, 최소 높이 64px, 좌우 18px, 파형·화살표 보라 `#7A32F5`, 제목 16px·700을 쓰고 기존 링크와 실제 대기 건수를 유지한다. 서버 분석 미노출 시 보이는 곡 확인 링크에도 같은 스타일을 적용한다.

### 공통 녹음 목록 (2026-11-09)

보관함의 녹음 행과 인라인 플레이어를 내 곡 상세의 녹음 탭·기록 영역, 레슨 상세, 일정의 연결 녹음·독립 녹음, 대표 테이크처럼 실제 녹음이 나오는 목록에 재사용한다. `app/recording-list.css`의 공통 행을 사용하며 제목 한 줄 말줄임, 날짜·종류·길이의 보조 정보, 보라 파형, 오른쪽 펼침 표시, 흰 카드와 구분선 없는 행을 공유한다. 재생 버튼은 44px 터치 영역 안의 36px 보라 원, 진행 바와의 간격 17px, 한 줄 시간, 48px 더보기 영역(350px 이하 44px)을 사용한다. 펼친 플레이어는 연보라에 가까운 `#F8F6FD` R14이며 속도·A/B 조작은 표시하지 않는다.

화면 고유 선택 방식은 유지한다. 내 곡 상세의 기본 전체 선택을 유지하고, 녹음 전체선택 행에는 선택 개수만 표시하고 더보기 버튼은 두지 않는다. 선택 0개일 때 하단 보컬 분석 버튼을 숨긴다. 1개 이상 선택하고 모두 같은 곡이면 하단 보컬 분석을 표시한다. 일정·레슨의 연결 관계는 바꾸지 않는다. 보관함 개별 녹음의 더보기에서 보컬 연구소로 가면 **그 한 녹음 ID만** 선택하여 분석한다. 다른 화면의 녹음별 더보기도 해당 녹음 하나를 연구소에 넘긴다. 곡 상세에서 사용자가 여러 녹음을 명시적으로 선택한 경우에만 그 선택 묶음을 넘긴다. 선택해도 카드 배경은 흰색이고 제목을 누르면 플레이어가 열린다.

## 9. 곡 확인

상단은 뒤로가기와 곡 확인 제목 바로 옆 ⓘ만 둔다. 설정 아이콘은 숨기고, 이를 통해 열리던 ‘가사 없는 곡용 기준 만들기 (고급)’ 영역도 화면에 노출하지 않는다. 기존 저장 기준과 자동 매칭 데이터는 유지한다. ⓘ는 제목과 함께 스크롤하며 고정하지 않는다. 터치하면 그 아래에 “곡 상세의 원문 가사와 비교해요. 첫 구간에서 찾지 못하면 다른 구간을 순서대로 확인하고, 일치하면 멈춰요.” 도움말을 표시한다. 같은 아이콘을 다시 누르거나 다른 작업·스크롤을 하면 닫는다. 분석 현황은 흰 카드 한 장이며 내부 가로·세로 구분선을 없앤다. ‘확인 필요 / 곡 자동 지정 / 대기·분석 중’ 수치는 같은 크기로 표시한다. 확인 필요 항목만 보라색으로 강조한다. 보컬 측정 완료 `완료/전체`는 헤더 보조 정보다.

‘미지정 녹음’ 제목부터 상태 탭과 전체선택 행까지 한 묶음으로 상단에 고정한다. 스크롤할 때 헤더와 분석 현황은 올라가고 이 묶음만 남는다. 선택 행은 `#F3ECFF` 면이다. 왼쪽 전체선택, 오른쪽 선택 N개를 둔다.

전체선택과 각 녹음의 체크박스는 같은 20px·R5 컴포넌트를 사용한다. 미선택은 흰 바탕·회색 테두리, 선택은 `#7A32F5` 채움·흰 체크다. 전체선택은 현재 필터의 모든 녹음이 선택된 경우에만 선택 상태로 표시한다.

| 선택 상태 | 표시·동작 |
|---|---|
| 0개 | 전체선택, 개수 숨김 |
| 1개 이상·전체 미만 | 전체선택 + 오른쪽 ‘선택 N개’ |
| 전체 | 전체선택 체크·강조, 반복 선택 시 전체 해제 |

별도 선택해제 버튼은 두지 않는다. 녹음 카드는 제목/메타정보 → 플레이어 → 곡 확인 행 순서다. 추천된 곡 행은 카드 하단 전체 폭의 회색 `#F2F4F7`, 식별 불가·분석 실패 행은 라벤더 `#F3ECFF`이며 오른쪽 꺾쇠를 둔다. 행을 누르면 곡 선택 바텀시트를 열고, 선택 결과는 카드에 반영한다. 하단 ‘추천대로 곡 지정’에서 저장한다.

분석 시작을 누르면 30초 한 구간을 먼저 전사하고, 등록된 원문 가사 또는 기준 녹음과 일치하지 않을 때만 30초 클립을 3초씩 겹치게 이어서 확인한다. 맞는 가사를 찾으면 즉시 멈추고, 최대 파일당 10분까지만 본다. 목소리가 감지되지 않는 구간은 유료 전사를 건너뛴다. 네트워크·서버·파일 디코딩 오류는 전체 탐색의 조건이 아니라 해당 오류로 표시한다. 시작 전 최대 전사 구간과 비용 상한을 확인하고 진행 중 현재 구간을 표시한다. 저장한 전사 구간은 재시도 시 재사용한다. 최종 곡 지정은 사용자가 확인 후 적용한다.

녹음별 더보기의 ‘전사 확인’은 별도 전체 페이지를 연다. 해당 계정의 녹음인지 확인한 뒤 저장된 첫 분석 문장과 추가 구간 전사문을 시간 순서의 흰 카드(R20, 안쪽 16px, 간격 12px)로 표시한다. 전사문은 줄바꿈을 보존하고 긴 문장도 카드 밖으로 넘치지 않는다. 없으면 빈 상태를, 계정이 바뀌면 내용을 즉시 가린다.

분석 시작(왼쪽 보조) / 추천대로 곡 지정(오른쪽 주요)은 같은 52px 높이로 화면 하단에 고정한다. Safe Area를 확보하고 마지막 본문을 가리지 않는다. 페이지네이션은 없으며 실제 30개 초과일 때 더 보기로 30개씩 추가한다. 선택 상태와 스크롤 위치는 유지한다.

분석 수치는 원천이 서로 다르다. 확인 대기 작업 수를 모든 미지정 파일 수로 표시하지 않는다. 시안의 `1546/1546 · 779 · 0 · 310`은 과거 화면 예시이며 운영 데이터로 하드코딩하지 않는다.

## 곡 상세 적용 기준 (2026-11-09)

승인 기준은 `Vocalzip_Song_Detail_Preview.html`의 마지막 검토본이다. 실제 계정에서는 예시 수치를 사용하지 않고 곡·녹음·연습·레슨 데이터를 계산한다. 헤더는 곡 상세, 상단은 내 곡의 최근 연습곡과 같은 그라데이션 카드이며 곡명·실제 요약을 표시한다. 곡 상세의 작품명은 표시하지 않는다. 대시보드는 흰 R20/16px 카드, 3개 수치 사이에 구분선이 없고 목표가 있는 경우 텍스트 한 줄만 쓴다. 최근 6개월은 선형 그래프와 월별 분·횟수를 같이 표시한다.

탭은 녹음(기본) / 가사 / 악보 / 활동 기록 / 레퍼런스다. 레퍼런스 탭에는 MR 반주를 AR 레퍼런스 위에 같은 위계로 배치한다. AR 레퍼런스 제목·링크 목록과 추가는 레퍼런스 탭 안에서만 제공한다. 제목과 빈 상태를 감싸는 흰 박스는 두지 않으며, 제목 오른쪽 추가는 다른 곡 상세 영역과 같은 44px 회색 선형 `+` 버튼(접근성 이름: AR 레퍼런스 링크 추가)으로 통일한다. 상단의 별도 AR 카드는 제거한다. 공연 전용 탭은 제거한다. 활동 기록은 타임라인 대신 공연·오디션 / 레슨 기록 / 연습 기록 / 숙제의 독립 영역으로 나눈다. 레슨과 연습은 기존 상세를 열고, 연결된 공연은 기존 공연 상세로 이동한다. 공연·오디션 영역에는 연결된 공연 항목만 표시하고 녹음은 녹음 탭의 전체 목록에서 확인한다. 녹음 탭은 전체 녹음 목록을 계속 제공한다. 탭은 공통 투명 바탕·44px 캡슐·선택 `#EDE1FF`를 재사용한다. 각 영역은 18px 제목과 우측 44px 선형 도구 아이콘, 개별 흰 카드 R20/16px/12px 간격을 쓴다. 레슨 기록·연습 기록·숙제 제목 오른쪽에는 44px `+` 버튼을 두고, 해당 곡을 미리 선택한 각 기록·일정 등록 시트를 연다. 녹음 제목 옆 작은 범주 칩은 기존 일정 범주색과 같이 연습 `#7A32F5`/`#F3ECFF`, 레슨 `#078994`/`#E8F6F6`, 공연·오디션 `#DE3E0A`/`#FFF0E9`로 표시한다. 종류와 실제 기록 연결을 구별한다. 연결된 기록이 있을 때만 칩에서 날짜·시간·만족도·메모 등 실제 기록을 짧은 바텀시트로 연다.

그라데이션 곡 요약 카드 바로 아래의 타이머·녹음 비교 아이콘 줄과 접힌 ‘곡 정보’ 카드를 표시하지 않는다. 성장 카드 아래에는 ‘나의 레퍼토리’ 제목과 상태, 숙련도, 키 정보, 대표 테이크를 각각 독립된 흰 카드로 표시한다. 상태부터 키 정보까지는 카드마다 왼쪽 항목명·오른쪽 현재 값·꺾쇠를 한 줄에 배치하며 긴 값은 말줄임한다. 대표 테이크는 아이콘·제목·녹음명을 두 줄로 표시한다. 각 카드는 R20·패딩 16px·간격 12px이며 내부 구분선이나 숙련도·키의 2열 배경은 두지 않는다. 빈 값은 입력하기·미평가·미입력·지정 안내로 보이고 각 영역은 44px 이상 터치 가능하다. 보라색 #7A32F5, 연한 면 #F3ECFF, 본문 #344054를 재사용한다. 곡 상세의 곡 정보 수정에서는 작품·배역 입력을 표시하지 않는다. 작품·배역은 공연 및 공연 회차에서 관리한다. 기존 곡에 저장된 작품·배역 데이터는 삭제하지 않는다. 각 항목은 기존 편집 시트를 열며 대표 테이크의 기존 플레이어도 유지한다. 우측 메뉴의 ‘나의 레퍼토리 설정’도 유지한다. 카드 안에는 공연 이력을 넣지 않으며 연결 공연은 활동 기록에서만 확인한다. 시트는 고정 분석 버튼보다 위에 표시된다. 녹음 비교는 기존 녹음별 메뉴 등 다른 진입점에서 유지한다. 녹음 목록은 개별 카드에 선택 버튼·제목·메타·더보기 및 인라인 플레이어를 둔다. 전체선택은 녹음 제목 아래 `#F3ECFF` R16 행의 왼쪽, 선택 개수는 오른쪽에 둔다. 녹음 탭 진입 시 목록의 모든 녹음을 기본 선택한다. 화면 맨 아래 Safe Area를 확보한 흰 고정 면에는 녹음을 하나 이상 선택했을 때만 52px 높이의 전체 폭 ‘보컬 분석하기’ 버튼과 그 바로 아래 `녹음 N개 · 분석과 비교 보기` 링크를 표시한다. N은 이 곡에 연결된 실제 녹음 수이며 링크는 해당 곡의 `#/vocal-lab/{songId}`로 이동한다. 선택 0개 또는 녹음이 없으면 하단 면과 버튼을 숨긴다. 선택 개수는 목록 상단 행에만 표시하며, 실제로 선택된 녹음이 있을 때는 녹음 플로팅을 숨긴다. 보컬 분석하기는 선택한 파일 모두를 보컬 연구소에 넘긴다. 연구소에서는 선택한 날짜가 모두 활성화되고 플레이어로 파일을 바꿔 볼 수 있다. 분석 엔진은 파일별로 실행한다. 일반 재생·수정·저장·분석은 기존 실제 미디어 동작을 재사용한다. 녹음 시작 플로팅은 해당 곡을 미리 선택한 녹음 화면으로 이동한다. 곡 상세에서는 ‘보컬 변화’와 ‘추천 연습’ 접기 영역을 표시하지 않는다. 연구소 자체의 추천 연습 기능은 유지한다.

가사 탭은 원문·한글 해석/번역·발음/호흡/감정 메모를 각각 흰 R20 카드로 표시한다. 카드 제목 아래에는 저장된 내용의 첫 줄을 한 줄 말줄임으로 미리 보여주고, 비어 있으면 ‘입력한 내용이 없습니다’를 표시한다. 카드를 누르면 해당 항목만 편집하는 바텀시트가 열린다. 저장 후 카드 미리보기를 즉시 갱신하며 다른 가사 항목과 기존 녹음·연습 데이터는 보존한다.

곡 상세 녹음의 전체선택 행은 왼쪽 체크박스와 오른쪽 선택 개수만 둔다. 보컬 분석은 선택한 녹음이 있을 때 하단 버튼으로만 진입하며 같은 곡의 선택 파일 전체를 연구소에 전달한다.

녹음 전체선택과 개별 선택은 체크박스 상태만 바꾸고 카드 배경은 항상 흰색으로 유지한다. 체크박스를 다시 누르면 해당 녹음만 해제한다. 선택 여부와 관계없이 카드의 제목 영역을 누르면 인라인 플레이어를 펼치거나 접는다. 선택 변경만으로 열려 있는 플레이어를 닫지 않는다.

## 10. 네비·플로팅·고정 영역

메인 네비는 홈 / 내 곡 / 보관함 / 일정 4개다. 중앙 녹음 탭을 추가하지 않는다. 선택된 화면은 아이콘·라벨·연한 보라 면으로 표시한다. 아이콘보다 라벨을 한 단계 연하게 둔다.

네비는 70px 높이의 흰 반투명 면(불투명도 58%), blur 24px, 캡슐 모서리다. 홈과 나머지 화면의 홈/내 곡/보관함/일정 아이콘은 동일한 Phosphor Regular(선형) 글리프를 22px로 사용한다. 선택·미선택 모두 선형을 유지하고 색상과 선택 면으로 상태를 구분한다. 기본 아이콘은 `#475467`, 선택 아이콘은 `#7A32F5`다. 선택 면은 `#EDE1FF`이며 아이콘보다 라벨을 연하게 둔다. 녹음 시작은 네비 위 12px 간격의 **56 × 56px 원형 마이크 버튼**이다. 눈에 보이는 텍스트 대신 접근 가능한 이름 '녹음 시작'을 제공하며, 아이콘은 네비와 같은 Phosphor Regular 22px이다. 홈·내 곡·보관함·일정이 같은 위치·크기·그라데이션을 쓴다. 버튼을 누르면 해당 버튼 중심에서 보라 원이 화면 전체로 커지며 점차 검어지고, 다크 녹음 화면이 나타난다. 동작 감소 설정에서는 전환 애니메이션을 생략한다.

홈의 ‘N일 연속’은 **화면에 선택한 주**의 마지막 연습일부터 날짜를 거슬러 센다. 일요일·월요일·화요일처럼 주 경계를 넘더라도 매일 이어졌으면 3일이고, 하루라도 쉬었다면 그다음 연습일부터 새로 센다. 그 주에 연습이 없으면 0일이다. 미래 날짜의 연습은 계산하지 않는다.

녹음·곡 확인·재생처럼 집중 작업을 하는 페이지는 자체 동작 영역을 사용한다. 선택 모드에서는 플로팅 버튼과 선택 작업 바가 겹치지 않는다.

녹음 시작 플로팅 아이콘은 홈·내 곡·보관함·일정 모두 Phosphor Regular `ph-microphone`(글리프 `e326`), 22px, 흰색을 사용한다. 선택 상태에도 아이콘 형태·굵기를 바꾸지 않는다.

### 헤더와 홈 로고

- 일반 페이지 헤더 제목은 내 곡 기준 26px / 34px / 700, `#101828`로 맞춘다. 카드·섹션 제목에는 페이지 제목 크기를 적용하지 않는다.
- 홈 `Vocalzip`도 26px / 34px / 700이고, 파형 로고는 28px, 글씨와 간격은 8px이다.
- 대제목 옆 실제 개수는 13px / 600 / `#7A32F5`다. 배경·테두리·그림자·배지 패딩 없이 숫자와 단위만 표시한다.
- 오른쪽 일반 도구 아이콘은 `#667085`로 통일한다. 터치 영역은 최소 44px다.

### 홈 주간 연습

- 날짜 선택 영역에는 긴 배경 바를 두지 않는다. 양끝 화살표는 18px, 연회색 `#F2F4F7` 원은 지름 32px, 실제 터치는 44px이다. 화살표 색상은 일정 캘린더의 `--ink-2`를 공유한다.
- 날짜 범위는 섹션 제목보다 낮은 14px / 600 / `#475467`, 자간 `0.01em`, 숫자 폭은 tabular-nums로 한다. 대시 양옆에 공백을 둔다.
- 현재 연도 안의 주: `11.2 – 11.8`. 같은 다른 연도: `2025.12.16 – 12.28`. 연도 경계: `2025.12.29 – 2026.1.4`. 연도와 월·일은 같은 크기·굵기다.
- 주를 바꿔도 카드 높이를 유지한다. 하단 목표·달성률·연속 영역은 3열, 셀 콘텐츠 최소 36px, 위 패딩·선 포함 최소 47px로 예약한다. 미래 날짜의 시간 문구가 없어도 일자 영역의 높이는 유지한다.
- 연속 연습은 0~1일이면 `#667085`, 2일 이상이면 아이콘과 문구 모두 `#7A32F5`다.
- 주간 목표 시간이 있고 실제 연습 시간이 목표 이상이면 오른쪽 총 시간 숫자와 `분`을 `#7A32F5`로 표시한다. 미달·미설정은 기존 중립색이다.
- 지난 날짜에 별도 시간 목표가 없으면 하루 30분으로 목표치·달성률을 계산한다. 기존 목표가 있으면 우선 사용한다. 실제 연습 시간이나 원본 기록은 바꾸지 않는다.
- 오늘의 목표 완료 개수는 제목 바로 옆에 `완료 / 전체 완료` 형태로 둔다. 오른쪽에는 설정 아이콘만 둔다. 목록 체크가 바뀌면 같은 위치의 개수가 갱신된다.

## 11. 상태·검수 기준

- 데이터가 없을 때 안내와 바로 실행할 행동을 제공한다. 임의의 예시 곡이나 수치를 실제 계정에 넣지 않는다.
- 로딩 중 안내를 표시하고, 데이터 도착 후 목록이 비어 있는 채로 남지 않게 한다.
- 독립 HTML은 스크립트가 차단되어도 초기 목록과 선택 네비가 보이도록 정적 초기 마크업을 제공한다.
- 운영 화면은 기존 캐시와 새 데이터를 사용한다. 사용자 입력·재생 중·선택 상태를 백그라운드 갱신으로 지우지 않는다.
- 내 곡: 카드 분리·12px 간격·필터 면·구분선 없음·회색 검색·곡 선택된 녹음 이동을 확인한다.
- 보관함: 선택 네비·뒤로가기 없음·월별 목록·검색·형식/곡 필터·가져오기·선택·재생 페이지를 확인한다.
- 곡 확인: 동일 수치 크기·선택 수 우측·고정 하단 버튼·긴 제목·Safe Area·더 보기를 확인한다.
- 320 / 390 / 430px와 모바일 Chromium / WebKit에서 가로 넘침과 버튼 겹침을 확인한다.

홈 최근 연습곡 카드의 배경은 한 단계 진한 라벤더 그라데이션 `#E8D8FF → #EFE3FF(52%) → #F5EDFF`(135deg)로 한다. 카드의 제목·메타정보는 기존 중립 텍스트색을 사용한다.

### 마지막 통일 요청

모든 화면의 같은 역할 제목은 Pretendard 크기·굵기를 공유한다. 기본 카드 여백은 16px, 카드 사이 12px다. 페이지 좌우는 12px, 카드 내부는 16px로 각각 한 번만 적용한다. 검색·설정의 배경은 없고 최소 터치 크기는 44px이다. 하단 네비는 현재 홈의 528px 최대 폭·70px 높이·반투명 면을 사용한다. 녹음 플로팅은 현재 홈의 560px 콘텐츠 기준 위치와 56px 원형 크기를 공유한다. 마지막 콘텐츠가 고정 요소 아래에 가리지 않게 한다. 연보라 필터·선택 면과 바텀시트 선택 동작은 공통 규칙이며, 목록 행 높이와 강조 카드 여백은 예외로 남긴다.



## 주간 탐색 범위와 현재 홈 셸 일치

- 최초 녹음·연습·레슨·공연 일정이 있는 주까지만 이전으로 이동한다. 그 주에서는 이전 버튼을 비활성화한다.
- 다음 이동은 현재 주와 마지막 미래 일정 주 중 늦은 주까지다. 미래 일정이 없으면 이번 주의 다음 버튼을 비활성화한다. 과거 주에서는 이번 주 방향으로 이동할 수 있다.
- 삭제된 자료와 취소된 일정은 범위를 늘리지 않는다. 기록이 전혀 없으면 이번 주만 표시한다.
- 버튼뿐 아니라 스와이프·휠·키보드 탐색도 동일한 범위로 제한한다. 비활성 버튼은 옅게 표시하고 실제 disabled 상태를 제공한다.
- 내 곡·보관함의 외부 셸은 현재 홈의 실제 규격을 공유한다: 최대 폭 560px, 좌우 12px, 위 max(8px, Safe Area), 헤더 44px + 아래 8px, 아래 콘텐츠 여유 142px + max(12px, Safe Area). 네비 최대 폭 528px·좌우 16px·높이 70px, 녹음 버튼 위치도 560px 콘텐츠 기준이다.

### 공통 셸: 네비·녹음·분석 버튼 (2026-11-09)

홈의 4개 하단 메뉴와 일반 화면의 메뉴는 같은 70px 유리 도크를 사용한다. 최대 폭 528px, 좌우 16px, Safe Area 위 12px, 내부 패딩 8px, 항목 높이 54px·아이콘 22px·라벨 11px, 선택 배경 `#EDE1FF`, 표면 `rgba(255,255,255,.58)`·블러 24px이다. 녹음은 도크 오른쪽 위 82px에 둔 56×56px 원형 아이콘 전용 버튼으로 통일한다. `#9557FF → #7A32F5 → #6D2BE5` 135도 그라데이션과 동일한 그림자를 사용하고, 녹음 집중 화면·네비 없는 분석 화면 및 녹음 선택 작업 중에는 숨긴다. 누르면 기존 확장 전환으로 녹음 화면을 연다.

선택 녹음의 하단 `보컬 분석하기`는 동일한 52px 분석 동작을 유지하고, 깊은 보라→밝은 보라 그라데이션·작은 별 아이콘·주기적 빛 스침으로 AI 느낌을 준다. 버튼 안에서만 움직이며, `prefers-reduced-motion`에서는 정적 그라데이션과 아이콘을 쓴다. 선택 0개 또는 분석할 수 없는 곡 조합일 때는 버튼을 노출하지 않는다.

## 13. 일정·녹음 확장

- 일정의 월간 요약은 '11월 연습 · 시간 · 횟수'를 한 줄로 표시한다. 바로 아래 연보라 `#F3ECFF` 한 줄에는 곡명·시간·횟수만 나타낸다. 연습 시간 상위 최대 5곡을 4초 간격으로 순환하며, 정렬 스위치·순번·다음 화살표는 표시하지 않는다. 호버·포커스·화면 비활성 중에는 자동 전환을 멈춘다.

- 추천 목록은 최대 세 개다. 기간 안의 숙제를 먼저 표시하고 연결된 레슨 숙제를 우선한다. 나머지는 분석 신뢰도를 충족한 최근 녹음에서 같은 측정 문제가 두 번 이상 나온 추천 중 빈도와 강도 순서로 채운다. 데이터가 부족하면 근거 없는 분석 추천을 채우지 않는다. 홈 ‘오늘의 목표’ 카드에서 흰색 바탕의 연한 라벤더 R14 추천 행을 바로 표시하고 각 행의 44px ‘따라 하기’로 진입한다. 숙제 목록의 진행 중 카드에도 같은 진입을 둔다. 목표 설정 시트의 추천은 목표 담기만 제공하고, 일반 연습 기록 입력 시트에는 추천 진입을 중복 배치하지 않는다. 기존 목표 체크와 수동 기록 편집은 유지한다.
- `연습하기`는 별도 전체 페이지다. 단계 번호, 연습 안내, 전체 진행률, 현재 단계, 영상 또는 시작·종료 타이머를 표시한다. 영상이 없는 단계나 사용자가 영상을 부적절하다고 평가한 단계는 설명과 타이머로 진행한다. 영상의 실제 길이가 확인되면 그 길이를 단계 진행률의 비중에 사용하고, 타이머 단계는 안내된 연습 시간을 사용한다. 영상 시청만으로 연습 완료를 표시하지 않는다.
- 숙제 문구가 롱톤·지속음 또는 기준음 따라 부르기와 명확히 일치하는 경우에만 검토한 영상을 연결한다. 영상 평가는 `맞아요`와 `맞지 않아요`로 받는다. `맞지 않아요`는 사용자 계정의 해당 숙제 ID 또는 연습 종류와 영상 ID 조합에 저장하여 다음 추천에서 제외한다. 다른 숙제와 연습 종류까지 제외하지 않는다. 영상은 외부 유튜브 임베드로 재생하고, 재생할 수 없을 때는 타이머로 계속할 수 있다.
- 마지막 단계를 마치면 별도 저장 동작 없이 직접 진행한 시간을 초 단위로 보존하고 분 환산값을 연습 기록에 한 번만 저장한다. 추천 제목과 분석 종류에 맞는 기존 연습 카테고리와 세부 항목을 연결하고, 적절한 카테고리가 없으면 새로 만들어 같은 기록에 연결한다. 곡 숙제라면 곡 연결도 유지한다. 저장에 실패한 경우에는 완료 화면에서 다시 저장할 수 있다. 영상 단계는 영상이 끝나고 실제 시청 분량이 80% 이상일 때 다음 단계로 이동할 수 있으며, 재생 불가 시 타이머로 전환한다. 연결된 숙제의 수행·완료와 오늘 목표 체크도 함께 반영한다. 실제 연습 시간과 녹음 길이·영상 시청 길이를 혼동하지 않는다. 화면의 수치와 단계는 실제 분석·숙제 데이터로 채운다.
- 따라 하기 화면은 백그라운드 데이터 갱신 때 재생 중인 영상과 진행 상태를 다시 만들지 않는다. 영상 자체의 터치·키보드·전체화면 조작을 막고 하단 앱 버튼으로만 재생한다. 영상을 다 듣기 전에는 다음 단계 버튼을 숨긴다. 영상이 끝나면 다음 단계가 나타나고, 마지막 단계까지 마친 뒤에만 ‘연습 끝내기’를 표시한다. 영상이 없는 단계의 시작·종료는 직접 연습 시간을 재는 타이머다. 하단 조작 영역은 최대 폭 560px, 좌우 18px, 최소 52px 버튼, Safe Area를 포함해 화면 아래에 고정한다. 뒤로가기·탭 닫기·앱 전환·화면 꺼짐으로 페이지를 떠나거나 숨기면 영상과 타이머를 즉시 멈추고 숨겨진 시간은 연습 시간에 더하지 않는다. 돌아왔을 때 자동 재개하지 않는다.

## PDF 개인 필기 (Phase 07-C, 2026-11-10)

곡 상세 악보 탭은 항목 전체를 누르면 통합 뷰어로 연다. 별도의 눈/필기 진입 아이콘은 제거하고 정보 수정·삭제는 독립된 보조 동작으로 유지한다. 원본 PDF 열기는 뷰어 설정에 둔다. 기존 전체 작업 페이지(VZ.sheet)의 최대 폭 560px, 상단 뒤로/18px 제목, 라벤더 배경·Pretendard·Safe Area를 재사용한다. 하단 `완료` 버튼은 두지 않고 상단 `←`(돌아가기)로 닫는다(2026-11-11). 별도 바텀시트나 하단 네비를 겹치지 않는다.

도구는 Phosphor 선형 20px, 터치 최소 44px로 통일한다. 이동/펜/형광펜/지우개·되돌리기/다시 실행, 색상/굵기·펜만 입력, 페이지 이동·100/150/200% 확대를 제공한다. 선택 도구는 공통 선택 면 #EDE1FF와 #7A32F5, 일반 도구는 #344054. 일반 화면의 도구는 좁은 폭에서 줄바꿈하고, 전체화면에서는 한 줄 스크롤을 사용한다. 악보는 흰 페이지 위, 주변 면 #E8E4F0이며 본문 내부에서만 스크롤한다. 읽기/이동 모드에서는 스크롤, 그리기 모드에서는 펜 입력을 우선한다.

한 획마다 기기에 저장하고 상단 `←`로 닫는 집중 편집 화면이다. 하단 버튼은 필기 저장 실패 때만 `다시 저장`으로 나타난다. 클라우드 저장 완료로 단정하지 않고 기존 동기화 상태와 구분한다. 실패 시 빨간 상태 문구·다시 저장을 제공하고 실패 입력을 닫기로 조용히 버리지 않는다. 원본 PDF와 다른 PDF 해시의 필기는 겹치지 않는다. 손가락/합성 pen 검사는 iPad Pencil 실기기 인수를 대신하지 않는다.

### 악보 작업 화면 고도화 — 2026-11-10 (후속 기준)

### 악보 PDF 로딩·손가락 페이지 이동 — 2026-11-10

아이폰 악보 작업에서는 이동·펜·형광펜·지우개·선택을 한 줄에, 되돌리기·다시 실행·페이지 필기 삭제·설정·전체화면을 다음 줄에 배치한다. 각 도구의 터치 영역은 44px 이상이다. 페이지 번호와 이전·다음 버튼은 악보 위에 유지한다. PDF 주소·뷰어·다운로드·문서 준비 단계의 상태를 표시하고 지연 시 오류 문구를 제공한다. PDF 주소가 준비된 뒤 뷰어가 실패하면 원본 PDF를 열 수 있는 링크를 보여준다. 원본과 기존 필기는 보존한다.

### 악보 첫 페이지 우선 표시 — 2026-11-10

악보 목록 진입 시 뷰어 모듈과 앞쪽 악보의 서명 URL을 미리 준비한다. 악보를 누르면 전체 원본 다운로드도 즉시 시작해 뷰어 준비·첫 페이지 렌더링과 겹친다. 전체 원본이 먼저 도착한 경우에는 그 데이터로 문서를 한 번만 연다. 첫 페이지를 먼저 볼 수 있는 경우에도 해시 확인 전에는 필기를 잠근다. 이 준비 동작은 원본이나 기존 필기를 수정하지 않는다.

### 악보 페이지 탐색·마지막 위치·무대용 보기 — 2026-11-10

악보 작업 화면의 페이지 번호를 누르면 24쪽 단위로 페이지 미리보기를 열고, 입력한 번호로 바로 이동할 수 있다. 작은 미리보기는 보이는 항목만 저해상도로 그린다. 상단 ‘다른 악보’ 버튼에서 전환 가능한 PDF 악보를 선택한다. 저장 실패 입력이 남으면 악보 전환을 막는다.

마지막 페이지와 확대율은 사용자 계정·악보 ID·R2 원본 키·SHA-256 검증값에 묶어 기기에 보관한다. PDF 내용이 달라지면 첫 페이지와 기본 확대율로 돌아간다. ‘저장 중… / 이 기기에 저장됨 / 저장 실패 · 다시 시도’는 별도 배지로 구분하고 클라우드 저장 성공을 확인하지 못한 상태를 클라우드 완료로 표시하지 않는다.

‘무대용 보기’는 기존 전체화면 레이아웃을 쓰되 필기 입력과 도구를 잠그고 페이지 조작과 편집으로 돌아가기만 잠깐 노출한다. 페이지 렌더링이 끝날 때까지 기존 페이지를 유지하고, 편집으로 돌아오면 같은 페이지와 필기를 보여준다. 기존 손가락 수에 따른 페이지 이동 규칙은 유지한다.

변경 기록: 2026-11-10 페이지 미리보기/번호 이동, 파일별 마지막 위치, 저장 상태, 무대용 보기, 같은 곡의 다른 악보 이동 추가.

‘다른 악보’ 목록은 현재 PDF를 제외한 계정의 모든 곡에 연결된 PDF를 같은 위계의 행으로 보여준다. 곡명을 14px/650으로, PDF 제목과 작품명을 12px 회색 보조 문구로 표시한다. 최근 연습 기록이 있는 전환 후보 중 가장 최근에 연습한 곡을 맨 위에 두고, 이어 현재 곡의 다른 PDF와 같은 작품명 또는 같은 공연의 곡을 우선한다. 나머지는 최근 연습 날짜순이며 같은 날짜는 기록 시각으로 구분한다. ‘최근 연습’과 ‘같은 공연’은 연보라 `#F3ECFF`/보라 `#7A32F5`의 작은 표시로 구분한다. 44px 이상 터치 영역, 흰 목록면/R10, 메뉴 R16과 최대 높이 42vh를 유지한다. 소유자의 PDF 키가 확인된 악보만 보여주고, 선택 시 해당 곡과 PDF로 전환한다.

변경 기록: 2026-11-10 같은 곡의 다른 PDF로 한정했던 악보 전환을 전체 곡의 PDF로 확장하고 최근 연습곡·같은 공연 순서를 적용.


### 악보 전용 표시 — 2026-11-10

기존 도구 행의 ‘악보 표시’에서 숨표·반복·컷·시작점을 고른다. 숨표와 시작점은 위치 탭, 컷은 생략할 구간을 긋고, 반복은 시작과 끝을 차례로 선택한다. 각 표시는 원본 PDF에 합성하지 않고 기존 개인 필기와 같은 계정·악보·PDF 해시·페이지에 묶인 벡터 획 하나로 저장한다. 기존 선택 도구로 표시 전체를 이동·크기 조절·삭제하며, 추가와 삭제는 각각 한 번의 되돌리기로 복구한다. 펜만 필기 설정의 손가락 스크롤과 무대용 보기 잠금 규칙을 그대로 따른다.

변경 기록: 2026-11-10 숨표·반복·컷·시작점 표시 도구 추가.

### 악보 영역 표기 설명·손글씨 변환 — 2026-11-10

악보 필기 화면은 기존 44px 도구 규격과 연보라 선택면을 따른다. '표기 알아보기'를 누르고 PDF 원본 위에 사각형을 그리면 해당 부분만 잘라 설명을 요청한다. 필기 선택 도구에서 획을 고르면 '텍스트로 변환'을 보여주며, 인쇄 악보를 제외한 선택 획만 흰 배경 이미지로 보낸다. 손글씨 변환 직전에는 선택 획이 OpenAI API로 전송된다는 확인을 받고, 표기 설명은 명시적으로 요청했을 때 NVIDIA Nano Omni로 선택 영역 이미지를 보낸다. 결과는 불확실성을 안내한다.

손글씨 결과는 편집 가능한 텍스트 메모로 페이지 위에 저장한다. 기본 동작은 원래 필기 보존이며 '저장 후 원래 필기 대체'를 별도로 선택해야 획을 제거한다. 변환 전 닫기, 저장한 메모 수정·삭제, 메모 되돌리기를 지원한다. 저장 배지는 실제 기기 저장만 표시하고 다른 기기 동기화를 암시하지 않는다. 원본 PDF 내용은 변경하지 않는다. 서버 기능은 소유자 허용 목록·비밀 키·기능 스위치가 갖춰졌을 때만 보인다.

운영 활성화: STT와 같은 Supabase 프로젝트에 `vzip-score-vision` Edge Function을 배포한다. 표기 설명에는 `nemotron_nano` NVIDIA 키를 사용하고 한국어 `label`·`explanation` JSON을 요청한다. 손글씨 변환에는 기존 `OPENAI_API_KEY`와 `STT_ENABLED`를 사용한다. 두 경로 모두 `STT_ALLOWED_USER_IDS`, `vzip_ai_owner_allowed` 소유자 검사를 재사용한다. 함수가 배포되기 전 UI는 숨김 상태다. 텍스트 메모는 이 기기의 계정별 저장소에 보관되며 기기 간 동기화는 제공하지 않는다.

변경 기록: 2026-11-10 선택한 악보 표기 설명과 선택 손글씨 변환, 결과 확인·수정·저장·취소 추가.

표기 알아보기 모드에서는 펜만 필기 설정과 관계없이 손가락 한 개로 사각형을 그릴 수 있다. 이 모드 동안 악보 영역의 터치 스크롤을 잠그고, 다른 도구로 전환하면 원래 이동 규칙을 복원한다.

변경 기록: 2026-11-10 아이폰에서 표기 사각형 선택 중 악보 페이지가 밀리는 입력 충돌 수정.

### 악보 아래 MR·녹음, 기기 보관, 완료 버튼 제거 — 2026-11-11

악보 페이지 바로 아래에 **한 줄** 오디오 막대를 둔다. 왼쪽은 곡의 MR을 보관함과 같은 공통 인라인 플레이어(보라 36px 원형 재생, 진행 바)로 재생하고, 오른쪽에 `녹음`·`MR+녹음` 알약 버튼(높이 44px, 연보라 #F6F1FF 면, #5B21B6 글자)을 둔다. 녹음 중에는 `● 시간`과 빨간 `정지`, 녹음 후에는 방금 녹음 플레이어와 보라 `저장`·`버리기`만 한 줄로 바꾼다. 제목 입력은 두지 않고 `곡 이름 녹음 M/D HH:MM`으로 저장하며 이름은 보관함에서 바꾼다. MR이 여러 개면 막대 위에 작은 선택을 둔다. 유튜브 MR은 펼쳐서 재생만 하고 `MR+녹음`은 업로드한 MR 파일에서만 켠다. MR+녹음은 마이크를 먼저 열고 MR을 처음부터 재생하며 MR이 끝나면 녹음을 멈춘다. 저장 전에는 저장·업로드하지 않고, 저장하지 않은 녹음을 남긴 채 뷰어를 닫으면 버리지 않고 이 곡의 녹음으로 보관한다. 전체화면에서는 아이콘만 보이고 오른쪽 페이지 이동을 피한다.

한 번 연 PDF는 계정·R2 키·크기·업로드 시각별로 기기(Cache Storage)에 검증된 SHA-256과 함께 최대 12개 보관한다. 다시 열 때는 1바이트 확인으로 저장소 원본의 크기·ETag가 같을 때만 기기 사본을 쓰고, 다르면 사본을 지우고 다시 받는다. 오프라인이면 기기 사본으로 연다. 악보를 삭제하면 기기 사본도 지운다.

뷰어에는 하단 `완료`가 없다. 상단 `←`가 닫기이며 필기 저장 실패 때만 하단 `다시 저장`이 보인다. 손가락 스와이프 규칙(펜만 필기 켬: 한·두 손가락, 끔: 두 손가락만)은 위 기준을 유지하고 브라우저 입력 경로로 자동 검사한다. 실제 iPhone/iPad 손 제스처와 MR 동시 녹음은 실기기 확인 대상이다.

변경 기록: 2026-11-11 악보 아래 MR 재생·녹음·MR+녹음 한 줄 막대, 열었던 PDF 기기 보관과 원본 변경 확인, 하단 완료 버튼 제거.

**간소화 배치(2026-11-11 후속).** 맨 위는 `악보 필기` 대신 곡 제목 한 줄(말줄임)과 오른쪽 `다른 악보` 아이콘이다. 필기 도구는 아이콘만 한 줄이며 오른쪽 끝 `더보기`에 되돌리기·다시 실행·페이지 필기 삭제·설정·무대용 보기·전체화면을 둔다(일반·전체화면 동일). 상태 배지와 손가락 안내 문구는 두지 않고, 불러오는 동안만 악보 위 가운데 어두운 알약 팝업을 띄운다. 오류는 빨간 문구로 남긴다. 쪽수 줄은 일반·전체화면 모두 악보와 오디오 막대 아래 한 줄로 고정하며 악보 위에 겹치지 않는다(겹치는 자동 숨김 방식은 2026-11-11 철회). 악보를 열면 원본 전체를 한 번에 받기 시작하고, 첫 페이지가 보이기 전까지 로딩 팝업에 `악보 불러오는 중 N%`를 표시한다.

**오디오 막대 상태.** 평소에는 `재생`·`녹음`·`재생+녹음` 알약 3개 한 줄이다. 재생·녹음을 시작하면 막대는 악보 왼쪽 아래에 떠 있는 작은 칩(깜박이는 점·시간·⏸·■, 시작 때 한 번 반짝임)으로 줄고 악보가 그만큼 넓어진다. ⏸는 MR과 녹음을 함께 멈추고 막대(`계속`·`정지`)를 다시 보인다. ■는 둘을 함께 정지하고, 녹음이면 `저장`·`버리기`로 바뀐다.

**무대용 보기.** 첫 페이지가 보이면 바로 쓸 수 있다(필기 검증 완료를 기다리지 않음). 필기는 꺼지고, 손가락 한 개 또는 두 개 가로 스와이프로 페이지를 넘긴다.
