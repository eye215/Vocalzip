# Kiro로 일 시키기

Kiro IDE에서 이 저장소를 열면 `.kiro/steering/`의 세 파일을 자동으로 읽어요. 이 파일에는 프로젝트 규칙, 기술, 파일 위치가 들어 있어요. 그래서 Kiro에게 매번 규칙을 다시 설명하지 않아도 돼요.

## 처음 한 번 준비

1. Kiro IDE와 Git을 설치하고 로그인해요.
2. GitHub에 로그인한 다음 `https://github.com/eye215/Vocalzip`을 내려받아요(Clone). 받은 폴더를 Kiro에서 열어요.
3. 회사 계정이면 개인 프로젝트에 써도 되는지 먼저 확인해요. 녹음 파일, 개인 정보, 비밀 키는 Kiro 대화에 넣지 않아요.

## 빨리, 깊게 시키기 (디자인 v5 정리)

v5 정리를 한 번에 한 줄씩 하면 너무 느려요. 지시서를 `.kiro/specs/v5-cleanup/`에 새로 넣었어요. 지금 상태를 직접 재 본 숫자도 들어 있어요. 예를 들어 보라색 값을 254군데에 직접 적어 두었고, 카드 모양 이름이 36가지예요.

1. Kiro 채팅 아래쪽에서 **Autopilot**을 켜요. 그러면 단계마다 허락을 묻지 않아요.
2. 아래 문장을 그대로 붙여 넣어요.

> git으로 main을 받은 다음 `.kiro/specs/v5-cleanup/`의 requirements.md와 tasks.md를 읽고, Batch 1부터 4까지 순서대로 끝까지 해 줘. 묶음마다 새 브랜치, 테스트, PR까지 하고 멈추지 말고 다음 묶음으로 넘어가. 화면이 눈에 띄게 달라질 때만 물어봐. 다 하면 growth-v2 Phase 1을 시작해 줘.

PR이 올라오면 Claude가 검토하고, 화면 사진을 보여 드린 다음 배포해요.

## 성장 완전 재개편 시키기

지시서는 `.kiro/specs/growth-v2/`에 있어요.
- `requirements.md`: 무엇을 만들지
- `design.md`: 어떻게 만들지
- `tasks.md`: 단계별 할 일

Kiro 채팅에 아래 문장을 그대로 붙여 넣어요.

> `.kiro/specs/growth-v2/` 스펙의 tasks.md에서 Phase 1을 해 줘. 새 브랜치를 만들어 작업하고, 테스트를 돌린 다음 PR을 올려 줘. main에는 바로 올리지 마.

Phase 하나가 PR로 올라오면 Claude 세션에 "Kiro PR 올라왔어"라고 알려 주세요. Claude가 검토하고 자동 검사를 확인한 뒤, 화면 사진을 보여 드리고 배포해요. 그다음 Phase 2를 시켜요.
