# 기록 캘린더

연습 탭을 기록 탭으로 표시하고 월별 캘린더와 선택 날짜의 연습·레슨·숙제 수행 카드를 추가했다. 카드에서 기존 기록으로 이동하며 연결 파일은 기존 플레이어로 연다. 기존 전체 연습 이력과 작성 폼은 유지한다.

- 캘린더는 기존 데이터의 읽기 전용 표시다. localStorage/IndexedDB 스키마 변경이나 초기화 없음.
- 월 선택, 이전/다음 달, 오늘 이동, 윤년과 연말 전환 지원.
- 유효하지 않은 날짜는 달력에서 제외하되 기존 이력에서 보존한다.
- 월/날짜 변경에도 작성 중인 입력을 초기화하지 않는다.
- 신규 집중 테스트 9개 통과(Chromium 모바일·데스크톱, WebKit 모바일).
- IAB 390×844에서 개발용 예시 기록으로 시각 검토. 실제 iPhone 미검증.
- 전체 화면 개편 중 캘린더 단계이며 숙제 체크리스트와 독립 상세 화면은 후속 작업.
