# LEARN-09-01A: 실제 연습 시간 집계 — 2026-11-09

## 저장·집계 계약

- 직접 입력한 manualMinutes를 우선한다. 명시적 0도 유효하다.
- 과거 기록에 manualMinutes가 없으면 기존 minutes를 유지해 읽는다. 기존 데이터의 자동 수정/초기화는 하지 않는다.
- practiceTimeSource=unconfirmed는 실제 수행 시간이 미확인인 기록이며 시간 집계에서 제외한다.
- 새 업로드의 자동 연습 기록은 minutes=0, manualMinutes=0, practiceTimeSource=unconfirmed로 만든다. 파일 길이는 mediaSeconds와 원본 파일 메타데이터에 따로 보존한다.
- 연습 기록 저장 시 사용자가 입력한 분을 minutes/manualMinutes에 저장하고 practiceTimeSource=manual로 확인한다. 녹음 선택·연결·해제로 시간을 자동 변경하지 않는다.
- 사용자가 명시적으로 누른 녹음 길이 채우기 버튼은 입력 보조로 유지한다.
- 미연결 녹음·파일 길이는 실제 연습 시간에 자동 합산하지 않는다. 파일 개수와 보관함의 길이 표시는 유지한다.
- 홈·성장·곡 상세·캘린더는 공통 실제 시간 모델을 사용한다. 캘린더의 기존 횟수 정의는 유지하며 미입력 시간은 따로 안내한다.
- 동일 기록 ID의 중복 버전은 최신 updatedAt 하나를 읽는다. 서로 다른 실제 연습 기록은 같은 녹음을 연결해도 별도 수행 시간으로 계산한다.
- 트레이닝 기록은 녹음 연결과 직접 시간 입력을 유지하며, 남아 있는 곡 ID로 곡별 시간을 부풀리지 않는다.

## 과거 데이터의 한계

예전 업로드가 파일 길이를 manualMinutes로 저장한 기록은 실제 직접 입력과 구분할 수 없다. 이를 추측해 일괄 0으로 만들거나 원본을 덮어쓰지 않는다. 사용자가 기록을 열어 실제 시간을 확인·수정할 수 있다.
기존 mediaSeconds는 호환 정보로 보존하며 실제 연습 시간으로 사용하지 않는다.

## 범위·검증

화면 구조·색상·카드·아이콘은 변경하지 않는다. 집계 기준 설명과 시간 미입력 문구만 동작에 맞게 조정한다.
새 실제 시간 모델, 구형 데이터 보존, 중복 ID, 트레이닝, 업로드 후 직접 시간 확인과 홈/성장/캘린더 일치를 자동 검사한다. 실행 결과는 PR/Actions에 기록한다.
이번 범위는 실제 시간 집계다. 반복 목표·숙제의 최종 완료·선생님 기능 전체를 완료 처리하지 않는다.
