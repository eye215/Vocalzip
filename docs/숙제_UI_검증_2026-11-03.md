# 숙제 체크리스트

전체/숙제 보기, 진행 중 체크리스트, 완료 목록 펼침, 직접 추가와 내용·안내 메모 수정, 수행 이력 펼침을 추가했다. 같은 숙제 ID와 레슨 연결 및 수행 메모를 유지한다. 저장은 기존 changeData 트랜잭션과 롤백 경로를 사용한다.

저장 실패 시 입력 보존과 재시도, 수정 취소, 완료/다시 진행, 목록 전환, 레슨 삭제 후 보존에 대한 24개 집중 테스트가 Chromium 모바일·데스크톱 및 WebKit 모바일에서 통과했다. IAB 390×844에서 참고 이미지와 나란히 비교했다. 실제 iPhone 검증은 하지 않았다.

스키마 마이그레이션/초기화/데이터 삭제 없음. 기존 레슨 숙제도 같은 체크리스트에서 보인다. 숙제 안내 note는 선택 속성이고 기존 레코드는 그대로 지원한다.
