# 주간 연습 — 최종 수정 범위

첨부 화면의 내용과 레이아웃을 유지하며 주간 체크 원의 색상과 현재 요일 표기만 수정합니다.

- 상단 내용 유지: **180분 / 목표 3시간 / 달성률 100% / 6일 연속**. 예시 수치의 재계산이나 변경 없음.
- 요일 아래 분·퍼센트·새 설명을 추가하지 않음.
- 원의 보라색 진하기: 100% 미만 #D9C5FA / 100~120% #7A32F5 / 120% 초과 #4C188E.
- 지난 날 연습 없음은 #E4E7EC, 미래는 빈 원.
- 요일은 월·화·수·목·금·토·일 그대로 유지. '오늘'로 치환하지 않음.
- 현재 요일 글자는 #7A32F5 / 700, 원 바깥에는 #7A32F5 2px 링, 간격 3px.
- 현재 날짜 강조와 달성률 색상은 독립적. 현재 날짜라도 실적이 있으면 해당 보라색을 채우고 링은 유지.

시안의 색상 예시: 월 연습없음 / 화 100% 미만 / 수 100~120% / 목 120% 초과 / 금 100~120% / 토 현재요일 / 일 미래. 상단 합계와 문구는 사용자가 유지 요청한 시각 참조 값이며 이 예시로 재계산하지 않습니다.
