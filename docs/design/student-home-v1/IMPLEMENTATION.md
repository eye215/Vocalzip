# 개발 인계 — 학생 홈 승인 시안 적용

## 목표

[final-approved.jpeg](./final-approved.jpeg)와 [디자인 시스템](./README.md)을 기준으로 기존 Vocalzip 학생 홈을 구현한다. 사용자는 2026-11-07 KST 이 시안을 기준으로 개발 진행을 승인했다. 이번 문서 PR은 **승인 이미지·토큰·개발 지시서만 추가**하며 앱 적용 코드가 아니다.

## 기존 코드·PR 관계

- `app/views-main.js`: 기존 홈·연습 기록 렌더/이벤트. 기존 데이터·액션을 확인한 뒤 시각 계층만 점진적으로 교체한다.
- `app/app.css`, `ios-lavender.css`, `glass.css`, `ui-refresh.css` 등 기존 레이어가 있으므로 CSS 우선순위 충돌을 먼저 확인한다.
- DS PR #120: `design-system/v1-foundations-and-components` 초안. 여기의 토큰·컴포넌트를 수정하는 방향을 우선한다.
- 홈 파일럿 PR #122: #120에 의존하는 다음 레슨 카드 전환 초안. 현재 미병합이며 전체 홈 구현 완료가 아니다.
- #120의 과거 ‘원형 링/주간 사각 타일/불꽃 제거’ 규칙은 이 승인 시안의 ‘반원/꽃 배지/불꽃 유지’로 대체한다.
- 기존 제품 정책 문서의 데이터 계약과 사용자 기록은 보존한다. 정산·업로드·분석·인증 리팩터링을 이 UI 작업에 섞지 않는다.

## 반드시 유지할 최종 결정

1. 라벤더 Liquid Glass 카드·몽환적인 배경·iOS 곡률·균형을 유지한다.
2. 카드 제목은 아이콘 수준의 보라색, 일관된 600 굵기. 인사말은 선명한 흰색 세미볼드.
3. 아이콘은 채움형 보라색, 몽환적 색 변화. 입체 돌출 금지. **중앙 녹음만** 구체형 글래스 + 흰 마이크 예외.
4. 무대 카드 하단에 다음 레슨 통합.
5. 목표는 반원 게이지 + 단일 내부 스크롤 체크리스트. 목표 체크는 **얇은 둥근 사각형**.
6. 주간 기록은 **꽃잎 배지 + 달성 시 ✓**, 일별 비율에 따른 3단계 보라색. 오늘 배지는 별도 유지.
7. 주간 실제 시간·목표·달성률은 한 줄, 불꽃 + 연속 일수는 유지.
8. 최근 곡 1:1 + 우측 레슨노트/연습기록. 퀵메뉴 보관함 중복 금지.
9. 하단 네비 순서 홈/내 곡/녹음/보관함/일정. 녹음 외 글자는 아이콘보다 연하게.
10. 320/390/430px·safe-area·최소 44px 터치·긴 텍스트 검증. 단순 화면 축소 금지.

## 데이터 연결 전 확인할 사항

- 일별 연습 목표가 기존 모델에 존재하는지, 주간 목표에서 도출하는지 확인. 예시 하루 30분·주 3시간은 시안용이다.
- 목표 0개·1개·3개·10개·900개를 처리. 분할 칸을 생성하지 않고 반원 비율과 완료/전체 수를 표시한다.
- 비율 경계: 0, 99, 100, 120, 121%. 정확히 120%는 중간 보라, 120% 초과만 진보라.
- 오늘: 미연습·미달성·달성·초과 달성 모두 오늘 배지를 보존한다.
- 시안의 연속 6일은 ‘매일 실제 연습 있음’ 예시다. 서비스의 휴식일·연속 산정 계약을 확인하고 정책을 UI에서 임의 변경하지 않는다.
- 주간 합산은 같은 기록이 녹음/수동 입력에 중복 연결돼도 중복 계산하지 않는다. 기존 데이터 계약 재사용.
- 로컬 날짜 기준 월~일과 D-day의 타임존 처리 확인. 예시 날짜를 하드코딩하지 않는다.
- 정보가 없으면 가짜 실제 기록이나 임의 목표를 만들어 저장하지 않는다.
