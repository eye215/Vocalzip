# 녹음 및 재생 UI 개선

기존 라벤더 색상과 데이터 저장 흐름을 유지하면서 연습 녹음 영역을 폼 위로 옮겼다. 음성/영상 선택, 큰 시간 표시, 실제 마이크 파형, 일시정지/재개, 종료·저장, 메모에 시간 마크 남기기를 연결했다. 이름 입력은 선택적으로 펼친다.

보관함 및 연습 연결 파일은 공통 재생 카드로 표시한다. 재생/일시정지, 시간/길이, 접근성 이름이 있는 탐색 슬라이더, 기본 플레이어 대체 경로를 제공한다. 파형 요약이 있는 새 로컬 녹음은 최대 512개 진폭 요약으로 표시한다. 파일 전체 디코딩이나 클라우드 원본 다운로드는 추가하지 않았다. 기존 파일과 클라우드만 남은 파일에는 파형을 생성하지 않으며 탐색 바를 사용한다. 파형은 음성 분석 점수가 아니다.

## 검증
- JavaScript 구문 검사 통과.
- 최종 Chromium mobile/desktop: 98 passed.
- 파형 저장/표시, 클릭, 탐색 집중 검사: 2 passed.
- Windows 전체 실행(최종 파형 변경 전 시작): 137 passed / 5 skipped / 5 failed. 실패는 기존 Windows WebKit WAV 디코딩 테스트 5개. 성공으로 처리하지 않았다.
- IAB 390×844에서 녹음 화면 및 합성 WAV 파일의 보관함 재생 카드 확인.
- 실제 iPhone Safari 녹음·MOV·M4A·메모리·백그라운드 복귀는 미검증.
- 기존 데이터를 초기화하거나 서버 스키마/정책을 변경하지 않았다. 배포하지 않았다.

## 남은 UI 작업
캘린더 기록 탐색, 체크리스트 숙제 화면, 기록 상세의 메모/비교 배치를 이어서 개선해야 한다. 이번 변경은 녹음/재생 카드에 한정한다. 클라우드 파형 요약 동기화는 아직 지원하지 않는다.
