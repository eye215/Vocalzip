알림 키 만들기

‘휴대폰으로 녹음’ 알림에 쓰는 키 한 쌍을 이 기기 안에서만 만들어요. 아무 데도 보내지 않고 저장하지도 않아요. 이 창을 닫으면 사라져요.

  1. Supabase 대시보드 → 이 프로젝트 → Edge Functions → Secrets를 열어요.
  2. 아래 세 줄을 하나씩 Add new secret으로 넣어요. 이름(Key)과 값(Value)을 그대로 복사해요.
  3. 저장하고 나면 이 창을 닫아요.

VAPID_PUBLIC_KEY

VAPID_PRIVATE_KEY

VAPID_SUBJECT

https://vocalzip.yullul.com

VAPID_PRIVATE_KEY는 비밀번호와 같아요. Supabase Secrets에만 넣고, 채팅·메모·GitHub·스크린샷에 남기지 마세요. 잃어버리거나 노출되면 이 화면에서 새로 만들어 세 값을 다시 넣으면 돼요(그 뒤에는 각 기기에서 알림을 한 번 다시 켜요).
