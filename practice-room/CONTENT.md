# 노래 연습실 콘텐츠 v1

이 버전은 사용자가 직접 고른 노래와 구절로 수행하는 **텍스트 안내·기기 내 기준 소리·제출·자기 회고**다. 과제별 실제 문구는 `lessons.js`에서 관리한다. 영상 강의나 외부 음원은 포함하지 않으며, 제출 횟수는 숙련도나 통과 점수가 아니다.

| 단계 | 과제 | 학습 내용 | 남기는 자료 |
|---|---|---|---|
| 출발점 찾기 | 나의 시작점 적기 | 노래·어려움·이번에 바꿀 행동 구분 | 답변과 다음 행동 |
| 편하게 소리 내기 | 편한 소리로 한 구절 남기기 | 편한 구간을 짧게 고르고 상태 인지 | 음성·편안함·회고 |
| 음정과 리듬 | 기준음 / 짧은 선율 / 단순 리듬 | 한 음 비교, 음 움직임, 시작 간격을 각각 확인 | 각 과제 음성·기초 비교·회고 |
| 가사 전달 | 가사를 말로 전하기 | 상대를 정하고 전달할 단어를 골라 읽기 | 읽은 음성·들린 말 회고 |
| 음악적으로 표현하기 | 표현을 담은 한 구절 | 강약·길이·쉼 중 한 가지 선택 | 부른 음성·선택한 표현 회고 |
| 감정과 해석 | 가사의 상대와 목적 정하기 | 상대·상황·바라는 변화를 분리 | 답변과 다음 적용점 |
| 장면 만들기 | 상황 속 한 구절 부르기 | 장면과 행동을 정하고 소리에 반영 | 부른 음성·의도 회고 |
| 한 곡 완성하기 | 두 구절 연결하기 | 나눠 부른 A와 이은 B를 직접 비교 | A/B 음성·연결 지점 회고 |
| 첫 공연 | 공연 연습 녹음과 회고 | 5분 이하 구간을 한 흐름으로 부르고 되돌아보기 | 음성·유지할 점·바꿀 점 |

기준음·선율·리듬은 브라우저가 만든 예시 소리와 기초 비교한다. A/B 자동 비교는 하지 않고 사용자가 직접 듣는다. 발성 방식, 안전성, 감정의 정답, 무대 움직임은 판정하지 않는다. 예시 녹음은 실제 제출·연습 시간·클라우드 저장에 반영하지 않는다.

## 다음 콘텐츠 작업

- 사용자가 원하는 곡·영상 또는 선생님의 자료를 과제에 연결하는 정책과 실제 자료 선택 UI.
- 영상이 없는 과제의 대체 경로, 구간 시작·종료와 부적절한 추천 자료 제외.
- 실제 사람 목소리와 iPhone 녹음으로 기준 소리·기초 분석·안내 난도를 검토하고 문구를 조정.
