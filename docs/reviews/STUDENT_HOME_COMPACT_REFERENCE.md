# PR #136 레퍼런스 기반 학생 홈 고도화

기준: main `c47082038ed0`의 [상세 분석](../design/compact-ui-reference-2026-11-08/README.md), 사용자가 올린 assets 이미지.
이 문서는 이전 미채택 시안과 구분되는 구현 명세다. 레퍼런스 적용 및 자동 테스트 통과와 사용자 시각 승인은 구분한다.

## 적용

| 구분 | 구현 |
| --- | --- |
| 정보 순서 | 인사 → 주간 연습 → 최근곡/바로가기 → 목표 → 조건부 공연·레슨 |
| 화면 / 내부 여백 | 좌우 16px / 기본 16px, 카드 간격 12px |
| 표면 | 연한 라벤더 바탕, 흰 카드, 전체 카드 반경 22px, 최근곡 20px |
| 주간 연습 | 실제 연습 분을 30px 핵심 수치 하나로 표시; 목표/달성률과 7일 상태는 보조 |
| 최근곡 | 기본 외곽 1:1; 390px에서 173px, 오른쪽 2행 바로가기와 동일 높이 |
| 긴 곡명·큰 글자 | 비율보다 내용 보존 우선, 전체 제목·작품명 줄바꿈 및 카드 확장 |
| 목표 | 한 카드 안 48px 행, 22px 체크, 15/22 본문, 12/18 출처; 완료 개수는 제목 옆 |
| 다수 목표 | 기존 내부 스크롤과 행 순서 유지. 전체 목표 접근 정책을 임의 변경하지 않음 |
| 일정 | 실제 날짜·시간 우선, 긴 제목은 줄바꿈; 일정이 없으면 미노출 |
| 이미지 | 실제 사용자 포스터만 표시. 커버가 없으면 중립 음표 아이콘 |
| 아이콘 | 기존 지정된 채움 형태 복원, 약한 보라색 명암; 중앙 녹음 외 강한 면적 제한 |
| 하단 메뉴 | 기존 5개 경로 유지, 밝은 반투명 독과 본문 하단 여유 |

목표 3개를 기본 높이에 표시하며, 길이가 긴 목표는 내부에서 스크롤해 전체 내용을 확인한다.
큰 글자에서는 곡 타일과 바로가기가 높이를 늘린다. 모든 내용을 한 화면에 맞추려고 글자·터치 영역을 줄이지 않는다.
이번 작업에서는 홈과 연결되는 기존 동작을 유지하며 다른 화면의 레이아웃을 전면 개편하지 않는다.

## 기존 기능 보존

계정·로컬 저장·클라우드 동기화·파일·정산·AI 정책은 변경하지 않는다.
녹음 길이를 주간 연습에 합산하지 않고 기존 수동 수행 시간 집계를 사용한다.
체크 저장, 실패 복원, 목록 위치 보존, 최근 녹음 재생과 종료, 기존 화면 이동을 재사용한다.
앞선 미채택안의 큰 검정 카드·목표 달성률 히어로·추가 녹음 버튼은 이 홈 구성에서 제거한다.
녹음은 기존 중앙 메뉴에서 시작한다.

## 검증

- JavaScript 구문 파싱.
- 실제 연습 30분, 원본 minutes 99 및 녹음 3600초가 섞인 fixture에서 대표 수치가 30인지 확인.
- 320/390/430px에서 1:1/높이 정렬, 카드 간 겹침, 가로 넘침, 스크롤 끝 하단 여유.
- 긴 한글·공백 없는 영문 곡명 및 긴 일정 제목의 줄바꿈과 내용 보존.
- 기존 900개 목표, 체크 저장·새로고침·실패 복구, 큰 글자, 경로 이동, 실제 WAV 재생 회귀.
- 흰 카드 대비 색상 계산: 본문 #352b40 13.37:1, 보조 #786381 5.38:1, 제목 #58416b 8.81:1, 출처 #806989 4.88:1, 체크 경계 #9b83ae 3.36:1.
- 브라우저 실행 결과 및 실제 렌더링 캡처는 PR #135와 해당 Actions에 기록한다. 실행 전 항목을 통과로 표시하지 않는다.

전체 길이 캡처에서는 고정 하단 메뉴를 숨겨 콘텐츠를 확인한다. 뷰포트 캡처는 실제 고정 메뉴를 표시한다.
Linux WebKit과 실제 iPhone Safari/PWA/VoiceOver 검증은 구분한다. 실기기 검증 및 운영 배포는 이번 자동 검증에 포함되지 않는다.
